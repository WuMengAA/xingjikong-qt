⇒ 以后验证任何 nsi，**cwd 和 nsi 必须同目录**。

### 6-D-3 根因二：`Q_INVOKABLE` 写在了没有访问说明符的地方 ⇒ class 默认 private ⇒ QML 调不到

上轮挂着的另一条 WARN：`Main.qml:1926 TypeError: Property 'subscribeThumbnails' of object
ViewerBackend is not a function`。上轮记的是「待确认是改名还是未实现」——**都不是**：

真因在访问段（实测行号）：
- `class ViewerBackend` 起于 h 第 61 行；
