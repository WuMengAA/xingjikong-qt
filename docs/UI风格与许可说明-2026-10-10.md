## 二、许可明细

### Qt 6.12 官方 FluentWinUI3 风格
- **本质**：Qt Quick Controls 的官方内置风格（与 Basic/Fusion/Material 同级打包），**非第三方库**。
- **许可**：跟随 Qt 本身 —— **LGPLv3 / GPLv3 / 商业**。
- **我们的用法（合规）**：动态链接 Qt DLL + QML 插件（FluentWinUI3 是 qml 目录里的运行时插件），
  不修改 Qt 源码、不静态链接 → **LGPLv3 合规**，产品可保持闭源。

### QWinUI3（wuyijing-dev/QWinUI3）
- Apache-2.0（宽松，可闭源商用）。
- **未采用**：仅源码、需自行构建维护，且有明确 Windows 重心；官方 FluentWinUI3 覆盖其核心表意。

### Class-Widgets-2（RinLit-233-shiroko/Class-Widgets-2）
- **MIT 许可**（用户 2026-10-10 确认）。
- 用途：借鉴其桌面小组件 UI 设计（配色/布局/动效），MIT 允许，需保留版权声明。

## 三、技术要点（后续工作可用）

- Qt 6.12 FluentWinUI3 是**运行时 QML 风格**：`qputenv("QT_QUICK_CONTROLS_STYLE", "FluentWinUI3")`
  或 `QQuickStyle::setStyle`，**不需要** find_package/link（手机端已验证零 link 生效）。
- 风格作用在**标准 Controls**（Button/Dialog/ComboBox/Slider/TabBar 等），
  自绘组件（Rectangle + th 令牌）不受影响，可共存。
- Qt 6.12 Quick 依赖链需要 **Qt6TaskTree**（addon，维护工具 `qt.qt6.6120.addons.qttasktree`）——
  QmlAssetDownloader 的依赖，缺它 find_package 失败（已装好）。
- 管理端要切 Fluent 需**删除 WebEngine 依赖**（Qt 6.12 不装 WebEngineWidgets，
  且「去 WebEngine 底层」本来就是目标）——见《WebRTC去WebEngine接线方案-2026-10-09.md》。
