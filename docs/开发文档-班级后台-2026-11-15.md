## 1. 架构：模块化，而不是写死

### 1.1 前后端分离（现状）

```
Qt / QML 管理端  ──HTTP Bearer──┐
Qt 被控端       ──WS /ws/agent ─┼──► Stelarith-cloud（本实例）
网页（可选）     ──WS /ws/viewer┘        │
                                        ├── src/class-*.js      班级域（按对象拆）
                                        ├── src/classroom-*.js  他线 WIP，未入库
                                        ├── src/store.js        指令队列 + 审计
                                        └── node:sqlite 本地库  零外部服务
```

QML 只画图与点击（AGENTS §10.9）；**所有 JSON 解析、权限判定、落库都在 C++ / Node**。
云端按模块拆，不是一坨：`class-admin.js` 只剩路由分发与 re-export，业务落在
`class-admin-classes.js`（班级身份）/ `class-admin-students.js`（学生与课表）/
`class-admin-attendance.js`（考勤）/ `class-admin-shared.js`（权限与租户）。
新增一个域 = 新建一个 `src/<域>/` 或 `src/class-*.js` + 在 `index.js` 挂一行分发，
**不动其它模块**（这正是用户第 1 条「加功能不牵一发动全身」的既有落点）。

## 2. API 接口调用

### 2.1 鉴权（所有管理面调用都先过这一关）

```
Authorization: Bearer <CLOUD_VIEWER_TOKEN 或 站点签发的 viewer 票据>
```

- 两条通道都认：静态令牌（`mode:'token'`，`scopes:null` = 全权，审计匿名）与票据（带 `claims`）。
- **裸 uid 票据 = 零权限**（`f943fd8` 的 fail-closed：`perms.js:48` 无 claims ⇒ `scopes: []`）。
  「能签票 ≠ 能管设备」；合法老师靠站点 claims 票或 `/api/admin/user-claims` 白名单授予。
- 平台级端点（`/api/admin/config`、`/api/admin/ota`、`/api/admin/provision*`、
  `/api/admin/songkeys`、`/api/admin/user-claims`、`/api/admin/broadcast-club`）额外要求
  `platform_admin` 或全权身份，否则 403 `PV4002`。
- 班级写操作（`/api/class/*` POST）票据身份超过 `STE_REAUTH_INTERVAL_MS`（默认 8h）
  回 403 `AU1002 REAUTH_REQUIRED`，重登后重试；静态令牌不受此限。

**错误形状**（`src/protocol.js` 的 ECODES，不是纯文本猜）：
```json
{ "ok": false, "ecode": "AU1003", "code": "TOKEN_INVALID", "error": "未授权：需要 Bearer ..." }
```
常用：`AU1003` 令牌无效 / `PV4002` 无设备或班级权限 / `DV3001` 设备离线 /
`CM1002` 缺 uid 或 action / `CM4001` 无权执行 / `CIMS_RETIRED`(410) 旧通道已退役。

### 2.5 WebSocket（同一实例的三条升级路径）

| 路径 | 谁连 | 握手 |
|---|---|---|
| `/ws/agent` | 被控端 | 连上后必须先发 `register`（v1 信封 `{v:1,type,id,ts,payload}` 或旧扁平双认） |
| `/ws/viewer` | 管理端 | 先发 `auth`：`{token}` 或 `{ticket}`；成功回 `authed`（v1）/ `auth-ok`（旧），带 `identity` |
| `/ws/tunnel*` | 远控隧道 | **已下线**，仅旧客户端兼容；新客户端走主 WS 的 `vnc-data` 二进制帧 |

被控端 register：
```json
{"v":1,"type":"register","id":"r1","ts":1730000000000,
 "payload":{"uid":"class_a_2028_01","token":"<设备令牌或设备票>","fp":"<设备指纹>","version":"0.6.72","name":"高一(1)班"}}
```
回执 `registered`（旧客户端 `registration-ok`）带 `uid / heartbeatMs / timeoutMs / classCode /
`className / role / latestVersion / updateUrl / updateSha256 / updateNotes / updateMandatory`。
**班级归属只认云端 `knownDevices` 表**，端侧自报 `classCode` 一律忽略。

管理端 auth：
```json
{"v":1,"type":"auth","id":"a1","ts":1730000000000,"payload":{"token":"<CLOUD_VIEWER_TOKEN>"}}
```
或 `{"payload":{"ticket":"v1.<exp>.<uid>.<nonce>.<hmac>"}}`。票据第 3 段可编
base64url(JSON claims)；`identity.scopes` 是数组时 viewer 自动锁死本地「切管理员」。

**按班事件**（低频语义事件，2 秒一拍的样本不走这里）：
```json
{"v":1,"type":"class-event","id":"e1","ts":1730000000000,
 "payload":{"kind":"noise_alert","data":{"message":"本节课噪音连续超阈 3 次","hits":3,"at":"..."}}}
```
云端四道闸：`kind` 匹配 `/^[a-z0-9][a-z0-9_.-]{0,31}$/`；`data` 必须是对象且 JSON ≤ 64KB；
同 `uid|kind` 最小间隔 1s（回 `throttled:true`，不静默丢）；fanout 背压 > 8MB 跳过。
落 `class_events` 表（环形 200 条），无班回 `{ok:false,code:'NO_CLASS'}`。
视图侧 `ClassEventModel` 的 detail 回落 `data.message`，**前端零改动就能显示**。

### 2.6 新线 `admin-server` 的开发者后台（纯后端，默认 `:8855`）

```text
GET  /health                      GET  /api/public/health
GET  /api/schools  /api/classes  /api/devices  /api/users  /api/scopes  /api/automations
POST 同上六表                GET  /api/events
POST /api/instructions        GET  /api/instructions/:batchId/status
GET|POST /api/plans · POST /api/plans/:id/execute · DELETE /api/plans/:id
POST /api/local-token · /api/local-token/verify
GET  /api/class-applies ...（12 条，状态机 pending/approved/rejected/bound）
GET  /api/dev/status|meta|schema|stats|health|tables/:table|events|backups
POST /api/dev/query（只读 SQL，四道闸）· /api/dev/backup（VACUUM INTO 热备份）
WS：/ws/agent · /ws/admin · /ws/viewer（兼容现役 Web 后台）
```

`/api/dev/*` 一律要求 `identity.tenantBypass`（静态 `ADMIN_TOKEN`）：自由 SQL 一旦放行，
租户过滤拦不住 `SELECT * FROM users`，故**人的身份一律 403**。只读 SQL 还有
`SELECT|WITH|EXPLAIN QUERY PLAN|VALUES` 白名单 + 禁写关键字 + 单语句 + `query_only=ON` + 行数上限。
本线默认 SQLite 真持久化（`data/admin.db`，WAL），`ADMIN_DB_DISABLE=1` 可退回旧内存实现。

### 4.1 主权契约（用户 m30108 的核心）

```text
src/instance.js: SOVEREIGNTY_CONTRACT.crossCloudControl === false
每个实例只管自己的设备、班级、令牌与数据；不代理、不指挥、也不被别的云端指挥。
```

**为什么改代码**：旧 `provision.js` 把 `https://control.245959623.xyz` 写成了
`CLOUD_PUBLIC_BASE` 的默认值。别人拿源码单独部署，生成的装机 bat 会连回我方云端 ——
那不是独立部署，是一次隐式接管。现在 fail-closed：**不填自己的地址就不生成装机包**，
绝不猜、绝不回落到我方域名（`src/instance.js` 是这条契约的唯一代码落点）。

全仓扫描结论：`245959623.xyz` 只剩三处**可选内容源**注释/常量
（`voicehub-sources.js` 的点歌主备源、`voicehub-bridge.js` 注释），
**不是控制通道**，留空即关闭；`/api/admin/cims*` 全部 410。代码里不存在
`fetch(上级云端)` / 中心令牌 / 跨实例下发。

### 4.2 最小部署（单机 / 一个电教委员 / 一所学校）

```bash
# 1) 拿源码（只要 Stelarith-cloud/ 这一个目录即可）
#    Node 22.5+（推荐 24 LTS，本机实测 v24.14.0 + SQLite 3.51.2）
cd Stelarith-cloud
npm install --omit=dev            # 唯一业务依赖：ws

# 2) 生成三把自己的随机令牌（不要复用样例，不要跨实例共用）
node -e "for(let i=0;i<3;i++) console.log(require('crypto').randomBytes(32).toString('hex'))"

# 3) 从模板复制 .env，只改下面这些（完整键表见 .env.example）
#    CLOUD_PUBLIC_BASE=https://cloud.school-a.edu.cn   ← 你自己的域名/IP，不是我方域名
#    CLOUD_WS_HOST=0.0.0.0                            ← 只本机用就 127.0.0.1
#    CLOUD_WS_PORT=8788
#    CLOUD_WS_TOKEN=<第 1 把>        # 被控端 STE_QT_WS_TOKEN 与它一致
#    CLOUD_VIEWER_TOKEN=<第 2 把>    # 管理端 / 桌面端与它一致
#    CLOUD_VIEWER_SECRET=<第 3 把>   # 签 viewer 票据用
#    STE_SITE_URL=（留空）           # 独立部署不接我方站点账号
#    STE_OAUTH_CLIENT_SECRET=（留空）

# 4) 部署自检（只读、不连网、不打印令牌）
node scripts/check-standalone.mjs --strict

# 5) 起服务
node --env-file=.env src/index.js

# 6) 验收
curl -H "Authorization: Bearer <CLOUD_VIEWER_TOKEN>" https://cloud.school-a.edu.cn/api/classes
```

`--strict` 会拒：官方域名、跨云端控制键、`STE_SITE_URL` 依赖、弱/默认令牌、
设备与管理端令牌相同、Node 版本过低、`ws` 缺失。非严格模式只查「有自己的地址 +
本地凭据不是默认值」，适合我方现役实例自查。

**HTTPS / 域名 / 备案**：服务本体只说 HTTP/WS，公网请自备 Nginx / Caddy 反代并终结 TLS；
`CLOUD_PUBLIC_BASE` 填 `https://` 时装机 bat 自动派生 `wss://`（`wsUrlOf()` 已处理，
别手写 `https://.../ws/agent`，那是当年握手失败的老坑）。域名与备案属学校自己的运维，
不在本代码里。

### 4.3 被控端与管理端指向本实例

- 被控端：`STE_QT_WS_TOKEN` = 本实例 `CLOUD_WS_TOKEN`，云端地址 = `wss://<自己的域名>/ws/agent`。
- 管理端：`STE_VIEWER_TOKEN` = 本实例 `CLOUD_VIEWER_TOKEN`，地址 = `wss://<自己的域名>/ws/viewer`。
- 装机包：`assets/pkg/` 放自己的安装包、`assets/provision/` 放脚本，
  `GET /api/admin/provision/status` 会回报**本实例**的两个 WS 地址；
  `/api/admin/provision?type=agent&uid=...` 生成的 bat 只指向本实例。
  **未配 `CLOUD_PUBLIC_BASE` → 生成直接抛错**，不会偷偷连回我方。
