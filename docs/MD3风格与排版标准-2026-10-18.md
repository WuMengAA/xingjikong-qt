# 星集控 · MD3 风格与排版标准（2026-10-18）

> 依据：`qml-md3` 组件库 v1.1.4（https://github.com/wuyijing-dev/qml-md3），
> LGPL-3.0 动态链接接入。本文档是**风格与排版规范的真源**，不是代码——
> 代码接入与分批迁移在标准批准后另立任务。
>
> 用户裁决（2026-10-18）：**先定标准再动代码**；授权 LGPL-3.0 动态链接。
> 背景：现有 `Stelarith-shared-qml/ui/Md3.qml` 只是"换了皮肤"（令牌换 MD3 值，
> 组件未迁）；本标准以 qml-md3 的企业级实现为准，覆盖色彩/字阶/形状/状态层/
> 动效/阴影/组件，并给出差异清单与迁移路线。

---

## 0. 一句话

**星集控两端（管理端 viewer-qt / 被控端 control-qt）的视觉与交互统一采用
qml-md3 v1.1.4 的 Material 3 实现**：设计令牌（色/字/形/态/动效）以 qml-md3
`Md3Theme`/`Md3ColorScheme`/`Md3Typography`/`Md3Shape`/`Md3Motion` 为准；
组件以 `import Md3` 的 204 个组件为准；现有手写组件与页面分批迁入，迁移桥
（legacy 别名）在迁移完成后删除。

## 1. 令牌标准（真源：qml-md3 docs/guides/tokens.md）

### 1.1 色彩角色

对齐 Flutter `ColorScheme` 全量 surface（浅/深，基线种子 `#6750A4`）：

- `primary / onPrimary / primaryContainer / onPrimaryContainer`
- `primaryFixed / primaryFixedDim / onPrimaryFixed / onPrimaryFixedVariant`
- `secondary`、`tertiary`（同上四件套 + Fixed*）
- `error / onError / errorContainer / onErrorContainer`
- `surface / onSurface / surfaceDim / surfaceBright`
- `surfaceContainerLowest / Low / (默认) / High / Highest`
- `onSurfaceVariant / outline / outlineVariant`
- `shadow / scrim / inverseSurface / onInverseSurface / inversePrimary / surfaceTint`

**禁用态**：内容用 `onSurface` @ **0.38** 不透明度；容器用 @ **0.12**。

### 1.2 状态层（on* 色叠在容器上）

| 状态 | 不透明度 |
|------|---------|
| hover | 0.08 |
| focus | 0.12 |
| press | 0.12 |
| drag | 0.16 |

⚠️ 与现有 `Md3.qml` 差异：press 是 **0.12** 不是 0.10；缺 focus(0.12)/drag(0.16)。

### 1.3 字阶（dp/sp）

| Role | Size | Weight | Tracking | Line height |
|------|------|--------|----------|-------------|
| displayLarge | 57 | 400 | -0.25 | 64 |
| displayMedium | 45 | 400 | 0 | 52 |
| displaySmall | 36 | 400 | 0 | 44 |
| headlineLarge | 32 | 400 | 0 | 40 |
| headlineMedium | 28 | 400 | 0 | 36 |
| headlineSmall | 24 | 400 | 0 | 32 |
| titleLarge | 22 | 400 | 0 | 28 |
| titleMedium | 16 | 500 | 0.15 | 24 |
| titleSmall | 14 | 500 | 0.1 | 20 |
| bodyLarge | 16 | 400 | 0.5 | 24 |
| bodyMedium | 14 | 400 | 0.25 | 20 |
| bodySmall | 12 | 400 | 0.4 | 16 |
| labelLarge | 14 | 500 | 0.1 | 20 |
| labelMedium | 12 | 500 | 0.5 | 16 |
| labelSmall | 11 | 500 | 0.5 | 16 |

**字体**：HarmonyOS Sans SC（Regular 默认内置；Medium/Bold 可选，经
`MD3_BUNDLE_EXTRA_UI_FONTS` 或应用 `fonts/`）。回退系统 UI 无衬线。
**图标**：Material Icons Outlined（`Md3Icon variant:"outlined"` 默认）/ Filled。

⚠️ 现有 `Md3.qml` 字阶 13 档与本表一致（px 与 sp 同值），无需改；但**字体族
未指定**，需补 HarmonyOS Sans SC。

### 1.4 形状（dp）

| Token | Radius |
|-------|--------|
| none | 0 |
| extraSmall | 4 |
| small | 8 |
| medium | 12 |
| large | 16 |
| extraLarge | 28 |
| full | 9999（pill） |

⚠️ 现有 `Md3.qml` rXS=4/rS=8/rM=12/rL=16/rXL=28/rFull=999 **已一致**。

### 1.5 阴影 / 高程

高程 0–5。MD3 表面随高程以 `surfaceTint` 着色。阴影用 **key + ambient 双影**
（`Md3Shadow` + MultiEffect 模糊），让 FAB/菜单等浮动控件与页面分离清晰。

⚠️ 现有 `Md3.qml` **无阴影**（以色阶代高程）——需补。

### 1.6 动效（iOS UIKit / Core Animation）

历史 Material 令牌名保留为别名，曲线自动换 iOS 值。

**时长**：short1=100 / short2=150 / short3=200 / short4=250 / medium1=300 /
medium2=350（push / 多数 UI，即 `uiDuration`）/ medium3=400 / medium4=450 /
long1=500（modal / sheet，`spatialDuration`）/ long2–4=550–650 / extraLong*=700–1000。

**曲线（cubic-bezier → Qt Easing.BezierSpline）**：

| 别名 | Curve | CAMediaTimingFunction |
|------|-------|------------------------|
| iosDefault / emphasized / standard / ui | 0.25, 0.1, 0.25, 1.0 | Default |
| iosEaseIn / emphasizedAccelerate / uiExit | 0.42, 0.0, 1.0, 1.0 | EaseIn |
| iosEaseOut / emphasizedDecelerate / uiEnter | 0.0, 0.0, 0.58, 1.0 | EaseOut |
| iosEaseInOut / legacy | 0.42, 0.0, 0.58, 1.0 | EaseInEaseOut |
| iosSheet / spatialDefault / uiSpatial | 0.32, 0.72, 0.0, 1.0 | sheet settle |
| iosSnap / spatialFast / uiSpatialSnap | 0.2, 0.9, 0.1, 1.0 | snappy chrome |

⚠️ 现有 `Md3.qml` 动效 3 档（200/350/500ms + easeEmph/easeStd），
需扩到全表（含 sheet/snap 曲线、spatial 时长）。

## 2. 组件标准（真源：qml-md3 src/Md3/，204 个）

`import Md3` 模块 URI。按功能分域：

- **基础**：Md3Button（六变体）/ Md3Card（elevated/filled/outlined）/ Md3Checkbox /
  Md3Radio / Md3SwitchRow / Md3Chip / Md3ChipGroup / Md3TextField / Md3Icon
- **导航**：Md3AppToolBar / Md3NavBar / Md3BottomAppBar / Md3NavigationRail /
  Md3Breadcrumb / Md3CommandBar / Md3CommandPalette
- **反馈**：Md3Dialog / Md3BottomSheet / Md3Snackbar / Md3Banner / Md3Badge /
  Md3Badged / Md3ProgressIndicator（含 Circular）
- **数据**：Md3DataTable / Md3List / Md3ListItem / Md3Avatar(Group) / Md3Divider
- **图表**：Md3Chart（Bar/Area/Bullet/ArcBand/Compass 等）
- **日期**：Md3DateField / Md3DatePicker / Md3DateRangePicker
- **布局**：Md3VStack / Md3HStack / Md3Flow / Md3Grid / Md3AdaptiveContainer /
  Md3ApplicationWindow / Md3Panel

⚠️ 现有 12 个手写组件（Md3Btn/Md3Card/Md3CheckBox/...）将**退役**，由 qml-md3
同名/等价组件取代；组件名可能不同（如 Md3Btn → Md3Button），迁移时按 API 文档
逐一对齐。

## 4. 迁移路线（分批，每批可验证）

> 代码迁移在**本标准批准后**另立任务。原则：每批只动一个页面/组件域，
> 跑 qmllint + 构建 + 探针截图；迁移桥（legacy 别名）在全部迁完后删除。

1. **P0 接入**：qml-md3 以 `find_package(Md3)` 接入 viewer 构建（LGPL-3.0
   动态链接；锁 tag v1.1.4）；QML `import Md3` 首屏验证。
2. **P1 令牌对齐**：`ui/Md3.qml` 补全 ColorScheme / 状态层 / 字阶 / 阴影 / 动效
   （保留 legacy 别名，存量零改动）。
3. **P2 组件迁移**：按 基础 → 反馈 → 导航 → 数据 → 图表 顺序，逐组件替换
   手写实现（Md3Btn→Md3Button 等），每个组件跑 API 对照 + 截图。
4. **P3 页面重排**：管理端 Main.qml 1915 行手写 UI 按新组件域重排
   （排布优化与主题规范标准同步落地）。
5. **P4 退役**：删除 `ui/md3/` 12 个手写组件 + legacy 别名块。

## 5. 未决（需要裁决时另行提出）

- **被控端是否同步迁**：被控端灵动岛是独立置顶窗（C++ QQuickWidget），
  MD3 规范对动态岛的面签/进度条适配度需单独评估——建议先迁管理端，岛延后。
- **包体积**：qml-md3 静态库 Md3.lib ≈ 446MB（共享 DLL 形态会小很多）；
  接入后安装包增重幅度需实测（共享模式）。
- **字体内置**：HarmonyOS Sans SC 是否打进安装包（约数 MB），或依赖系统字体。
