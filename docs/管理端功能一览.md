## 0. 一句话

管理端 = **老师机上的控制台**：以「班级」为单位看本班设备与展板，以「集控」为管理员视角看全校设备；
动作下发走同一张动作表，结果统一落在回执与班级时间线里。

## 1. 形态与部署

| 项 | 实情 |
|---|---|
| 分发形态 | **NSIS 安装包**（`scripts/make-installer.nsi` → `dist/stelarith-viewer-setup-<ver>.exe`）+ **绿色版**（`scripts/make-portable.mjs`） |
| 配置 | 读 **exe 同目录的 `viewer.env`**（`set KEY=VALUE`）。⚠️ 引号包的是**整个** `KEY=VALUE`，不先剥这层整体引号 → key 变成 `"STE_VIEWER_TOKEN`（带前导引号）→ 能启动但连不上云端**且不报错** |
| 必填两项 | `STE_VIEWER_URL`（云端 `wss://…`）、`STE_VIEWER_TOKEN`（管理端静态令牌） |
| 常用可选项 | `STE_SITE_URL`（站点，`/register` 注册入口）、`STE_REGISTER_URL`（可覆盖注册地址）、`STE_VIEWER_LOG`、`STE_VIEWER_PROFILE`、`STE_ALLOW_MULTI`（自检绕开单实例）、`STE_SOFT_RENDER`、`STE_VNC_*`（远控）、`STE_OAUTH_*`（站点 OAuth） |
| 单实例 | 三级守卫：`Global\` 互斥 → `Local\` 降级 → 文件锁。只写 `Local\` 时，计划任务（Session 0）与手动双击（Session 1）会各认各的 → 双开 |
| 托盘常驻 | 菜单三项：`状态：运行中`（只显示不可点）/ `打开日志目录` / `退出管理端`；图标 QPainter **现画**，不依赖外部 `.ico` |
| 日志 | exe 同目录 `viewer-run.log`（`STE_VIEWER_LOG` 可改） |
| 技术栈 | **Qt 6.12.0 / msvc2022_64** / QML（旧版写的是 6.8.1，已过时）；`QApplication`（托盘属 QtWidgets） |
| 版本真源 | `CMakeLists.txt` 的 `set(VIEWER_VERSION ...)`；`src/main.cpp` 的回落值在 CMake 配置期做**一致性校验**，不一致直接 `FATAL_ERROR` |
| 自更新 | ❌ **管理端不自更新**。设置页「更新」分区只给下载入口（`open-download`），不做拉取/替换 |

## 2. 界面结构（骨架 = `qml/shell/MainWindow.qml`）

```
┌─ TopBar（当前栏目名 / 班级下拉 / 账户菜单）────────────────────────────┐
├─ ClassNav 侧栏 ─┬────────────── 内容区 ────────────────────────────────┤
│ 班级（带在线数） │  仪表盘   S1 三张统计卡 / S2 云端存储 / S3 动作排行 / S4 回执流水      │
│ ─ 系统组 ─      │  班级看板 三栏：身份 | 设备网格+展板 | 动作+Timeline            │
│ 仪表盘          │  设备集控 多班视角的设备网格与批量动作（**管理员**）            │
│ 班级看板        │  运行监控 内嵌 MonitorPage                                    │
│ 设备集控        │  系统设置 五个分区（见 §3.7）                                │
│ 运行监控        │                                                            │
│ 系统设置        │                                                            │
├─ 底部状态条 ──────────────────────────────────────────────────────────┤
└──────────────────────────────────────────────────────────────────────┘
竖屏（宽<高，或内容区 <860）→ 侧栏让位给 BottomNav，班级看板切竖排栈（可滚动）
弹窗：同一时刻只允许开一个（UiPanelHost 按 id 实例化，openOnly() 互斥）
主题：themeMode 0 浅色 / 1 深色 / 2 跟随系统；令牌唯一真源 = shared-qml/ui/theme/Md3.qml（pragma Singleton）
```

> ⚠️ 旧版里那个「控制 / 被控」胶囊与三页底部标签已随旧壳删除，不必再找。

## 3. 能力清单（逐条对照源码）

### 3.1 仪表盘

| 元素 | 说明 |
|---|---|
| S1 三张统计卡 | 在线 / 待执行指令 / 离线（离线数读 `backend.storage`，没拉到显示 `—`，**不假装是 0**） |
| S2 云端存储 | 已知设备数 / 在线 / 离线 / 班级数 / 待办 / 事件落盘量 / 最近活跃（云端算好推下来，前端不重算） |
| S3 动作排行 | 近 7 天按动作计数（`/api` 拉取 `actionRanking`） |
| S4 最近回执 | 最新 8 条流水 |

### 3.2 班级看板（以班为单位的日常入口）

| 能力 | 说明 |
|---|---|
| 三栏编排 | 左：班级身份（ClassIdentityPane）；中：设备网格 / 学生 / 展板三段；右：动作 + Timeline |
| 设备网格 | 本班设备卡；缩略图按需订阅（UI 取前 9 台，后端 LRU 32 台硬上限） |
| 展板 | 黑板卡 / 发布内容展板（展板全屏时隐藏左右栏） |
| 发布中心 | `ClassPublishDialog` → `POST /api/class/publish` → 按班推黑板卡 + 时间线 |
| 成员管理 | 增/删成员、角色（`/api/class/member-add|member-remove|members`） |
| 学生名单 | 学号幂等导入、`ClassStudentEditDialog` 单个编辑、`StudentCsv.js` CSV 批量 |
| 课表 | `ClassTimetablePane`：支持 **ClassIsland 档案导入**（云端 `timetable-import` 归一化，多课表群先 `timetable-groups` 预览再选） |
| 班级管理 | 建 / 改名 / 删除 / 绑班解绑（`create|rename|delete|bind|unbind`） |
| 班级接入码 | `ClassAdminPane` 生成 6 位票（一次性、24h、绑班级），设备 OOBE 输码入班 |
| 上手引导 | `ClassOnboardGuide`（新建班前的三步引导） |

> 写入红线：**按班写入只在班级看板，按设备写入只在设备集控** —— 两页都可能出现设备管控按钮，
> 但落点不同（详见《星集控-系统总图-2026-10-25.md》）。

### 3.3 设备集控（管理员视角）

- 多班 / 全校设备网格 + 批量动作（pick 系列）。
- **门禁**：只在「服务端下发并锁定」的受限身份（`backend.roleLocked && role === "teacher"`）下隐藏入口；
  未登录 / 静态令牌 / 平台超管不受影响（见 §3.6）。

### 3.4 运行监控

内嵌 `pages/control/MonitorPage.qml`，与集控页共用 TopBar / 状态条（不再跳旧壳独立页）。

### 3.5 动作（52 条，一张表；`qml/ActionDefs.js`）

| 组 | 动作（id） |
|---|---|
| 电源（不可逆，独占整行） | `lock` `reboot` `shutdown` |
| 通知 | `notify-send` |
| 查看（只读） | `screenshot` `software-list` `open-camera` `volume` `open-file` `schedule` `terminal` |
| 远控 | `remote-start` `remote-stop` `control-open` |
| 广播 / 语音 | `speech-open` `broadcast-open` `multiband-open` `open-interact` `voice-toggle` `voice-start` `voice-stop` |
| 屏幕 / 考试 | `screen-toggle` `screen-start` `screen-stop` `exam-toggle` `exam-start` `exam-stop` |
| 批量（pick 系列，按本班在线名单下发） | `select-all` `pick-clear` `pick-lock` `pick-lock-all` `pick-shutdown` `pick-volume-mute` `pick-volume-low` `pick-volume-high` `pick-study-on` `pick-study-off` `pick-noise-on` `pick-noise-off` |
| 页面与系统 | `page-overview` `page-control` `page-jikong` `page-settings` `page-md3shell` `refresh-devices` `login-site` `role-admin` `role-teacher` `theme-dark` `theme-light` `theme-auto` `open-download` |

> ⚠️ 批量 id（`pick-*`）与单台 id（`lock`/`reboot`）**不能混用**：单台 id 在 danger 分支只看
> `backend.currentUid`，传批量会被「先选中一台」拦掉或只作用于那一台。

**面板（14 个，`qml/UiPlugins.js`）**：`log` `term` `media` `sched` `camera` `notify` `file` `software`
`speech` `interact` `control` `multiband` `changelog` `help`

### 3.6 账户与权限（RBAC）

| 项 | 实情 |
|---|---|
| 登录 | 站点 OAuth（`STE_SITE_URL`），换票后云端下发 ticket；未登录则走静态令牌（系统身份） |
| 注册 | 无自建注册服务 → `openRegisterPage()` 打开站点 `/register`（界面明示去向） |
| 角色 | `admin` / `teacher`（服务端下发时锁定，本地不可切回 admin）；未认证账号（`verified=false`）也可登录，身份低一档 |
| 身份可见 | 个人中心统一卡（账号名 + 角色徽标 + 未认证徽标 + 退出登录）；OOBE 与设置页复用同一组件 |
| 组件级鉴权 | `perms.can("domain:action")`，如 `system:settings`；默认拒绝（deny-by-default），全权 / 平台超管放行 |
| 行级数据隔离 | 设备表在 C++ 单一入口按 scope 裁剪（`scopedDevices`），班级名单对票据用户按成员过滤（`filtered`） |
| 页面门禁 | 系统设置（既有）、设备集控（2026-10-25 加） |

### 3.7 设置页（五个分区）

| 分区 | 文件 | 内容 |
|---|---|---|
| 连接 | `SecConnection.qml` | 云端地址 / 连接状态 / 令牌状态（401 时明确说用哪种凭据、长度多少） |
| 账户与登录 | `SecAccount.qml` | 统一身份卡 + 注册入口 |
| 课表 | `SecSchedule.qml` | 课表相关设置 |
| 更新 | `SecUpdate.qml` | 版本 + 下载入口（不自更新） |
| 关于与诊断 | `SecAbout.qml` | 版本、Qt、渲染后端、日志路径等诊断信息 |

## 5. 已知边界（设计如此，不是 bug）

1. **批量下发靠遍历 uid。** 云端没有"全校一键"接口；pick 系列是前端按名单逐台下发。
2. **画面会自动降级。** WebRTC 帧超过 1.5s 没来 → JPEG 轮询接管（徽标跟着变）。
3. **设备管理端不自更新**，只给下载入口。
4. **Android 打包会 OOM**：ninja 按核数并行 → `viewerbackend.cpp`（2800 行 + Qt 头）等几个大 TU
   同时编 → `LLVM ERROR: out of memory`。脚本已加 `--jobs`（默认 2）。
5. **沙箱跑不了 offscreen 自检**（只部署了 `windows` 插件）—— 不是产品缺陷，用
   `QT_QPA_PLATFORM_PLUGIN_PATH` 指向 Qt 的 `plugins/platforms` 可解。
6. **版本号只有一个真源**（`CMakeLists.txt` 的 `VIEWER_VERSION`），改版本只改那一处。
