# 星集控 · 管理端（老师机）功能一览

> 版本 **0.6.1** · 2026-10-06（0.6.1 = 补上「通知」发送端）
>
> **本文不是凭印象写的**：每一条都对照源码核过 —— 接口面看 `src/viewerbackend.h`（Q_PROPERTY /
> Q_INVOKABLE / signals），动作看 `qml/Main.qml` 里那张动作表（第 795–859 行），弹窗看
> `qml/{Software,Media,Schedule,FilePush,Log}Dialog.qml`。凡是**没做**或**没验**的，下面单独标注。

---

## 0. 一句话

管理端 = **老师机上的控制台**：左边挑一台教室机 → 中间看它的画面 → 右边点动作 → 结果落在「最近回执」里。

---

## 1. 形态与部署

| 项 | 实情 |
|---|---|
| 分发形态 | **绿色版免安装**：解压后双击 `viewer-qt.exe`，无注册表项、拷走即用 |
| 配置 | 读 **exe 同目录的 `viewer.env`**（`set KEY=VALUE`，`rem` / `#` 是注释）。编码三种都认：UTF-16LE+BOM（NSIS 默认）/ UTF-8+BOM / 裸 UTF-8。<br>只设**进程内**环境变量，不写系统；**已存在的真环境变量优先**（便于临时覆盖）。 |
| 必填两项 | `STE_VIEWER_URL`（云端 `wss://…`）、`STE_VIEWER_TOKEN`（管理端令牌） |
| 单实例 | 三级守卫：`Global\` 互斥 → `Local\` 降级 → 文件锁。**这道是关键**：只写 `Local\` 时，计划任务（Session 0）与手动双击（Session 1）会各认各的 → 双开 |
| 托盘常驻 | 菜单三项：`状态：运行中`（只显示不可点）/ `打开日志目录` / `退出管理端`。图标用 QPainter **现画**，不依赖外部 `.ico`（少一处"打包漏了"） |
| 日志 | exe 同目录 `viewer-run.log`，`STE_VIEWER_LOG` 可改路径 |
| 技术栈 | Qt 6.8.1 / QML；`QApplication`（不是 `QGuiApplication` —— 托盘 `QSystemTrayIcon` 属 QtWidgets） |
| 版本真源 | `src/main.cpp` 的 `kViewerVersion = "0.6.1"`，与被控端 `kAppVersion` 对齐 |

## 2. 界面结构

```
┌─ 顶部条 ────────────────────────────────────────────────────────────┐
│ 星集控   [ 控制 │ 被控 ]                       ● 1 台在线            │
├─ 主体（三页，底部标签切换）─────────────────────────────────────────┤
│                                                                    │
│   概览      ← 在线台数 / 已收帧数 + 在线设备卡 + 最近回执卡          │
│   控制      ← 左设备 / 中画面 / 右动作   ← 主战场                    │
│   设置      ← 账户 / 连接 / 提醒 / 外观 / 关于                       │
│                                                                    │
├─ 底部标签：概览 │ 控制 │ 设置 ──────────────────────────────────────┤
└────────────────────────────────────────────────────────────────────┘
弹窗（同一时刻只允许开一个，走 openOnly() 互斥）：
  音量浮层 / 打开程序 / 软件 / 日志 / 媒体 / 定时 / 文件推送 / 通知
```

> ⚠️ 「控制 / 被控」那个胶囊**只有「控制」一侧是真的**：`被控` 是静态占位（连 MouseArea 都没有），
> 源码注释原话"被控端是另一台机器的形态，这里先只做控制端"。看着像能切，实际不是开关。

## 3. 能力清单（逐条对照源码）

### 3.1 概览

| 元素 | 说明 |
|---|---|
| 顶部统计 | 在线台数 / 已收帧数（累计） |
| 在线设备卡 | 每台一行：`uid` + 已收帧数；右上角"共 N 台"；空态"暂无设备 / 屏幕上的机器会自动出现" |
| 最近回执卡 | 动作结果流水；空态"还没有操作 / 点了右边的动作，结果记在这儿" |

### 3.2 控制页 · 左栏（设备）

- 设备列表：`uid` + 选中态（点一下 = `backend.currentUid = uid` → 向云端订阅这台机器的画面）
- 下方「**全校**」分组 —— **是空占位**：没有批量能力，见 §5

### 3.3 控制页 · 中栏（画面，主体）

| 元素 | 说明 |
|---|---|
| 标题 | 当前 `uid`（未选时"未选择设备"） |
| 读数 | `fps · 帧字节数`（例：`0 fps · 200 KB`） |
| 链路徽标 | `轮询`（JPEG 推送）/ `实时`（WebRTC）—— 见 §4 的 WebRTC 说明 |
| 底部状态 | `已收 N 帧 · 连接正常`，右侧同一条给回执留位 |
| 静态画面 | 连续多帧像素一致 → 判定"静态区"，界面**停止重绘**（省 CPU） |
| 软键盘 | 输入框「打字发给教室机，回车」→ `sendType(text)`，把字打给被控端 |

### 3.4 控制页 · 右栏（动作，**核心**）

三组 + 一个未实现按钮。所有动作走 `sendAction(action, params)`，结果经 `resultReceived` 回执。

**① 电源**（独占整行、描边更重 —— 因为点下去不可逆）

| 按钮 | 动作名 | 参数 |
|---|---|---|
| 锁屏 | `lock` | — |
| 重启 | `reboot` | — |
| 关机 | `shutdown` | — |

**② 看看**（只读，不会改那台机器的状态）

| 按钮 | 动作名 | 参数 / 去处 |
|---|---|---|
| 截图 | `screenshot` | — |
| 拍一张 | `camera_snapshot` | — |
| 软件 | `process_list` | 另拉 `list_shortcut_candidates` → 开软件弹窗 |
| 日志 | `log_tail` | → 开日志弹窗 |
| 探活 | —— | **不走 action**：直接 `sendPing()` |
| 摄像头 | `camera_list` | — |
| 音量 | —— | 开音量浮层 → `set_volume {value: 0..100}` |
| 文件 | —— | 开推文件弹窗 → `file_push` / `file_chunk` / `file_done` |

**③ 让它做事**（会改远端状态；**开/停刻意排在同一行左右两格**，一眼看出是互逆操作）

| 按钮 | 动作名 | 参数 |
|---|---|---|
| 定时 | `list_schedules` | 先拉列表，回执到了再开弹窗 |
| 媒体 | `media_list` | → 开媒体弹窗 |
| 开录 | `camera_record_start` | — |
| 停录 | `camera_record_stop` | — |
| 播放 | `media_session_start` | — |
| 停播 | `media_session_stop` | — |
| 远控开 | `remote_control_start` | `{fps: 20}` |
| 远控关 | `remote_control_stop` | — |

**④ 通知**（2026-10-06 实现，整行宽度，因为它要**凑内容**而不是点一下就发）

| 按钮 | 动作名 | 说明 |
|---|---|---|
| 通知 | `notify` | 开通知弹窗 → 发 `{kind, title, content, seconds?, flags:{speech, severity?, emergency_confirm?}}` |

发出去之后**结果落在哪**：`resultReceived` 回执 → 概览页「最近回执」会多一行（`notify / done|failed`）。
如果失败（标题为空、设备离线、被控端拒收），状态栏会**红字**写 `云端拒绝：…`，界面上不会"点了没反应"。
刻意与能点的组分开摆，"没做出来的能力单独躺着、标明没做"。

### 3.5 弹窗

| 弹窗 | 能力 | 关键约束 |
|---|---|---|
| **软件** | ①可打开候选（**选自这台机器**的快捷方式，不预置名单）→ `launch_app {target}`<br>②正在运行的进程 → `process_stop {pid}` | 候选名单要现向被控端要，没拿到就显示"还没拿到候选（点「软件」时会向这台机器要）" |
| **媒体** | 媒体库列表（数量 + "已截断"标记）；**点一行就删** → `media_delete {path}` | 删的是**回收站**（可恢复）；删**媒体库之外**的文件会被被控端**拒绝** |
| **定时** | 待执行列表（含"还有 N 分钟"）+ 取消 → `cancel_schedule {id}`<br>快捷创建："N 分钟后关机 / 重启" → `{delay_sec}` | ⚠️ **被控端到期默认不会真关机** —— 装教室机时要把 `STE_QT_ALLOW_SCHED_FIRE` 设成 `1`（回执里带 `fireAllowed` 说明当前状态） |
| **文件推送** | 选一个本机文件 → 分片推送，**一片一片等回执再发下一片**；带进度、可取消 | 被控端落进它自己的收件目录；`cancelPush()` 会让被控端关掉半截文件（**不留下半个坏文件**）<br>⚠️ 选文件走 C++ 原生 `QFileDialog`，**不是** QML 的 `QtQuick.Dialogs`（后者是一套独立 QML 插件，部署漏了就是"exe 起不来 / Main.qml 整个挂掉"） |
| **日志** | 看被控端日志尾部（`log_tail`） | 显示"末 N 行" |
| **通知**（新） | 凑一条大屏通知：**形态**（弹窗 / 灵动岛 / 全屏）、**标题**（必填）、**正文**、**显示时长**、**语音播报**、**紧急锁定**；全屏时多一行**配色**（提醒绿 / 提示黄 / 紧急红） | 见下方「通知的三条硬事实」 |

> **通知的三条硬事实**（都是被控端 `NotifyWindow` 的真实行为，不是猜的）：
> 1. **标题超 24 字、正文超 64 字会被截断加省略号**（`kTitleCap` / `kContentCap`），
>    语音播报读的也是**截断后**的文本。所以弹窗里直接给了字数计数，超了变琥珀色 ——
>    不说的话老师会以为整段都发过去了。
> 2. **配色（severity）只对全屏生效**：弹窗/灵动岛本来就是深色半透明，换配色没意义。
>    所以选了非全屏时那一行**整行不显示**，而不是摆一个没用的选项骗点击。
> 3. **紧急锁定 = 不会自动消失**：被控端收到 `emergency_confirm` 后不再挂自动关闭定时器，
>    并在底部加一个「✓ 确认」按钮，要学生在屏幕上点一下才关。
>
> 另外三条自动行为：`seconds > 0` 才带这个字段（0/缺省 = 按字数自适应，约 5 秒起，上限 3600 秒）；
> 弹窗形态还会**同时**往 Windows 通知中心留一份；`kind` 传了未知值会被回落成居中弹窗。

### 3.6 设置页

| 分区 | 内容 | 真实性 |
|---|---|---|
| 账户 | "还没有账户 / 登录后显示" | **占位**（源码注释："没源；不编"） |
| 连接 | 云端地址（运行时从环境变量读）+ 连接状态 | **真数据**（不写死，避免编造） |
| 提醒 | "操作完成时提示" / "设备离线时提醒" | **未实现**：两个圆圈是静态 Rectangle，**没有 MouseArea、没有状态**，纯摆设 |
| 外观 | 黑白 / 浅色 切换 | **可用**（真） |
| 关于 | 星集控 · Qt 6.8.1 / 版本 / 日志路径 | 真 |

## 5. 已知边界（这些是设计如此，不是 bug）

1. **没有批量下发。** 「全校」分组是空标签，动作只作用于**当前选中的那一台**。
   云端也没有"批量一键"接口 → 要批量得自己遍历 `/api/devices` 的 uid 逐台发。
2. **画面会自动降级。** WebRTC 帧超过 **1.5s** 没来就判定断了，自动让 JPEG 轮询接管（徽标跟着变）——
   这是避免"RTC 静默死掉、界面毫无变化"。
3. **重建 WebRTC 连接要靠退订重订。** `rtcRenegotiate(uid)` 是给自检用的：被控端只在 `rtc-start`
   时建一次连接，若那次 offer 发出去时没人订阅（云端丢了），之后订阅就没有新 offer。
4. **配置静默失效的老坑已修**：`set "KEY=VALUE"` 的引号包的是**整个** `KEY=VALUE`，
   不先剥这层整体引号 → key 变成 `"STE_VIEWER_TOKEN`（带前导引号）→ 变量名没人读 →
   **能启动但连不上云端且不报错**。这是与被控端同一个 bug、同一处修法。
5. **沙箱里跑不了 offscreen 自检**：日志里那条
   `Could not find the Qt platform plugin "offscreen"` 是自检试图用离屏平台，
   沙箱里只部署了 `windows` 插件 —— **不是产品缺陷**。
6. **版本号只有一个真源**（`kViewerVersion`）。合并两棵树时曾出现同一文件里两个版本常量
   （外层 0.6.0 / 内层 0.5.0）→ 编译期 `C2374` 重复定义，已清理。
