## 七、风险与注意事项

1. **生产令牌未换 = 最高风险**。公网已开，`dev-cloud-token` 谁都知道。
2. **首次升级必须重装**（现存 `0.4.0-v1` 无 OTA 能力），别指望 OTA 一步到位。
3. **ingress 顺序敏感**：任何新加的路由都要**排在通配规则之前**，否则静默失效。
4. **`.ps1` 必须 UTF-8 BOM**（PS 5.1 否则按 ANSI 解析中文注释 → 语法炸）；`.bat` 必须纯 ASCII。
5. **删除物只进了回收站**，`D:\$RECYCLE.BIN`=4.8G，空间尚未真正释放。
6. 令牌/密钥**已暴露在对话中**（CF 令牌 + R2 S3 密钥），**建议全部轮换**。
7. **根目录已是 git 仓库**（三子工程为 gitlink）；另有 AI 会话在协同，动根仓库前先探活。
