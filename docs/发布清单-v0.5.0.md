## 六、复现本次构建

```bat
rem 被控端
cd Stelarith-control-qt
build-qt-agent.bat
copy /y build\stelarith-agent-qt.exe deploy\stelarith-agent-qt.exe
"C:\Program Files (x86)\NSIS\makensis.exe" installer.nsi
node scripts\gen-wxs.mjs > msi\stelarith-agent.wxs
wix build msi\stelarith-agent.wxs -o msi\stelarith-agent-msi.msi -arch x64

rem 管理端
cd ..\Stelarith-viewer-qt
build-qt-viewer.bat
copy /y build\viewer-qt.exe deploy\viewer-qt.exe
node scripts\gen-wxs-viewer.mjs > msi\viewer-qt.wxs
wix build msi\viewer-qt.wxs -o msi\stelarith-viewer-msi.msi -arch x64
```

> 版本号单一真源：被控端 `installer.nsi` 的 `!define VER`（MSI 自动跟随）、
> 管理端 `src/main.cpp` 的 `kViewerVersion`（MSI 自动跟随）。**改版本改这两处即可。**
