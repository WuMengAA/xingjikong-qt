# 管理端 0.6.3 真机验证清单

> 本轮自动验证过的（本地离屏截图 + exe 实跑）：概览 / 控制 / 集控 / 设置四页渲染、账户菜单开合、
> 构建期版本号一致性校验、绿色包 `dist/stelarith-viewer-portable-0.6.3.zip`（自检必需件 16/16）。
> 下面这些**只有真机（教室机 / 公网凭据）能验**，本机 dev 环境复现不了。
> 按 1→5 顺序走，每步给「该看到什么 = 通过」，对不上就记下现象发我。

## 0. 装包

1. 解压 `stelarith-viewer-portable-0.6.3.zip`（到任意盘，绿色版免安装）。
2. 双击目录里的 `viewer-qt.exe`。
3. 顺手删掉解压目录里的 `platforms/qoffscreen.dll`（自检用的离屏插件，正式包里本来就没有；
   如果它在，说明你拿的是临时拼的目录，不是这个 zip）。

**通过**：窗口起来，顶栏左侧「星集控」，右侧是「连接状态点 + 状态文案 + 账户胶囊 + 角色徽标」。

## 1. 版本号（验证「单一真源」这条修没修好）

- 进「设置」→「关于」，看版本号。
- **通过**：显示 **0.6.3**（修之前这里是 `—` 或和日志对不上）。
- **通过**：启动时日志里的版本也是 0.6.3（日志和 UI 两处必须一致，不一致就是又漂了）。

## 2. 顶栏死开关已删（验证导航重构）

- 看顶栏左侧「星集控」右边、账户胶囊左边，**不应该**再有任何「被控 / 管理 / 控制」的切换按钮或下拉。
- **通过**：没有任何被控/管理切换入口；账户胶囊是唯一身份入口。
- **不对**：如果还能切出「被控」→ 你手上的包还是旧的，重新解压这个 zip。

## 3. 云端连接（这条是本轮最关键的 regression 点）

- **不用任何配置**，直接打开就该连：默认地址已改成生产 `wss://control.245959623.xyz/ws/viewer`。
- **通过**：顶栏状态变「已连上云端」，设备列表出现设备（至少 1 台）。
- **通过（断线重连）**：拔网线/关云端 → 状态变「没连上云端」，**间隔必须是 5→10→20→30 秒递增**，
  不能是「5 秒刷屏」。
- **不通过（这条要报给我）**：日志里继续循环
  `FAIL AUTH_FAILED: 管理端鉴权失败：auth 消息里既没有 token 也没有 ticket`
  加 `FAIL 与云端断开，5 秒后重连`。
  出现这个 = 云端站点票 / 密钥与管理端的 `STE_VIEWER_TOKEN` 对不上，**与本轮改动无关**，
  是凭据侧的事，报现象我再定位。

## 4. 角色与权限置灰（teacher 态）

1. 顶栏点账户胶囊 → 菜单里「这一台上的身份」从「管理员」切成「教师」。
2. 进「控制」页看右栏动作区（电源 / 看看 / 让它做事 / 通知 / 终端 …）。
3. **通过**：
   - 管理员能点的（电源类、终端等）在教师态**变灰 + tooltip 说明为什么灰**；
   - 教师仍**能**用：通知下发、录播、推文件；
   - 教师态下进「集控」页，广播/定时这些也应该按权限灰掉而不是全亮。
4. **不通过**：
   - 全灰（教师啥都点不了）→ 门控判反了；
   - 全亮（教师能点管理员的动作）→ `mayDo` 没生效；
   两种都报给我。

## 5. 集控页（这轮修的整页空白）

1. 点底栏「集控」。
2. **通过**：自上而下看到**三张完整卡片**——① 通知下发、② 定时任务、③ 广播（发给所有在线设备），
   三张卡之间留白正常，**下方不该有大片空白/纯黑**。
3. **不通过（旧 bug 复现）**：只露出顶部一条、下面全黑。
   那就是补丁没进包，重新解压这个 zip，再不行报我。

## 6. 账户菜单在 1366×768 下不出框（clamp 验证）

- 教室机常见分辨率 1366×768 下，点账户胶囊：
- **通过**：菜单完整落在窗口内，**底部不出框、右侧不出框**；窗口越矮它越往上贴。
- **不通过**：菜单下沿被窗口切掉 → 报我截图。
