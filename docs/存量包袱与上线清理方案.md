## 一、架构更正（按你的裁决）

⚠️ **本文档初版把 ClassIsland 插件误判为"另一条远端线，会抢指令" —— 这是错的，已更正。**

你的裁决：
- **CIMS 已退役**（CIMS-backend 8096/8097/8098/8100 那条线不再启用）；
- **Rust 被控端归为歧途**（不再演进）；
- 教室机**只装两样**：**星集控被控端** + **ClassIsland 客户端**；
- **ClassIsland 插件不是独立通道** —— 它**只与本地星集控被控端联动**；
- **星集控（被控端）承担转发/处理角色**。

### 正确架构

```
教室机
├── ClassIsland 客户端（非主体；课堂显示/课表/大屏壳等）
│      └── 星集控插件  ──►  只与【本地】星集控被控端 通信
└── 星集控被控端 (stelarith-agent-qt.exe)  ◄── 承担转发/处理角色
          │
          └── WebSocket ──► 云端 cloud-ws :8788 ◄── 管理端 viewer-qt / 网页面板
```

**要点**：插件→被控端是**本地**链路；被控端→云端是**唯一**远端链路。
因此**不存在"两条远端通道抢指令"**——初版 R1 风险作废。

### 已退役的旧世代（包袱来源）

| 代 | 客户端 | 通道 | 现状 |
|---|---|---|---|
| ① | Flutter 控制端 | — | 弃 |
| ② | Rust 被控端 `school-multimedia-control` | 自建 WS | **歧途，弃** |
| ③ | ClassIsland 插件**旧版**（走 CIMS-backend 8096） | CIMS | **CIMS 退役，弃** |
| ④ | **Qt 被控端** | cloud-ws 8788 | **当前正主** |

> ③ 与 ④ 的区别在**插件连谁**：旧版插件连 **CIMS-backend**（远端）；
> 新版插件连**本地被控端**（被控端再转发到云端）。这是本轮最关键的一处更正。

## 二、命名规范（按你给的样子）

| 对象 | 格式 | 示例 | 说明 |
|---|---|---|---|
| **被控端（教室机）** | `class_<校简称>_<届>_<班号>` | `class_xlzx_2028_08` | `xlzx` = 咸林中学拼音首字母 |
| **管理端（老师机）** | `admin_<校简称>_<届>_<班号>` | `admin_xlzx_2028_08` | 仅记录用途 |

**纪律**：
- **每台唯一**，不得重名（重名会让云端设备表互相顶替，画面/指令串台）；
- 大小写敏感（云端按原样存，`class_...` 全小写，别混用大写）；
- 管理端 uid 仅作记录，**不参与设备表**（它是 viewer 通道，不是 agent 通道）。

## 五、🔑 两条对上线最重要的结论

### 5.1 第一次升级只能"重装"，OTA 从 0.5.0 起才生效
`self_update` 是 **0.5.0 才引入**（commit `87006a1`）；云端设备表显示 TEST1 跑 **`0.4.0-v1`**，
它**没有下载/安装代码**，收到 `self_update` 只会落「未知动作」→ **不下载、不安装**。

> **OTA 只能升级"已经具备 OTA 的版本"。** 升级是**两段式**：
> ① 存量 → 0.5.0：**重装**（把 OTA 能力种进去）｜② 0.5.0 → 以后每版：**OTA**。

### 5.2 ⚠️ 云端缺"开机自启"任务
实测：只有 `StelarithCloudWatchdog`（**每 5 分钟**一次，指向 `cloud-watchdog.cmd`）；
**`StelarithCloud`（开机自启）任务不存在**。
→ **重启后云端最多空窗 5 分钟**（等看门狗下一跳）。

**修法**（需你确认——涉及生产运维，我未擅自执行）：
```bat
schtasks /create /tn StelarithCloud /tr "D:\Stelarith\Stelarith-cloud-ws\run-cloud.cmd" /sc onstart /ru SYSTEM /rl HIGHEST /f
```
> ⚠️ 注意路径：上面指向**当前在跑的** `D:\Stelarith\Stelarith-cloud-ws`。
> 若上线要用工作台版（含 OTA）替换生产，则应指向替换后的目录——**这属于"生产切换"决策，等你定**。
