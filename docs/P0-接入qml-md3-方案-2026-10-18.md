## 2. 接线步骤（三步，改 1 个文件 + 1 个验证点）

### 步骤 1：CMakeLists.txt 接入

在 viewer 的 `CMakeLists.txt` 中，`find_package(Qt6 …)` 之后加：

```cmake
# 2026-10-18 P0：qml-md3（MD3 组件库，LGPL-3.0 动态链接）
# ⚠️ 构建类型必须与 viewer 一致（Release）——Debug 宿主加载 Release 模块会
#    "使用了不兼容的 Qt 库" 静默失败（2026-10-18 实测踩到）。
set(STE_MD3_ROOT "$ENV{STE_MD3_ROOT}" CACHE PATH "qml-md3 预编译产物目录")
if(NOT STE_MD3_ROOT)
  set(STE_MD3_ROOT "D:/Stelarith/_probe/md3-ready" CACHE PATH "" FORCE)
endif()
find_package(Md3 REQUIRED PATHS "${STE_MD3_ROOT}" NO_DEFAULT_PATH)
```

并在 `target_link_libraries(viewer-qt PRIVATE …)` 列表末尾加 `Md3`：

```cmake
  if (TARGET Md3plugin)
    target_link_libraries(viewer-qt PRIVATE Md3 Md3plugin)
  else()
    target_link_libraries(viewer-qt PRIVATE Md3)
  endif()
```

### 步骤 2：验证点（不改界面）

选**最小、无界面影响**的验证：在 `main.cpp` 已有的 QML 引擎初始化旁，
确认 `import Md3` 能解析。**推荐做法**：不动 `Main.qml`，而用一次性验证——

- 方案 A（推荐，零侵入）：构建后跑一个 `qmlscene`/探针加载 `import Md3`；
- 方案 B：临时在 `Main.qml` 顶部加 `import Md3`，构建运行确认无报错后**立即撤回**。

### 步骤 3：部署清单

`installer.nsi`（或 `windeployqt` 之后）需额外打包：

```
md3-ready\bin\Md3.dll           → {app}\
md3-ready\lib\qml\Md3\**        → {app}\qml\Md3\
```

并在 `main.cpp` 里把 `{app}/qml` 加入 QML 导入路径（若尚未加），
或设 `QML2_IMPORT_PATH` 环境变量指向 `{app}\qml`。
