## 一、#94 通知：控制页暗色下无法输入文本

### 根因（两条，缺一条都还是"看不见"）
1. `qml/NotifyDialog.qml` 里标题/正文/显示时长三个输入框是**裸 QQC `TextInput`**，
   调用点只给 `color: th.fg`、不给 `background` ⇒ 沿用 Windows 系统调色板的**白底**。
2. 暗色外观下 `theme.fg = #FAFAFA` ⇒ **白底 + 近白字**，对比度 **1.04:1**（肉眼＝打不了字）。
   亮色外观下反过来（深字压深底），同一个 bug 换个方向。

### 改动（只动一个文件）
| 位置 | 改前 | 改后 | 行数 |
|---|---|---|---|
| `qml/NotifyDialog.qml` 顶部 | 无 | `import "components"` | +1 |
| 标题 `titleInput` | `Rectangle` + 裸 `TextInput` | `InputField { th: dlg.theme; maximumLength: 120; onTextChanged: dlg.error = "" }` | +7/−5 |
| 正文 `bodyInput` | 裸 `TextInput` | `InputField { th: dlg.theme; maximumLength: 300 }` | +4/−3 |
| 时长 `secInput` | 裸 `TextInput` | `InputField { th: dlg.theme; validator: IntValidator{bottom:0;top:3600}; text:"0" }` | +2/−2 |

行为差异：`InputField` 内部是 `background: Rectangle{ color:"transparent"; border... }`，
底由外层面板给、占位色走 `theme.ph`、聚焦时描边加深。原来"focus 时整块变白、focus 完变灰"的手感
没了，改成描边反馈。**唯一副作用**：纯键盘用户的 `selectByMouse` 之前没有、现在有（只增不减）。

### 量化验证（`scripts/verify-94-95.mjs` 第 1–4 条）
| | 底色 | 字色 | 对比度 |
|---|---|---|---|
| 修前·暗色 | `#FFFFFF` | `#FAFAFA` | **1.04:1**（AA 需 4.5） |
| 修后·暗色 | `#141414` | `#FAFAFA` | **17.65:1** |
| 修后·亮色 | `#EDEDED` | `#161616` | **15.46:1** |

真机截图：`shots/_shotcheck/p3-notify.png`（1792×1196）—— 弹窗居中、三个输入框都是深色底＋可见描边。

## 二、#95 终端：打开后关不掉 / 连不上

### 根因（两条，前者"连不上"，后者"关不掉"）
1. `viewerbackend.cpp` 的 `terminal_opened` 分支判据是 `m_termState != TermOpen` 就丢包。
   但下发 `terminal_open` 后本地状态已经是 **Pending（等本机点头）** ⇒ 机器那边的
   `terminal_opened` 回包**每次都被判成"无关的"丢掉** ⇒ 永远到不了 Open，界面显示"未连接"。
2. Pending 状态**没有任何兜底计时器** ⇒ 本机不点头（或说"不"）就永远卡在 Pending：
   关不掉（点关闭无反应），也连不上。

### 改动
**`src/viewerbackend.h`（+4）**
```cpp
QTimer *m_termWait      = nullptr;  // 等本机确认 terminal_open（默认 20s）
QTimer *m_termCloseWait = nullptr;  // 等 terminal_close 回话（默认 2.5s）
bool   m_termClosing    = false;    // 关闭请求已下发、还没拿到 terminal_closed（去重用）
```

**`src/viewerbackend.cpp`（+约 55/−约 8）**
- 构造函数：建两条单发 timer，间隔 `STE_TERM_WAIT_MS`（默认 20000）/ 2500，并 `qInfo` 打兜底时长。
- `m_termWait` 到点且仍在 Pending ⇒ 回 `Idle`，`m_termNote` 写「等本机点头超时（本机没允许，会话没开）」，
  `emit terminalClosed(sid, "等本机点头超时")`。
- `m_termCloseWait` 到点且仍在 Pending ⇒ 回 `Idle`，`m_termNote` 写「关断没回话（按已关处理，可以重开）」。
- `terminal_opened` 判据改为：仅当 `m_termState == TermIdle || sid != m_termSid` 才丢（并打 WARN）；
  其余情况清 `m_termClosing` 后置 Open。
- `termOpen()` 末尾 `m_termWait->start()`；`termClose()` 先 `if(m_termClosing) return;` 去重，
  再下发 `terminal_close`、置 Pending「正在关…」，末尾 `m_termCloseWait->start()`。
- `terminal_closed`：置 `m_termClosing = false` 再回 Idle；两处 timeout 复位前同样清。

**`qml/TerminalDialog.qml`（+13/−4）**
- 按钮文案三态：`Idle → "开终端"` / `Pending → "…"` / `Open → "关终端"`；
  `MouseArea { enabled: backend.termState !== 1 }` —— Pending 禁点（原来连点一次多发一条 `terminal_close`）。
- `tipText()`：Pending 直接顶 `backend.termNote`（"正在关…" / "等本机点头…"）；
  Idle 时若 `termNote != ""` 显示「上次：…」，否则显示开场那句。

### 顺带修掉的（同一弹窗、同一类病，不是新开的功能）
截图取证时发现终端弹窗底部的**命令行输入框**是裸 QQC `TextField` —— 自带系统调色板浅灰底。
`qml/TerminalDialog.qml` +1 行 `import "components"`、输入框本体换成 `InputField { th: dlg.theme }`，
容器 `Rectangle` 继续提供 `theme.win` 底色。
量化：输入行背景平均亮度 **修前 211（浅灰白条）→ 修后 13（暗底）**，占位文字「先开终端才能敲」变可读。
截图：`shots/_shotcheck/p3-term-io.png`（修前）→ `p4-term-io.png`（修后）。
