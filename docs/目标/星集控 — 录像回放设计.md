# 星集控 — 录像回放设计

> 结合最新的监控设计（多班级 15 秒截图、单班屏幕+摄像头双画面），录像回放需要解决三个问题：**录什么、存哪里、怎么看**。
> 核心原则：**默认不录，按需开启，本地为主，云端为辅。**

---

## 一、录制策略

### 1.1 三种录制场景

| 场景 | 录什么 | 触发方式 | 保留期 |
|---|---|---|---|
| **考试模式** | 屏幕 + 摄像头 | 考试开始时自动 | 云端 30 天 |
| **手动录制** | 屏幕 + 摄像头 | 老师手动点击 | 云端 7 天 |
| **异常触发** | 屏幕 + 摄像头 | 告警触发（如检测到异常进程） | 云端 30 天 |

**默认不录制**。学校不主动开启，老师无法单方面录制。

### 1.2 录制参数

| 项 | 屏幕 | 摄像头 |
|---|---|---|
| 分辨率 | 1280×720 | 640×480 |
| 帧率 | 15fps | 15fps |
| 编码 | H.264 | H.264 |
| 码率 | 400kbps | 200kbps |
| 单小时 | ~180MB | ~90MB |

**双路合计**：单班单小时约 270MB。60 个班同时录，单小时 16GB。所以**只录指定班级**，不全校录。

### 1.3 录制位置

| 方案 | 说明 | 优缺点 |
|---|---|---|
| **本地录制** | 被控端录到本地磁盘 | 不占带宽，可被删除 |
| **云端录制** | 推流到云端，云端录制 | 安全，占带宽和存储 |
| **本地 + 事件上传** | 本地循环录，触发事件上传 | **推荐** |

**推荐方案**：本地循环录制最近 1 小时，触发事件时把该时段上传到云端。

```
本地录制（循环）：
  /Recordings/room-101/screen/  最近 1 小时
  /Recordings/room-101/camera/  最近 1 小时

事件触发：
  考试开始 → 标记当前时间 → 上传到云端
  手动录制 → 直接上传
```

## 二、录制实现

### 2.1 被控端：FFmpeg 双路录制

```cpp
// RecordingManager.cpp
class RecordingManager : public QObject {
    Q_OBJECT
public:
    void startRecording(const QString &eventId) {
        m_eventId = eventId;

        // 屏幕录制
        m_screenProc = new QProcess(this);
        QStringList screenArgs;
        screenArgs << "-f" << "gdigrab" << "-framerate" << "15"
                   << "-i" << "desktop"
                   << "-c:v" << "libx264" << "-preset" << "ultrafast"
                   << "-tune" << "zerolatency" << "-b:v" << "400k"
                   << "-s" << "1280x720"
                   << "-f" << "segment" << "-segment_time" << "300"
                   << "-segment_wrap" << "12"
                   << "-strftime" << "1"
                   << m_recordDir + "/screen/%Y%m%d_%H%M%S.mp4";
        m_screenProc->start("ffmpeg", screenArgs);

        // 摄像头录制
        m_cameraProc = new QProcess(this);
        QStringList cameraArgs;
        cameraArgs << "-f" << "dshow" << "-i" << "video=摄像头名"
                   << "-c:v" << "libx264" << "-preset" << "ultrafast"
                   << "-tune" << "zerolatency" << "-b:v" << "200k"
                   << "-s" << "640x480" << "-r" << "15"
                   << "-f" << "segment" << "-segment_time" << "300"
                   << "-segment_wrap" << "12"
                   << "-strftime" << "1"
                   << m_recordDir + "/camera/%Y%m%d_%H%M%S.mp4";
        m_cameraProc->start("ffmpeg", cameraArgs);
    }

    void stopRecording() {
        if (m_screenProc) m_screenProc->terminate();
        if (m_cameraProc) m_cameraProc->terminate();
    }

private:
    QProcess *m_screenProc;
    QProcess *m_cameraProc;
    QString m_eventId;
    QString m_recordDir;
};
```

**关键参数**：
- `-segment_time 300`：每 5 分钟一个文件，方便上传和回放
- `-segment_wrap 12`：保留最近 12 个文件（1 小时）
- `-strftime`：文件名带时间戳

### 2.2 事件触发上传

```cpp
void RecordingManager::markEvent(const QString &eventId, qint64 startTs, qint64 endTs) {
    // 找到覆盖该时段的文件
    QDir screenDir(m_recordDir + "/screen");
    QStringList files = screenDir.entryList({"*.mp4"}, QDir::Files, QDir::Time);

    for (const QString &file : files) {
        qint64 fileTs = parseTimestamp(file);
        if (fileTs >= startTs - 300 && fileTs <= endTs) {  // 覆盖时段
            uploadSegment(m_recordDir + "/screen/" + file, eventId, "screen");
        }
    }

    // 摄像头同理
}
```

### 2.3 上传

```cpp
void RecordingManager::uploadSegment(const QString &filePath,
                                      const QString &eventId,
                                      const QString &type) {
    QFile *file = new QFile(filePath, this);
    file->open(QIODevice::ReadOnly);

    QNetworkRequest req(QUrl(m_serverUrl + "/api/recordings/upload"));
    req.setRawHeader("X-Event-Id", eventId.toUtf8());
    req.setRawHeader("X-Type", type.toUtf8());
    req.setRawHeader("X-Device-Id", m_deviceId.toUtf8());
    req.setRawHeader("X-File-Name", QFileInfo(filePath).fileName().toUtf8());

    m_nam->post(req, file);
}
```

### 3.2 HLS 切片

上传完成后，后端用 ffmpeg 切片：

```bash
# 屏幕切片
ffmpeg -i screen/10-00.mp4 \
       -c copy -f hls -hls_time 10 \
       screen/10-00.m3u8

# 摄像头切片
ffmpeg -i camera/10-00.mp4 \
       -c copy -f hls -hls_time 10 \
       camera/10-00.m3u8

# 双路同步索引（可选）
```

### 3.3 保留策略

| 类型 | 保留期 | 超期处理 |
|---|---|---|
| 考试录制 | 30 天 | 自动删除 |
| 手动录制 | 7 天 | 自动删除 |
| 异常触发 | 30 天 | 自动删除 |
| 标记为"永久" | 永久 | 需管理员手动标记 |

```js
// 每日清理任务
async function cleanupOldRecordings() {
  const events = await db.getEvents();
  for (const event of events) {
    if (event.permanent) continue;

    const age = Date.now() - event.createdAt;
    const maxAge = event.type === 'exam' ? 30 * 86400000 : 7 * 86400000;

    if (age > maxAge) {
      await deleteRecording(event.id);
      await db.deleteEvent(event.id);
    }
  }
}
```

### 4.3 时间轴组件

```qml
// PlaybackTimeline.qml
Item {
    id: timeline
    property int duration       // 总时长（秒）
    property int position       // 当前位置（秒）
    property var events         // [{ ts, label, level }]

    implicitHeight: 60

    Rectangle {
        id: track
        anchors.fill: parent
        anchors.topMargin: 20
        anchors.bottomMargin: 20
        color: Theme.bgHover
        radius: 2

        // 已播放部分
        Rectangle {
            width: parent.width * (timeline.position / timeline.duration)
            height: parent.height
            color: Theme.primary
            radius: 2
        }

        // 事件标记
        Repeater {
            model: timeline.events
            Rectangle {
                property real eventPos: modelData.ts / timeline.duration
                x: track.width * eventPos - width / 2
                width: 8
                height: 8
                radius: 4
                anchors.verticalCenter: parent.verticalCenter
                color: modelData.level === 'error' ? Theme.error : Theme.warning

                MouseArea {
                    anchors.fill: parent
                    onClicked: timeline.seek(modelData.ts)
                }
            }
        }

        // 播放指针
        Rectangle {
            x: track.width * (timeline.position / timeline.duration) - 1
            width: 2
            height: parent.height + 16
            anchors.verticalCenter: parent.verticalCenter
            color: Theme.primary

            Behavior on x {
                NumberAnimation { duration: 100; easing.type: Easing.Linear }
            }
        }

        // 拖动
        MouseArea {
            anchors.fill: parent
            onClicked: (mouse) => {
                timeline.seek((mouse.x / track.width) * timeline.duration)
            }
            onPositionChanged: (mouse) => {
                if (pressed) {
                    timeline.seek((mouse.x / track.width) * timeline.duration)
                }
            }
        }
    }
}
```

## 五、技术实现

### 5.1 管理端回放

**方案 A：Qt Multimedia（QMediaPlayer）**

```cpp
QMediaPlayer *player = new QMediaPlayer();
QMediaPlaylist *playlist = new QMediaPlaylist();
playlist->addMedia(QUrl("https://server/recordings/room-101/2026-10-09/exam-001/screen/index.m3u8"));
playlist->setCurrentIndex(0);
player->setPlaylist(playlist);
player->play();
```

**问题**：Qt Multimedia 在 Windows 上依赖 DirectShow/WMF，HLS 支持有限。

**方案 B：Qt WebEngine + hls.js**

内嵌 WebEngine，用 hls.js 播放：

```html
<video id="screen" controls></video>
<video id="camera" controls></video>

<script src="hls.js"></script>
<script>
  const screenVideo = document.getElementById('screen');
  const hls = new Hls();
  hls.loadSource('https://server/recordings/.../screen/index.m3u8');
  hls.attachMedia(screenVideo);

  // 双路同步
  screenVideo.addEventListener('play', () => cameraVideo.play());
  screenVideo.addEventListener('pause', () => cameraVideo.pause());
  screenVideo.addEventListener('seeked', () => {
    cameraVideo.currentTime = screenVideo.currentTime;
  });
</script>
```

**方案 C：直接下载 MP4 播放**

如果不需要边下边播，直接下载 MP4 到本地播放。

**推荐方案 B**：WebEngine + hls.js 支持双路同步、倍速、时间轴，最灵活。

### 5.2 后端切片

```js
// 上传完成后异步切片
async function processRecording(eventId, deviceId, filePath, type) {
  const outputDir = path.dirname(filePath);
  const baseName = path.basename(filePath, '.mp4');

  await exec(`ffmpeg -i ${filePath} -c copy -f hls -hls_time 10 ${outputDir}/${baseName}.m3u8`);

  // 生成索引
  const index = {
    eventId, deviceId, type,
    duration: await getDuration(filePath),
    segments: await listSegments(outputDir, baseName)
  };

  await db.saveRecordingIndex(index);
}
```

---

**一句话总结**：录制回放的核心是"默认不录、按需开启、本地循环、事件上传"。被控端用 FFmpeg 双路录制（屏幕 + 摄像头），事件触发时上传到云端，云端切片成 HLS，管理端用 WebEngine + hls.js 双路同步回放。时间轴支持拖动定位、事件标记、30 秒快速跳转。隐私保护是重点：学生知情、仅管理员可开、全程审计、到期删除。
