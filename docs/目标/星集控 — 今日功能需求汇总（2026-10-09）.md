# 星集控 — 今日功能需求汇总（2026-10-09）
> 本文档仅汇总今日讨论确定的功能需求，不含项目前期已有设计。
---
## 一、功能需求清单
### 1. 屏幕对讲
- **单班级实时监控**：网格缩略图 + 选中 1 路 WebRTC 实时画面，其余走快照；最多 16 路。
- **多班级面板**：每 15 秒截图一次缩略图，默认只显示屏幕画面；摄像头需进入单班监控才能查看。
- **单班双画面**：屏幕 + 摄像头左右分屏，可切换「仅屏幕 / 仅摄像头 / 双画面」。
### 2. 命令面板
- **Ctrl + K 唤出**：模糊搜索所有操作，支持拼音首字母。
- **远程命令行**：类似 UU 远程的受限 shell，通过 WebSocket 转发 stdin/stdout；需二次确认并全程审计。
### 3. 班级监控（录制 + 回放）
- **录制**：默认不录，按需开启（考试 / 手动 / 异常触发）；本地循环录制 + 事件上传云端；双路录制（屏幕 + 摄像头）。
- **回放**：双路同步播放，时间轴可拖拽，事件标记，支持 30 秒快进 / 快退。
### 4. 错误码体系
- **三段式编码**：模块 + 类型 + 编号；统一错误响应格式，各端统一使用。
### 5. 用户手册 + 运维手册
- **用户手册**：面向老师 / 管理员，步骤式语言，配截图。
- **运维手册**：面向部署者，命令可复制，含故障排查。
### 6. 考试模式
- **一键切换**：锁屏、禁网、黑名单、全屏、禁用 USB、禁用快捷键、录制、时间控制。
- **明确边界**：防君子不防小人，需配合物理监考。
### 7. 灵动岛生态
- **开放信息层**：统一消息协议（source / type / priority）。
- **三种接入**：本地 WebSocket、云端 API、HTTP Webhook。
- **插件体系与治理**：白名单、频率限制、优先级保护。
### 8. 灵动岛操作创新
- **核心操作**：双击执行、拖拽靶心、任务中心、预设模式、内联操作、上下文建议、跨端接力。
### 9. 灵动岛通用历史通知
- **统一格式**：所有通知走同一套 JSON 格式。
- **本地存储**：SQLite 本地库，按时间分组、分类筛选、搜索、跳转。
- **自动清理**：按类型保留 3-90 天；学生端极简（只保留 3 天 / 20 条 / 两类）。
