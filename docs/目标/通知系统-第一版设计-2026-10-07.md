# 星集控 · 通知系统（短信/邮件/企微 · 第一版设计，2026-10-07）

> 对应《全量设计文档》10.3「通知系统短信/邮件/企微（低）」。
> 目的：云端/站点有**重要事件**（设备批量离线、考试模式开始、告警升级）时，
> 把消息推到运维/管理员的手机（短信/企微/邮件），不用盯后台。

## 一、范围

| 通道 | 第一版 | 备注 |
|---|---|---|
| 企业微信（Webhook） | ✅ 推荐 | 配置一个群机器人 URL 即可，零订阅费 |
| 邮件（SMTP） | 🟡 可选 | 需 SMTP 服务；低优先级 |
| 短信 | ❌ 后置 | 需短信服务商/费用 |

**触发事件**（第一版只做三个最痛的）：
1. **设备批量离线**：同校在线设备数跌破阈值（如 < 80%）持续 5 分钟 → 通知。
2. **考试模式开始/结束**：管理员开启考试 → 通知（有提醒作用，防止误开）。
3. **云端告警升级**：云端 error 事件 5 分钟超阈值 → 通知运维。

## 二、架构

```
事件源（registry pushEvent / 云端逻辑）
   → NotificationRule（匹配：类型 + 阈值 + 静默期）
   → Channel（wecom webhook POST / smtp）
   → 记录（sent 事件进 events.log，防重复）
```

- **静默期**：同一规则 30 分钟内不重复发送（防止风暴 5 条短信）。
- **配置**：`config.js` 加 `NOTIFY_WECOM_WEBHOOK` / `NOTIFY_SMTP_*`；
  未配置 → 通道关闭（不假装能用）。

## 三、接口/配置

```env
# 企业微信群机器人（推荐）
NOTIFY_WECOM_WEBHOOK=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxx
# 邮件（可选）
NOTIFY_SMTP_HOST=smtp.xxx.com
NOTIFY_SMTP_PORT=465
NOTIFY_SMTP_USER=xxx
NOTIFY_SMTP_PASS=xxx
NOTIFY_SMTP_TO=ops@school.edu
```

**规则表**（config 里，可后续迁移到数据库）：
```
{ type:'devices-low-online', threshold:0.8, windowMs:'5min', quietMs:'30min' }
{ type:'exam-mode',          quietMs:'30min' }
{ type:'cloud-alerts',       threshold:20, windowMs:'5min', quietMs:'30min' }
```

## 四、实现要点（cloud-ws）

- 新增 `src/notify.js`：`evaluate(event)` + `sendWecom(text)`（http POST JSON）+ 静默表
  `Map<ruleKey, lastSentAt>`。
- 挂接点：
  - 设备离线判断：`sweepStale()`（心跳超时收垃圾）里统计在线率。
  - 考试模式：`setExamMode` 处（云端已记录 start/stop）。
  - 告警：`pushEvent('error')` 计数窗口。
- `tests/notify-rules.test.mjs`：规则匹配 + 静默期逻辑单测（不真发）。

## 五、安全

- Webhook URL 是密钥（能发消息）→ 放 `.env` 不落库； `.env` 已在备份范围。
- 通知内容不包含学生私人信息（只发设备数/uid/事件）。
