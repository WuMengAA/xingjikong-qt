# 星集控 · 网站过滤黑白名单（第一版设计，2026-10-07）

> 对应《全量设计文档》10.3「网站过滤黑白名单/分时段（中）」。
> 教室机上网管控：白名单（只允许这些站）或黑名单（禁止这些站），可按时段。

## 一、场景

| 场景 | 需求 |
|---|---|
| 信息技术课 | 只允许学习站点（白名单） |
| 上课时间 | 屏蔽娱乐站点（黑名单：视频/游戏） |
| 考试 | 只放行考试服务器（结合考试模式） |

**第一版**：黑名单为主（简单、误杀少），白名单后置（需代理/网关，重）。

## 二、技术方案（三层，从轻到重）

| 层 | 实现 | 优点 | 缺点 | 第一版 |
|---|---|---|---|---|
| ① hosts 拦截 | 写 hosts 把域名指向 127.0.0.1 | 零依赖 | 可绕过（学生能改 hosts）、只拦域名 | ❌ |
| ② Windows 防火墙 | `New-NetFirewallRule` 按 IP 阻断 | 系统级、强 | 域名动态 IP 难维护、需要管理员权限 | 🟡 试点 |
| ③ **DNS/代理（推荐）** | 管理端/云端下发规则 → 被控端改 DNS 或走本地代理 | 域名级、可按时段 | 被控端需实现代理/DNS 钩子 | 后置 |

**务实第一版**：**② 防火墙 IP 黑名单**（阻断已知娱乐域名解析出的 IP 段）
+ hosts 辅助（对静态 IP 站点）。考试模式已有防火墙禁网思路（文档 3.7），复用。

## 三、被控端改动

- 新增动作：
  - `net_filter_apply {mode: black|white, domains: [...], until: ISO}` —— 解析域名
    → 生成防火墙规则（阻断/放行）→ 设到期时间蜂鸣。
  - `net_filter_clear` —— 清除规则。
- 到期自动清理（QTimer 到点移除规则）。
- 规则命名统一 `StelarithNetFilter`（便于清理）。

## 四、管理端改动

- 集控页「网络管控」卡片：
  - 模式（黑名单/白名单）+ 域名列表（逗号分隔）+ 时长/到期时间。
  - 预设：娱乐屏蔽（youtube/bilibili/tiktok…）、考试放行。
  - 下发目标设备（同其他批量）。

## 五、安全与边界

- 过滤只挡**外网域名**，不断教室机—云端连接（复用考试模式防火墙经验：
  规则里必须放行云端 IP）。
- 学生改 hosts 可绕过 → 第一版诚实说明"防君子"；严格管控需代理层。
- 防火墙规则为系统级改动 → 操作前管理端二次确认；记录审计。

## 六、开发顺序

1. agent `net_filter_apply/clear`（防火墙规则封装 + 到期清理）
2. 管理端网络管控卡片
3. 白名单模式（需 DNS/代理，后置）
