# 星集控灵动岛 — 操作上的创新

灵动岛最大的创新不在"能显示什么"，而在"能怎么操作"。传统通知栏只能看，灵动岛要能**直接处理**。这份文档聚焦交互方式，不重复功能设计。


## 一、核心理念：从"通知栏"到"任务中心"

| 传统通知栏 | 星集控灵动岛 |
|---|---|
| 只展示 | 可操作 |
| 一次性 | 常驻（进行中） |
| 单条 | 多任务并行 |
| 被动看 | 主动建议 |
| 孤立 | 跨端接力 |

**一句话**：灵动岛不是"告诉老师发生了什么"，而是"让老师在原地把事做完"。


## 二、手势层：六种操作方式

| 手势 | 作用 | 场景 |
|---|---|---|
| **单击** | 收起 ↔ 展开 | 查看详情 |
| **双击** | 执行默认操作 | 快速锁屏 |
| **长按** | 弹出更多操作 | 批量操作菜单 |
| **右键** | 上下文菜单 | 复制/忽略/固定 |
| **拖拽** | 拖设备到灵动岛 | 加入批量操作 |
| **悬停** | 预览详情 | 不展开看摘要 |

### 2.1 双击执行默认操作

双击收起态的灵动岛，直接执行**当前主状态的默认操作**。

```
老师选中了 12 台设备，灵动岛显示"12 台已选"
    ↓
双击灵动岛 → 直接锁屏这 12 台（默认操作）
    ↓
不用展开、不用找按钮
```

**默认操作可配置**：老师可以在设置里定义"双击灵动岛 = 锁屏选中设备"。

### 2.2 长按弹出操作菜单

长按收起态，弹出上下文菜单：

```
╭─────────────────────────────────╮
│ 🔒 锁屏选中                      │
│ ⏻ 关机选中                      │
│ 💬 发送消息                      │
│ 📁 分发文件                      │
│ ─────────────────────────────── │
│ 🔒 锁屏全部                      │
│ ⏻ 关机全部                      │
╰─────────────────────────────────╯
```

**和右键的区别**：长按是触屏友好，右键是鼠标友好。两者内容一致。

### 2.3 拖拽设备到灵动岛

老师从网格视图拖一台设备的卡片，拖到灵动岛上方：

```
┌────────┐
│ 高一1班 │  ← 拖拽中
└────────┘
    ↓
╭─────────────────────────────────╮
│  🎯 放到这里执行操作             │  ← 灵动岛展开
│                                 │
│  [锁屏] [关机] [消息] [文件]     │
╰─────────────────────────────────╯
```

**创新点**：灵动岛变成"操作靶心"，把"选中 → 找菜单 → 点操作"三步压缩成"拖拽 + 点操作"两步。

### 2.4 悬停预览

鼠标悬停在收起态上 300ms，不展开但显示摘要：

```
╭─────────────────────────────────╮
│ ⏳ 锁屏 42/60                    │
│ ├ 成功 41  ✗ 失败 1              │  ← 悬停时浮现
╰─────────────────────────────────╯
```

松开鼠标，摘要消失。老师不用展开就能判断"要不要点进去看"。


## 三、任务中心：多任务并行管理

这是最核心的创新：灵动岛展开后是一个**小型任务管理器**。

```
╭─────────────────────────────────────────────╮
│  任务中心                          [全部暂停] │
├─────────────────────────────────────────────┤
│  ⏳ 锁屏 42/60                              │
│  ████████████░░░░░░  [暂停] [取消]          │
├─────────────────────────────────────────────┤
│  📁 分发 exam.zip 45/60                     │
│  ██████████░░░░░░░░  [暂停] [取消]          │
├─────────────────────────────────────────────┤
│  🎤 正在讲话 · 高一1班                       │
│  00:23  [停止]                              │
╰─────────────────────────────────────────────╯
```

**每个任务独立控制**：
- 暂停/继续
- 取消
- 查看详情
- 优先级调整（拖拽排序）

**创新点**：老师不用在多个页面之间切换，所有"进行中的事"在一个地方管理。


## 四、预设模式：一键触发多操作

老师可以定义"模式"，一个按钮触发多个操作。

### 4.1 预设示例

| 模式 | 包含操作 |
|---|---|
| **上课模式** | 锁屏 + 关闭外网 + 启动摄像头 |
| **考试模式** | 锁屏 + 禁网 + 白名单 + 录制 |
| **下课模式** | 解锁 + 恢复网络 + 关闭摄像头 |
| **放学模式** | 关机倒计时 60 秒 + 关闭录制 |
| **自习模式** | 仅禁网 + 保留本地操作 |

### 4.2 在灵动岛上的呈现

```
╭─────────────────────────────────╮
│  ⚡ 上课模式                     │
│  ████████████░░░░░░  进行中      │
│                                 │
│  ✓ 锁屏完成                     │
│  ⏳ 关闭外网...                  │
│  ⏳ 启动摄像头...                │
╰─────────────────────────────────╯
```

**创新点**：把"多个独立操作"打包成一个"模式"，老师不用逐个点。灵动岛显示模式执行的进度，每一步可见。


## 五、内联操作：原地完成

灵动岛的展开态里，**所有操作都能直接完成**，不用跳转。

| 场景 | 传统做法 | 灵动岛做法 |
|---|---|---|
| 批量指令失败 1 台 | 跳到设备列表 → 找设备 → 重试 | 展开态点"重试失败" |
| 收到告警 | 跳告警页 → 查看 → 处理 | 展开态点"标记已读" |
| 文件分发中 | 跳文件页 → 看进度 | 展开态直接看进度 |
| 语音讲话中 | 回工具栏 → 点停止 | 展开态点"停止" |

**原则**：能在灵动岛解决的，不跳转。


## 六、上下文建议：主动推荐操作

灵动岛根据当前上下文，主动推荐操作。

### 6.1 场景示例

| 上下文 | 灵动岛建议 |
|---|---|
| 选中了离线设备 | "该设备离线，是否尝试重连？" |
| 连续 3 次指令失败 | "指令失败率高，是否检查网络？" |
| 长时间未操作 | "是否进入考试模式？" |
| 检测到异常进程 | "检测到游戏进程，是否终止？" |
| 快下课了 | "5 分钟后下课，是否准备下课模式？" |

### 6.2 建议的呈现

```
╭─────────────────────────────────╮
│  💡 检测到 3 台设备离线          │
│                                 │
│  [尝试重连]  [忽略]             │
╰─────────────────────────────────╯
```

**创新点**：灵动岛不只是"被动的状态显示"，而是"主动的助手"。


## 七、快捷键体系

灵动岛支持完整的键盘操作：

| 快捷键 | 功能 |
|---|---|
| `Ctrl + Shift + I` | 唤出/隐藏灵动岛 |
| `Space` | 展开/收起 |
| `↑` / `↓` | 切换任务 |
| `Enter` | 执行默认操作 |
| `Esc` | 收起 |
| `Ctrl + 1~9` | 快速执行预设模式 |
| `Ctrl + Z` | 撤销上一个操作 |

**创新点**：老师可以全程键盘操作，不用鼠标。熟练后效率翻倍。


## 八、跨端接力

灵动岛的状态在多个端之间同步：

```
手机端发起了"锁屏高一1班"
    ↓
管理端灵动岛显示"锁屏进行中 42/60"
    ↓
老师在管理端点了"取消"
    ↓
手机端同步显示"已取消"
```

**场景**：老师在走廊用手机发指令，回办公室用电脑看进度，继续操作。

**创新点**：灵动岛不是"某个端的组件"，而是"跨端的任务视图"。


## 九、学生端的操作创新

学生端灵动岛默认**纯展示、点击穿透**，但有几个例外：

### 9.1 消息确认

收到老师消息，学生可以点击"知道了"：

```
╭─────────────────────────────────╮
│  💬 老师：请打开课本第 42 页     │
│                                 │
│  [知道了]                       │
╰─────────────────────────────────╯
```

点击后，老师端能看到"张三已读"。

**创新点**：从"单向广播"变成"可确认的通知"。

### 9.2 举手发言

学生端灵动岛集成"举手"按钮：

```
╭─────────────────────────────────╮
│  🎤 老师正在讲话                 │
│                                 │
│  [举手发言]                     │
╰─────────────────────────────────╯
```

点击后，老师端收到"张三请求发言"。

### 9.3 紧急求助

遇到设备故障，学生可以点"报告问题"：

```
╭─────────────────────────────────╮
│  ⚠ 设备异常                     │
│                                 │
│  [报告给老师]                   │
╰─────────────────────────────────╯
```

**注意**：学生端的交互要极度克制，不能变成"另一个 App"。默认无交互，只在必要时开放有限操作。


## 十、生态操作：第三方如何利用

第三方推送的消息，也可以带操作：

```json
{
  "source": "classisland",
  "type": "lesson.upcoming",
  "title": "5 分钟后英语课",
  "priority": 5,
  "actions": [
    { "id": "open-schedule", "label": "查看课表" },
    { "id": "dismiss", "label": "知道了" }
  ]
}
```

灵动岛渲染成：

```
╭─────────────────────────────────╮
│  📐 5 分钟后英语课               │
│                                 │
│  [查看课表]  [知道了]           │
╰─────────────────────────────────╯
```

**创新点**：第三方不只是"推送文字"，而是"推送可交互的卡片"。


## 十一、操作创新的汇总表

| 创新 | 传统做法 | 星集控做法 |
|---|---|---|
| 双击执行 | 展开 → 找按钮 → 点 | 双击直接执行 |
| 拖拽执行 | 选中 → 找菜单 → 点 | 拖到灵动岛 → 点 |
| 任务中心 | 多页面切换 | 一个地方管理所有任务 |
| 预设模式 | 逐个操作 | 一键触发多操作 |
| 内联操作 | 跳转处理 | 原地完成 |
| 上下文建议 | 老师自己判断 | 灵动岛主动推荐 |
| 快捷键 | 鼠标操作 | 全键盘 |
| 跨端接力 | 各端独立 | 状态同步 |
| 学生确认 | 单向广播 | 可确认通知 |
| 第三方操作 | 纯文字 | 可交互卡片 |


## 十二、开发优先级

| 优先级 | 操作 |
|---|---|
| P0 | 单击展开/收起 |
| P0 | 内联操作（重试、取消） |
| P1 | 双击执行默认操作 |
| P1 | 任务中心（多任务并行） |
| P2 | 长按/右键菜单 |
| P2 | 快捷键 |
| P3 | 拖拽执行 |
| P3 | 预设模式 |
| P4 | 上下文建议 |
| P4 | 跨端接力 |
| P5 | 学生端交互 |
| P5 | 第三方操作 |


**一句话总结**：灵动岛操作创新的核心是"从通知栏变成任务中心"——双击执行、拖拽靶心、多任务并行、预设模式、内联操作、上下文建议、全键盘、跨端接力。老师不用在多个页面之间跳转，所有"进行中的事"在灵动岛里完成。学生端保持克制，只在必要时开放有限交互。第三方推送可带操作，变成可交互卡片。
