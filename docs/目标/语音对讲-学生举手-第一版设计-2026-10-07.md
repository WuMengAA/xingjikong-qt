# 星集控 · 语音对讲-学生举手（第一版设计，2026-10-07）

> 对应《全量设计文档》3.3.5「学生举手（反向对讲，后置）」。老师讲话是 1→N 广播，
> 学生举手是 **1→1 反向**（学生想发言，老师听那一个学生）。

## 一、场景

| 时刻 | 学生 | 老师 |
|---|---|---|
| 上课 | 想发言 → 点「举手」（被控端托盘/浮动按钮） | 管理端看到「张三（uid）请求发言」 |
| 允许 | 麦克风开，对全班讲 | 老师点「允许」，停止自己广播，听学生 |
| 结束 | 讲完自动关麦 | 老师点「结束」，恢复自己广播 |

**第一版不做**：多学生同时举手排队、音质优化（回声消除）、举手历史记录。

## 二、技术方案（复用语音通道）

现有语音 = 老师麦克风 PCM → 云端 fan-out → 学生播放（单向）。
学生举手 = **学生麦克风 PCM → 云端 →（只这一个学生）老师播放**。

| 消息 | 方向 | 内容 |
|---|---|---|
| `audio.raise` | 学生 → 云端 | `{uid, ts}`（学生点举手） |
| `audio.raise` 通知 | 云端 → 老师端 | 「uid 请求发言」 |
| `audio.allow` | 老师 → 云端 | `{uid}`（允许这个学生讲） |
| `audio.allow` 通知 | 云端 → 该学生 | 开麦采集 |
| 学生 PCM 帧 | 学生 → 云端 | 转发给**老师端**（不广播） |
| `audio.stop` | 老师 → 云端 | 结束学生发言 |

**关键**：同一时间只允许一个学生说话；老师允许后**自己的麦克风暂停**（能停则停，
不能停则云端不转老师帧）。

## 三、云端改动（registry.js / index.js）

- 新增 `g_activeSpeaker`（当前被允许的学生 uid）。
- `audio.raise`：记录 pending + 通知该设备订阅的老师端（`broadcastToViewers`）。
- `audio.allow {uid}`：设 `g_activeSpeaker=uid`，通知该学生开麦；若已有 speaker
  先停旧的。
- 学生二进制帧：**接收路径与新逻辑**——学生帧按"当前 speaker 的 uid"配对，
  只转给老师端（复用 `relayTerminalFrame` 模式或加 `relayAudioToViewers`）。
- `audio.stop`：清 `g_activeSpeaker`。

## 四、被控端改动

- 托盘菜单加「举手」（或通知面板内按钮）。
- 收到 `audio.allow` → 用 **AudioCapture**（waveIn）采集自己的麦 → PCM 帧发云端。
- 状态显示：举手后托盘提示「等待老师允许」；被允许后「正在发言」。
- 学生端「正在讲话」提示复用现有 Island 通知。

## 五、管理端改动

- 集控页语音卡片加「学生发言」区：显示举手请求（uid + 时间），按钮「允许/忽略」。
- 允许后显示「正在听 {uid} 发言」+「结束」按钮。
- 老师自己的「开始讲话」与「听学生」互斥（UI 上自动切换）。

## 六、安全与边界

- 学生举手**不经允许不开麦**（隐私：学生不能自己开麦对全班讲）。
- 同一时间一个 speaker（后端强制）。
- 不录音、不存储（同广播）。

## 七、开发顺序

1. 云端 raise/allow/stop + 单声道转发（单测）
2. 被控端举手按钮 + 允许后采集（复用 audio_capture 思路，agent 侧新类）
3. 管理端举手区 UI
