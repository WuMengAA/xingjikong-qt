# 星集控 · 资产管理（第一版设计，2026-10-07）

> 对应《全量设计文档》10.3「资产管理（低）」。
> 教室机硬件/软件清单自动收集——IT 不用逐台跑，资产表自动更新。

## 一、目标

| 维度 | 第一版 |
|---|---|
| 硬件清单 | CPU/内存/磁盘/网卡 MAC/系统版本 |
| 软件清单 | 已装软件列表（名称+版本） |
| 归属 | 设备 uid → 班级 → 使用人（管理端显示） |
| 更新 | 被控端注册时上报 + 心跳周期刷新（如每日一次） |

**验收**：管理端「资产管理」页按班级列出每台机器的硬件/软件；导出 CSV。

## 二、数据采集（被控端）

- 新增动作 `system_info`（被控端执行一次）：
  - CPU 型号/核心数（注册表 + GetSystemInfo）
  - 内存总量（GlobalMemoryStatusEx）
  - 磁盘：各分区大小/剩余（GetDiskFreeSpaceEx）
  - 网卡 MAC（GetAdaptersInfo）
  - 系统：Windows 版本 + 架构
  - 软件列表：HKLM/HKCU Uninstall 键（DisplayName + DisplayVersion）
- 结果经回执 data 上报（复用现有回执通道，数据较大分片或 JSON 直接带）。

## 三、云端改动

- 新增 `/api/assets`（管理端令牌 GET，按 uid/班级过滤 + 导出 CSV）。
- `recordResult` 收到 `system_info` → 存 `assets/<uid>.json`（内存 + 备库随 backup）。
- 管理端 `GET /api/assets?uid=` 返回单台；`?export=csv` 全量导出。

## 四、管理端改动

- 设置页（或新增「资产管理」入口）：
  - 触发采集：选中设备 →「采集硬件信息」（下发 system_info）。
  - 列表：按班级分组 → 每台显示硬件摘要 + 展开软件清单。
  - 导出 CSV。

## 五、隐私与安全

- 资产数据是**机器硬件/软件**（非学生个人数据），但仍只对**有设备权限**的角色开放。
- 软件清单可能含私有软件名 → 明确"内部使用，不外发"。

## 六、开发顺序

1. agent `system_info` 采集（注册表 + 系统 API）
2. 云端 /api/assets 存储 + 列表 + CSV
3. 管理端资产页
