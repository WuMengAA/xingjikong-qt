设计语言

被控端是「讲台机上的全屏界面」，不是后台系统。所有取值只为三件事服务：远看清、近点准、不误读。

五条原则

这五条决定后面每个像素，先于任何组件

01
状态优先于装饰 空、加载、失败是界面的三种常态，不是异常。没有这三态的页面，用户看到的是「没做完」。装饰（阴影、动效）永远排在状态之后。
02
一比一，不折叠 讲台机是单任务近距离设备：一屏只做一件事，不藏二级菜单、不做悬停才出现的操作。要藏起来的，就是不该出现在这里的。
03
中性反白，不用品牌色 投影与强光下紫调会发灰发脏；主操作用「白底黑字」在任何环境都是最高对比。品牌色只留给管理端。
04
让格式消失 凡是要求用户「按格式输入」的地方，都是设计没做完。时间用时间轴，班码用分段框，区间用滑块 —— 用户不该记住语法。
05
层级靠底色，不靠线条 全局无边框。三级底色（页面 / 卡 / 次级容器）拉开层次，留白拉开节奏。线一出现，界面就开始像表格。

中文排版

这一页是对上一版的自我修正：颜色和层级没大问题，但字号、字重、行高、行宽、标点全是按西文习惯定的。 汉语是方块字，笔画密度是西文的两三倍，同一套数值搬过来就是"看着高级、读着费劲"。

三条病根

不是审美问题，是字体的物理属性问题

一
微软雅黑只有两档真实字重：400 与 700 写 500 / 600 不会报错，浏览器会自己"合成加粗"——把笔画往两边加胖。12–13px 的汉字本来就密， 再被强行加胖就粘连、发虚、像糊了。所以字重要么 400、要么 700，没有中间档。
二
汉字没有升降部，同样的行高看起来比西文挤 西文的 x-height 上下留白是行距的一部分；汉字从字面到字面几乎占满字身框。 西文 1.5 倍行高在中文里相当于 1.35 倍，读三行就"积在一起"。中文正文行高从 1.8 起。
三
汉字的笔画密度不允许 10–11px "警""翻""藏"这类字在 11px 下笔画会互相吃掉，投影出来更是一团。字号下不去， 就只能靠"提亮"来弱化次要信息——而不是缩小。原稿的 #6E6E78 在卡片底只有 3.54:1， 正文尺寸连 WCAG AA 都不过。

实现映射与顺序

设计稿只有落到共用组件上才算完成。下面每条都标了「哪件、改哪个文件、风险」。

一、共用组件补齐（先做，后面所有页都依赖）

AppErrorState 新增。props：title / reason / impact / retryText，signal retried。落 shared-qml/ui/，86 行以内。
AppSkeleton 新增。props：lines / widthJitter。只有一条闪烁动画，软件渲染下也要退化得掉（不要用 MultiEffect）。
AppStatTile 新增（可选）。四个数字卡是记录/时段页共用形状，抽出来免得两页各写一遍。
三件都进 test-qml-structural 与 test-ui-terms 的扫描范围，写完先跑门禁。

二、页面改造顺序（按收益/风险比）

1 · 记录页 加统计条 + 行结论色。已有 AppInfoRow，改 QML + 少量 C++（给「安静／偏吵」结论）。风险低。
2 · 自检页 加顶部结论卡（一句话 + 一个动作）+ 每行证据串。C++ 已有 4 项数据，补 statusHint 即可。
3 · 时段页 时间轴是新组件（AppTimeRange）：拖动 + 冲突高亮。C++ 侧解析口径不变，只是不再让用户手打。工作量最大，收益也最大。
4 · 广播台 两个入口从自绘矩形换 AppCard + 图标 + 说明；排期空态换 AppEmptyState。纯 QML。
5 · 广播社 489 行整体重写（登录门 + 周条 + 排期）。建议拆 3 件：ClubGate / ClubWeek / ClubSchedule，各自 ≤150 行。

改造量预估

行数是"净改动"，不是最终文件大小
时段页最重（要新写一个时间轴组件），但它是唯一"删掉一类交互"的改造——用户从此不需要记格式。 广播社是净减（489 → 目标 300 以内），拆成三件后每件都能塞进 300 行红线。

三、本稿没做的

设置页 10 个分片 703 行，已经是最"完整"的一页，设计收益最低。只提一条：分类菜单的选中态建议从反白改成左侧 2px 条 + 文字加粗，反白块太重。
插件页 只差三态与标题件，已在「组件与状态」页给出样式，不单独出稿。
灵动岛 它是独立视觉层（胶囊 + 面板），有单独的设计线；混进本稿会失焦。

四、口径声明

本稿是设计意图，不是实现。所有色值/字号/间距都与 shared-qml/ui/theme/Theme.qml 的现有令牌对齐 （页面 #0B0B0D 近似、卡 #17171B、次级 #202025、14px 圆角、8 的倍数间距）； 新增的只有「错误态 / 骨架 / 数字卡 / 时间轴」四种形状。
稿子里出现的数字（3 天 / 5830 条 / 91.2 dB / 42 分 10 秒）是演示数据，来自探针假数据，不是现场实测。
