## 1. 被控端灵动岛通知形态

### 1.1 形态表（目标）

| 形态 | 键 | 现存 | 用途 | 关闭方式 |
|------|-----|------|------|---------|
| 灵动岛（胶囊） | `island` | ✅（Collapsed 56 ↔ Expanded 168） | 普通消息/状态 | 定时自动收（ms） |
| 弹幕 | `danmaku` | ❌ **全新** | 轻量滚动提示（广播/刷屏类） | 播完即消失 |
| 全屏 | `fullscreen` | ✅ | 紧急通知 | emergency 手动关 / 定时 |
| +需要回复 | `needConfirm` | ✅（确认按钮+快捷回复） | 需用户应答 | 点确认才关 |
| +循环提醒 | `loopRemind` | ❌ **全新** | 重要未确认事（关前反复提醒） | **必须人工确认关闭** |

### 1.2 各形态验收条

- **island（胶囊）**
  - [ ] 顶部居中、自动吸附最顶端（现 y=24 ✓）
  - [ ] **默认浅色**（现跟随系统深浅色 ✗，需改默认 light）
  - [ ] **宽度随文字留冗余**：收起态标题+描述并排，宽度 = max(标题宽, 描述宽) + 图标 + 冗余量（现宽度公式在此前修复后已按剩余宽 ElideRight，需复核冗余量是否够）
  - [ ] **显示时间、状态**：胶囊内显示当前时间（HH:mm）与事件状态（发送/进行中/完成），随 showIsland 调用携带（现无时间/状态字段 ✗）
  - [ ] 自动弹出：收到 notify/broadcast/remind 指令即自动出现（现通知走统一入口 ✓）
- **danmaku（弹幕）全新**
  - [ ] 字幕式滚动条（可多条排队/重叠需定义：建议**单条滚动展示 + 队列**，教室机不追求弹幕墙）
  - [ ] 出现在屏幕上部（不与胶囊打架：弹幕**更低一层**），播完即消失
  - [ ] 鼠标穿透（不挡课件）
  - [ ] 内容 = 广播正文，长度截断（≥80 字右侧省略）
- **fullscreen（全屏）**（沿用）
  - [ ] urgent/inform/remind 三色、emergency 不自动关（✓）
- **needConfirm（需回复）**（沿用）
  - [ ] 确认按钮 + 快捷话术行、回执上传 ✓
  - [ ] **与循环提醒交集**：needConfirm + loopRemind = 未确认前周期性重现
- **loopRemind（循环提醒）全新**
  - [ ] 触发条件：指令 `params.repeat = true` 或 `params.intervalSec`>0
  - [ ] 行为：通知显示 → 超时未确认 → 淡出 → N 秒后**再次弹出**（默认 60s，可用 params.intervalSec 覆盖）
  - [ ] **只有确认（needConfirm 的回执）才终止循环**；不点确认就一直循环
  - [ ] 循环上限（防霸屏）：默认最多 60 次或 8 小时，之后转托盘气泡 + 丢弃；上限可配
  - [ ] 多条循环提醒互不干扰：各自独立计时，同时最多 1 个循环提醒在前台（教室机单屏约束）

### 1.3 触发源（通知/广播/提醒统一入口）

| 触发 | 现状 | 目标形态 |
|------|------|---------|
| `notify` 指令 | island/popup/fullscreen | island（默认）|
| `broadcast` 指令 | 全屏广播组件 | fullscreen 或 danmaku（可配 kind）|
| `remind` 指令 | island（#92 接收提醒）| island + 可带 loopRemind |
| 本地事件（收文件/考试/断连） | islandShow 6 类 | island + needConfirm（文件类）|

## 3. 数据契约（被控端 ↔ 云端 ↔ 站点）

`notify` 指令 params 扩展（向后兼容，缺省 = 现状行为）：

```jsonc
{ "title": "...", "content": "...", "kind": "island|danmaku|fullscreen",
  "needConfirm": true|false,
  "loopRemind": true|false,      // 或
  "intervalSec": 60,             // 循环间隔（loopRemind 时生效）
  "loopMax": 60,                 // 循环上限（可选）
  "tts": false, "severity": "remind|inform|urgent" }
```

- 老指令不带 kind → island 胶囊（现状）
- `kind:"danmaku"` → 弹幕形态
- `loopRemind:true` → 按 intervalSec 循环，确认后终止
- 循环提醒回执：每次弹出不重复回执；**首次弹出回执一次 + 确认时回执 confirmed**（沿用现有回执协议）

## 6. 通知新形态（2026-10-08 追加）

### 6.1 滚动式灵动岛（标题+正文在胶囊内滚动）

| 项 | 要求 | 验收 |
|----|------|------|
| 展示 | 展开态时标题+正文以**滚动式**呈现（横向滚动，非换行截断）| 长文本完整滚动可见，不 Elide 截断 |
| 持续 | 滚动展示**持续直到人为点击**，不自动消失 | 无人点击 → 一直滚；点击后收起（interactive） |
| 与弹幕关系 | 弹幕 = 独立滚动形态；灵动岛滚动 = 展开态内滚 | 两者不互斥，按 kind 分发 |
| 自动弹出 | 收到 notify/broadcast/remind 即弹出（已定 ✓）| 同 §1 |

> 说明：与 §1.1 的「island 定时自动收」语义区分——新需求「持续直到人为点击」适用于滚动形态的通知，需新增 kind 或复用交互态（interactive + 无 autoClose）。

### 6.2 考试模式：禁止一切通知与监视

| 项 | 要求 | 验收 |
|----|------|------|
| 通知 | 考试模式激活期间，**一切**通知/提醒/弹幕/灵动岛/全屏**不显示**（除考试模式自身 UI）| 考试帧内收到 notify 指令 → 静默丢弃或排队，考后不补 |
| 监视 | 考试期间**禁止屏幕采集/摄像头**上报（自动抓屏、camera_* 全停）| 云端 exam 标记期间 0 帧 0 截图事件 |
| 入口 | 以既有 exam_mode 状态为准（main.cpp 已含考试模式，2026-10-06）| 复用考试状态机，不动其白名单逻辑 |
| 恢复 | 考试结束自动恢复通知与监视 | 考后第一条通知正常弹出 |

### 6.5 噪音检测

| 项 | 要求 | 验收 |
|----|------|------|
