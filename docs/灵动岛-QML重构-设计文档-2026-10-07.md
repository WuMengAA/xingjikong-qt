## 3. 技术选型

### 3.1 为什么 QML 而不是延续 QWidget

| 维度 | QWidget + QPainter（现状） | QML（目标） |
|------|--------------------------|-------------|
| 渲染 | CPU 逐像素绘制 | GPU 场景图（OpenGL/D3D） |
| 动画 | 手写 `QPropertyAnimation` | `NumberAnimation`/`SequentialAnimation`/`StateMachine` 声明式 |
| 文本布局 | 手写 `QFontMetrics` 算宽度 | 内建 `Text` 自动布局 + `wrapMode` |
| 触控 | 手写 `QTouchEvent` 分发 | `TapHandler`/`PinchHandler`/`SwipeHandler` 声明式 |
| 资源 | `QPainter` 手动画 | `Image`/`AnimatedImage`/`QML` 声明 |
| 代码量 | 241 行手写 | 同等效果约 120-180 行 QML |
| 性能 | 文本宽度测量 4 次（`qMax` 公式） | 引擎自动测量 |

**决策：QML 为主渲染层，保留一层薄的 C++ 桥**处理生命周期、业务消息分发、音效调用。

### 3.2 窗口透明度的平台风险

`island.cpp:40` 用 `setAttribute(Qt::WA_TranslucentBackground)` 实现窗口圆角透明。这是 **QWidget 专属属性**，`QQuickWindow`（`QWindow` 子类）没有这个属性。

**Phase 1 必须验证**：Qt 6.8 QML `Window { flags: Qt.FramelessWindowHint | Qt.WindowStaysOnTopHint; color: "transparent" }` 在 Windows 10/11 上能否实现像素级透明。

**备选方案**（若 Phase 1 验证不通过）：用 `QQuickWidget`（QWidget 子类）承载 QML，外层 QWidget 设 `WA_TranslucentBackground`，内层 QML 画圆角矩形。混合模式但已验证可行（island.cpp 现状即此）。

### 3.3 动图格式

| 格式 | Qt 支持 | 原型用量 | 决策 |
|------|---------|---------|------|
| GIF | ✅ 原生（`QMovie`/`AnimatedImage`） | 217 次引用 | **主用** |
| APNG | ❌ Qt 无原生支持 | 7 次引用 | 转 GIF 或精灵表 |
| PNG | ✅ 静态 | 28 次 | 静态角色图 |

鲸鱼原型的 `RunningWhaleTail` 用 APNG——Qt 不支持，需用 GIF 替代或拆成精灵表 + `SequentialAnimation`。

### 5.3 通知提醒

**数据模型**（C++ 侧）：
```cpp
struct Notification {
    QString id;
    QString title;        // "屏幕正在被查看"
    QString desc;         // "3 秒后自动隐藏"
    QString icon;         // "◉" 或 emoji 或 svg path
    enum Priority { Low, Normal, Urgent } priority;
    int durationMs;
    int timestamp;        // 用于排序
    QString actionUrl;    // 点击跳转（可选）
};
```

**队列策略**：
- `QList<Notification>`，按 `priority` 降序 + `timestamp` 升序
- Urgent 通知插入队首，Low 通知追加队尾
- 同 `icon` 通知合并（更新而非重复弹）
- 队列深度上限 5，超出丢弃最旧

**QML 渲染**：
```qml
NotificationStack {
    Repeater {
        model: islandManager.notifications
        delegate: NotificationItem {
            notification: modelData
            onTapped: islandManager.dispatchAction(notification.actionUrl)
        }
    }
    // 堆叠动画：新通知从右侧滑入，旧的向左挤
    layout: GridLayout { columnCount: 1; spacing: 8 }
}
```

**动画**：
- 进入：`XAnimation { from: 300; to: 0; duration: 200; easing.type: "OutBack" }`（沿用 OutBack 超调风格）
- 退出：`XAnimation { from: 0; to: 300; duration: 150; easing.type: "InCubic" }` + `OpacityAnimator { from: 1; to: 0 }`
- 多条堆叠：`layout` 自动计算，每条带 `Z` 值

**自动消失**：`Timer { interval: notification.durationMs; onTriggered: parent.remove() }`

### 5.4 触控交互

Qt 6.8 的 `qwindows.dll` 原生支持触控，QML 提供声明式处理器：

```qml
// 收起 → 展开（单点）
TapHandler {
    target: island
    onTapped: island.expanded = !island.expanded
}

// 上滑展开 / 下滑收起（双指）
SwipeHandler {
    direction: Qt.Vertical
    onSwipedUp: island.expanded = true
    onSwipedDown: island.expanded = false
}

// 长按触发互动（揉动动画）
PressAndHoldHandler {
    timeout: 800
    onPressedAndHeld: whaleMascot.trigger("petpet")
}

// 双指捏合调整大小（可选）
PinchHandler {
    targetSize: island
    pinchUnitType: PinchHandler.ScaleFactor
}

// 悬停（仅鼠标，触控不触发——教室大屏不需要）
HoverHandler {
    onEntered: island.glow = true
    onExited: island.glow = false
}
```

**触控适配要点**：
- 最小可点击区域 44×44px（Apple HIG 标准，教室大屏手指约 10-14mm）
- 收起态按钮区域放大到 `width: 120`（原 island.cpp 的 56px 高度不够手指点）
- 禁用 `HoverHandler` 作为唯一交互路径（触屏无 hover）
- `TapHandler` 的 `pointedInside` 检查确保多点触控不误触发

### 5.6 音效（无 Multimedia 依赖）

**问题**：`Qt6Multimedia.dll` 不存在，`QSoundEffect` 不可用。

**方案：`winmm.dll::PlaySoundW` 直调**

```cpp
// IslandManager.cpp
#include <QLibrary>
#include <windows.h>

typedef void (WINAPI *PLAYSOUNDW)(LPCWSTR, HMODULE, UINT);

void IslandManager::playSound(const QString &name) {
    static QLibrary winmm("winmm.dll");
    static PLAYSOUNDW playSound = (PLAYSOUNDW)winmm.resolve("PlaySoundW");
    if (!playSound) return;
    QString path = m_soundDir + "/" + name + ".wav";
    playSound(reinterpret_cast<LPCWSTR>(path.utf16()), nullptr,
              SND_FILENAME | SND_ASYNC | SND_LOOP);
}
```

**资源策略**：
- 优先用 `.wav`（`task-end-a.wav`、`minecraft-exp-orb.wav` 已是 WAV）
- MP3 文件（`D1.mp3`、`Ya1.mp3` 等）**需转 WAV** 才能用 `PlaySoundW`
- 转换方案：Phase 0 用系统自带 `ffmpeg` 或手动转，提交 WAV 到 `assets/sounds/`
- MP3 播放备选：`QLibrary` + `CoCreateInstance` 加载 Windows Media Player COM 接口（复杂，仅当 WAV 无法满足时启用）

**音效映射**：
| 事件 | 音效文件 | 音量 |
|------|---------|------|
| 通知进入 | `task-end-a.wav` | 60% |
| Urgent 通知 | `task-end-a.wav`（双速） | 80% |
| 鲸鱼互动（点击） | `ya1.wav` | 50% |
| 鲸鱼互动（长按） | `ya2.wav` | 50% |
| 上课提醒 | `d1.wav` | 70% |
| 上课结束 | `d2.wav` | 70% |

**静默控制**：`IslandManager::setMuted(bool)` 全局开关，通知时静音不播放。

## 6. 现有 island.cpp Bug 修复清单

上一轮实测确认的三个 bug，QML 重构时应一并修复：

### Bug 1：宽度公式错（布局崩溃）

**现状**（`island.cpp:87-93`）：
```cpp
const int textW = qMax(fm.horizontalAdvance(title + "  "),
                       fm.horizontalAdvance(m_desc));
const int w = qBound(200, iconW + textW + 48, maxW);
```
宽度按 `max(title, desc)` 算，但渲染时标题和描述**并排**放（`island.cpp:221-231`）。

**实测后果**：
- 标题「屏幕正在被查看」(132px) + 描述「3 秒后自动隐藏」(118px) → 可用宽度 90px → 描述换行 → 压在标题下方
- 标题「可以点我展开/收起」(132px) + 描述「交互态：点击切换形态」(118px) → 直接叠字

**QML 修复**：`Text` 组件的 `wrapMode: Text.WordWrap` + `Layout.fillWidth` 自动处理，无需手写宽度公式。布局用 `RowLayout`（并排）或 `ColumnLayout`（堆叠）声明式定义。

### Bug 2：灵动岛永不消失（功能失效）

**现状**（`island.cpp:57-58, 145`）：
```cpp
m_fadeAnim = new QPropertyAnimation(eff, "opacity", this);
m_fadeAnim->setDuration(220);
// 没有 setStartValue / setEndValue

// dismiss():
if (m_fadeAnim->state() == QAbstractAnimation::Running) return;  // 永远早退
```

**实测后果**：
- 动画无 start/end value → `Running` 状态永不进入 → 第 145 行守卫恒真 → `start()` 被跳过 → `finished` 信号永不触发 → `hide()` 永不执行
- **每次 show 后窗口永久可见**，自动收起（3s/4s/5s）完全失效
- 单例窗口复用，表现为"新消息替换旧消息"，实际旧消息永远挂着

**QML 修复**：用 `OpacityAnimator` + `PropertyAnimation` 声明式：
```qml
SequentialAnimation {
    id: fadeOutAnim
    NumberAnimation { target: island; property: "opacity"; from: 1.0; to: 0.0; duration: 220 }
    ScriptAction { script: island.visible = false }
}
```
声明式动画的 `from`/`to` 是必需的，编译期检查，不会遗漏。

### Bug 3：两个死方法

**现状**：`island.h` 声明 `applyTheme()`、`positionForCurrent()`，`island.cpp` 零定义零调用。

**QML 修复**：重构后这两个方法不存在（主题在 `Theme` 单例里，定位在 `Main.qml` 的 `x/y` 计算里）。彻底移除。

### 附加问题：组件未接入主程序

**现状**：`main.cpp` 中 `IslandOverlay` 引用 0 次、`island.h` include 0 次。exe 停在 10-07 12:13，msi 停在 12:39，`island.cpp.obj` 是 18:40 编的但没链接进主程序。

**QML 重构后**：`IslandManager` 在 `main.cpp` 中实例化一次，`app` 启动时加载 QML，业务层通过 `IslandManager::instance()->show(...)` 调用。

### 10.1 灵动岛图标来源

**现状**：website 仓没有灵动岛 SVG 图标（§2.2 已验证）。

### 10.2 是否保留 QWidget 实现作为回退

**选项**：
- **(a)** 完全替换（QML 为主，移除 QWidget）
- **(b)** 保留两者，运行时切换（增加维护成本）

**推荐 (a)**：QML 是用户明确指定的方向，保留两套实现增加维护负担。Phase 1 验证通过后直接替换。

### 10.3 MP3 音效是否转 WAV

**选项**：
- **(a)** 全部转 WAV（`PlaySoundW` 支持，无 Multimedia 依赖）
- **(b)** 保留 MP3，用 Windows Media Player COM 接口播放（复杂，需 COM 注册）

**推荐 (a)**：`D1.mp3`/`D2.mp3`/`Ya1.mp3`/`Ya2.mp3` 转 WAV 后体积增加约 3-5 倍，但总增量 < 50KB，完全可接受。`PlaySoundW` 是最简单的路径。

### 10.4 鲸鱼娘角色动画形式

**选项**：
- **(a)** 直接用 GIF 动图（原型已有，最简单）
- **(b)** 精灵表 + QML 帧动画（可控性强，资源需拆帧）

### 10.5 通知是否支持点击跳转

**选项**：
- **(a)** 通知点击 → 触发 `actionUrl`（如 ` stelarith://repair` 打开维修单详情）
- **(b)** 通知仅展示，点击关闭

**推荐 (a)**：灵动岛作为入口，点击通知应能跳转对应功能。需主程序注册 `QUrlSchemeHandler` 处理自定义协议。Phase 2 实现。
