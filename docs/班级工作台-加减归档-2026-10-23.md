### 预览阶段实证并修掉的缺陷（自己抓到的错误也要记账）

1. **`Md3Card` 漏传 `md3`**（`ClassIdentityPane` / `ClassBoardPane`）：运行时刷 `Unable to assign [undefined] to QColor/double`，卡片圆角与描边全丢。修复：补 `md3: pane.md3`。
2. **`ClassActionPane` 高度塌成 0**：根 Item 没有 `implicitHeight`，内部 Column 又用 `anchors.fill`（与隐式高度成环）。表现是"右栏动作区根本没画出来"。修复：Column 改 `width: parent.width` 自然高度 + root `implicitHeight: bodyCol.implicitHeight`。
3. **`onCount` / `devCount` 命名踩坑**：属性名 `on` + 大写开头会撞 QML 信号处理器语法（历史整页崩溃案）。改名 `onlineN` / `deviceN`。
4. **探针日志写法致死**：给根对象新增第二个 `Component.onCompleted` 直接 `Property value set multiple times` → `failed to load component` → 进程退出（不是警告）。探针日志必须并进既有那段。
5. **空态位置**：班级空态 Text 放在 `Layout.fillHeight` 的 ListView **之后**，会被推到页面中间（看起来像空态飘着）。改到 ListView 之前。
6. **既有缺陷（顺带发现，只报不改）**：`shell/Sidebar.qml` 的「返回经典界面」用 `arrow-left`，而 lucide 图标集里没有该图标——一直画成空白。ClassNav 改用「‹」字形。
