# 星集控 · 管理端 UI 规范（2026-10-06 定稿）

这份文档是**界面改动的判据**。以后任何新界面/改样式，先照这里对齐再动手；
和这里冲突的写法一律改回来，不要"这次特殊一点"。

## 0. 一句话总纲

> 黑白是底，反白是唯一强调；界面只回答"现在是什么情况、我下一步能做什么"，
> **不写开发说明、不写术语、不写还没做的东西**。

三条硬规矩（从已交付界面里沉淀出来的）：

1. **不编造**：数据没有就留空态并说明"接下来会怎样"，不能填一个像模像样的默认值。
2. **不假装能用**：没做的能力置灰，且灰着的时候 tooltip 必须说出为什么灰
   （"这台机器不支持" / "要管理员身份" / "先在左边选一台"）。空壳开关比没有更糟。
3. **同一个数一屏只说一遍**：帧数/连接状态/设备数在顶栏、控制页、设置页各出现一次就够。

## 1. 色板（只有令牌，别写死十六进制）

所有颜色从 `Main.qml` 里的 `th`（`darkTh` / `lightTh`）取。**界面里不出现裸色值**，
换主题时只改这两个对象。

| 令牌 | 用途 |
|---|---|
| `win` / `body` | 窗口底 / 主体底（主体比窗口沉一档） |
| `panel` / `card` | 卡片底 / 卡片描边 |
| `cream` / `hover` / `hover2` | 选中底 / 悬停 / 按下 |
| `line` / `sepline` / `stroke` / `stroke2` | 分隔线（越来越重） |
| `fg` / `op` / `fg3` / `fg4` | 主文字 / 次文字 / 辅助 / 禁用 |
| `inv` | 反白（唯一强调手段：底反白 + 字反色） |
| `rWin` / `rCard` / `rCtrl` | 圆角 16 / 12 / 8 |

## 2. 尺寸与层级

| 元素 | 值 | 说明 |
|---|---|---|
| 顶栏 | 44px，左右 18 | 底下 1px 分隔线必须画 |
| 底部标签 | 42px，顶上 1px 分隔线 | |
| 卡片内距 | 16 | 《不写死》任何一张卡自己拍 14/18 |
| 卡片间 / 与屏幕边 | 14~18 | 大屏用 18，密集区 14 |
| 标题 / 正文 / 说明 / 按钮 | 11 / 12 / 11 / 12 | 11 是最小档，别再往下 |
| 主操作按钮高 | 30（强） / 26（次） | |
| 控件圆角 | 8 | 胶囊 14/999 |

层级只靠三样：**反白 > 底色块 > 描边 + 留白**。不加阴影、不加渐变、不加第三色。

## 3. 组件（一律用 `qml/components/` 里的，不许就地重画）

| 组件 | 用在哪 |
|---|---|
| `Card` | 所有"一块"的区域：概览卡、设置卡、关于 |
| `Btn` | 所有按钮（含空态里那颗），`strong` = 主操作（反白），`tip` 必填 |
| `EmptyState` | 所有空列表/空页面：两行文案（标题 12 + 说明 11） |
| `ToggleRow` | 设置页开关（真状态，不是画的） |

**新增组件的入口就是 `qml/components/`，不许往 Main.qml 里塞第三套按钮样式。**

## 4. 顶栏（2026-10-06 重写）

顶栏这一行讲三件事：**我是谁（品牌）→ 连没连上（状态）→ 谁在用（账户/身份）**。

- ❌ 原来有个「控制 ┃ 被控」分段控件：那是开发期"假装自己是被控端"的自检开关，
  被控端是另一台机器上的另一个程序，在这台机器上切它零效果。正经产品不该有这种死开关。
- ✅ 现在是 `AccountMenu`：未登录 = 「登录」胶囊；已登录 = 头像 + 账号 + 角色徽标，
  点开是身份菜单（切管理员/教师、看权限说明、退出登录、去设置）。
- 状态文字跟着登录态走：已登录但没连上 → "没连上云端"；没登录 → "没登录"，
  **点了直接去登录**（第一件该做的事不该藏在设置页第三张卡里）。
- 「被控端是什么、上哪儿下」属于说明，归设置 → 关于，不放顶栏。

## 5. 权限与身份

- 角色只有两种：**管理员**（默认）/ **教师**。切角色存在 QSettings，重开程序还在。
- 管理员专属（界面置灰 + tooltip 说清原因）：
  锁屏 / 重启 / 关机 / 远控开 / 远控关 / 终端 / 定时关机 / 定时重启 / 广播。
- 教师可用：看画面类（截图/日志/探活/摄像头/文件/音量）、通知、开录停录、播放停播、推文件。
- ⚠️ 界面门控**不是**安全边界，闸门在被控端和云端；界面置灰只为了"少让人白点一下"。

## 6. 文案

- 只写"要做什么 / 成了没"：写"已连上云端，正在鉴权…"不如写"连接正常"。
- 不把协议/C++ 内部状态端给用户看：`auth 消息里既没有 token 也没有 ticket`
  → `没登录，连不上云端。点右上角「登录」用星璃账号进去`。
- 不写版本号未注入、未实现、TODO 这类开发说明。

## 7. 空态（统一 `EmptyState`）

两行，禁止一行：一行说"现在是什么"（"暂无设备"），一行说"接下来会怎样"
（"屏幕上的机器会自动出现"）。只有一行会被读成"坏了"。
