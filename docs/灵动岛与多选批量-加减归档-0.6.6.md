# 管理端 0.6.6 · 灵动岛 + 设备多选 + 批量三段式（加减归档）

依据：《星集控 — 全量设计文档（整理合并版）》
- **3.8 灵动岛 — 状态聚合与统一交互**（优先级表、三态、收起/展开、进度条、优先级顺序）
- **4.4 选择与多选**（单击 / Ctrl / Shift / 框选 / Ctrl+A / Esc，选中视觉反馈）
- **4.5 批量操作规范（三段式）**（确认 → 进度可见 → 结果汇总）
- **4.7 效率功能**（快捷键表补全）
- **5.6 Toast 组件规范**（底部居中 / 距底 32 / 3 秒 / 上移淡入 200ms）

范围：**只在管理端 `Stelarith-viewer-qt` 的 QML 层**。`src/*`（C++/ViewerBackend）一行没改，
云端、被控端、站点全部没碰。

## 二、修改的既有文件

### 1. `qml/Main.qml`（+235 / −28 量级）

| 位置 | 改了什么 | 为什么 |
|---|---|---|
| 状态属性区（`property var islandStates` 等） | 新增 `islandStates` / `batch` / `alerts` / `toastText` / `toastTick` / `picked` / `pickAnchor` | 状态源与显示分离：灵动岛只画，主界面算 |
| `Connections.onResultReceived` 末尾 | 加三句：`batchStep(uid, ok, err)` / `pushAlert(...)` / `refreshIsland()` | 一台机器回话 = 批量进度走一步 + 可能记一条告警 + 状态重算。**刻意放在末尾而不是嵌进已有分支**：一条回执可能既是"批量的一台"又是"软件列表"，分着走才不互相踩 |
| 新增 `Connections` 回调 | `onConnectedChanged` / `onFileProgressChanged` / `onRtcStateChanged` → `refreshIsland()` | 连接、文件、监控三条状态线各自有 C++ 侧的 notify 信号，接上才能自动更新 |
| 控制页左栏设备 delegate | 补选中态（描边反白）+ `onClicked: (mouse) => root.pickDevice(uid, mouse.modifiers, index)` | 原来单击只做 `backend.currentUid = uid`，没有任何多选与选中反馈 |
| 左栏设备列表下方 | 新增「已选 N 台 + 锁屏选中的 / 关机选中的 / 取消选择」批量条 | 4.4 要求"顶部『已选 12 台』+ 批量按钮激活" |
| 快捷键区 | 新增 `Ctrl+A` / `Esc` / `Ctrl+L` / `Ctrl+Shift+L` | 4.7 快捷键表补全（原先只有 Ctrl+K / Ctrl+F / F5 / Ctrl+1..4） |
| 窗口层（弹窗区） | 新增灵动岛容器 `Item`（挂窗口层、悬浮于顶条下 8px）+ 全局 `Toast`（`Rectangle` + `Timer`） | 灵动岛讲"现在在干什么"与老师在哪一页无关；Toast 让任何页都能出提示 |
| 文件末尾 | 新增 `toast()` / `refreshIsland()` / `pushAlert()` / `batchStart()` / `batchStep()` / `pickDevice()` / `selectAll()` / `clearPick()` / `runOnPicked()` | 上面 UI 需要的行为集中在一处 |
| 命令面板 `pal.cmds` | 33 → **37 条**，新增 4 条选择类命令（选中全部 / 取消选择 / 锁屏选中的 / 锁屏全部在线设备） | 命令面板与快捷键必须走同一条路，否则面板能点、快捷键能按，权限门控就从后门绕过去了 |
| `broadcastAll` | 不动逻辑，但它的 `hint(...)` 换成全局 `toast(...)`（见下方"自己抓到的错误"） | 跨页提示原来根本不出现 |

## 三、行为迁移对照

| 能力 | 改前 | 改后 |
|---|---|---|
| 断线提示 | 顶栏一行 11px 小字（只有 WS 断时） | 灵动岛收起态主状态（优先级第 1 档）+ 展开看重连说明 |
| 批量指令进度 | 无 | 灵动岛收起态 `锁屏 30 台 12/30` + 底部进度条（按 `done/total`），展开看逐台 |
| 文件分发进度 | 只有 C++ 属性，界面无处可读 | 灵动岛 `分发文件 45%` + 进度条（复用已有 `fileState/filePercent/fileTarget`，没新加后端读数） |
| 告警 | 无收口 | 回执失败 / 文件推送失败 → `alerts`（同机同条去重，最多 20 条）→ 灵动岛 `N 条没处理`，展开看首条 |
| 屏幕监控 | 只有画面区链路徽标 | 灵动岛 `正在看 UID`（`rtcState === "track"` 时） |
| 设备选择 | 只能单选（决定看哪台） | 单选 + Ctrl / Shift / Ctrl+A / Esc 多选（`picked` 管"发给谁"，`currentUid` 管"看谁"） |
| 批量下发 | 只有广播（且发完无汇总） | `runOnPicked(a)` 统一走 `batchStart → sendAction × N → batchStep × N → 汇总 toast` |
| 提示 | `consolePage.hint()`（仅集控页可见） | `root.toast()`（全页可见，5.6 规范） |
| 空闲 | 无 | 灵动岛彻底消失（`mode === "hidden"`，尺寸为 0，不是"看不见"） |

**没做的（明确声明）**：
- **语音讲话状态**（3.8.3 优先级第 1 档）没接 —— 被控端没有这条链路，宁可空着也不摆一个永远空的胶囊。
- **设备搜索/筛选（4.8）没做**：uid 字段语义不明（云端下发的一维数组里只有 `uid` / `framesIn`，没有班级名/IP/标签），硬上拼音首字母表等于编数据；`Ctrl+F` 继续由命令面板承担入口。
- **框选（4.4 空白处拖拽）没做**：左栏是 168px 窄列表，框选的收益抵不上误拖风险；`Esc` 可取消选择已经兜住误操作。
- **批量"二次确认 / 取消剩余"（4.5）没做**：破坏性动作（锁屏/关机/重启）在右栏已经是重描边 + ToolTip"点了立刻执行"；本轮加的是**进度与结果**这两段，确认段沿用原路。

## 五、自己抓到的错误（都记在账上）

1. **中文乱码（上轮埋的雷，本轮修）**：上一轮我用 `bash heredoc` 把中文喂给 python 脚本，
   heredoc 走系统 ACP(GBK)，python 按 UTF-8 解 → 落盘变成「**锁屏敛c机机**」「**星琥**账号」「**郣**些都住在主界面里」
   （`教/室` → `敛c`，`璃` → `琥`，`那` → `郣`，`颗` → `题`）。已整段重建（命令表 37 条 + 两处注释）。
   **规则改了：只要脚本里要写中文，一律用 Write 工具落盘 .py 文件再执行，绝不经 bash heredoc。**
2. **`root.picked` 声明漏了**：函数里用了 `root.picked.length`，属性却没声明 → 运行时 TypeError。
   qmllint 抓不到，**只有真跑 exe 才暴露**（这跟上次 `CommandPalette` 属性名写成 `th` 是同一类坑）。
3. **`hint()` 只在集控页能用**（既有 bug）：`consolePage.hint()` 定义在集控页 Item 里，
   从别的页调用是 ReferenceError → `broadcastAll` 发了广播却一句回话没有。
   本轮补了全局 `toast()` 把它接上（集控页那颗旧的保留，它贴着卡片更好使）。
4. 灵动岛里我顺手写过一个不存在的属性 `isl.strokeSet`（会静默 fallback，属于脏代码），已改回 `theme.card`。
