# 星集控 · 用户手册（面向老师 / 管理员）

> 版本 v0.6.x（2026-10-07 整理）。本手册只写**真实存在的功能**——没法点的按钮不写，
> 避免老师照着手册找一个不存在的入口。

---

## 1. 快速开始

### 1.1 登录
- 打开管理端（viewer-qt，老师机上），点右上角「登录」→ 用星璃网站账号登录。
- 没账号时点「注册」；管理员给教师分配授权班级后，才能看到/操作对应设备。

### 1.2 界面概览
| 区域 | 作用 |
|---|---|
| 左侧导航 | 概览 / 控制 / 集控 / 设置 |
| 概览 | 今日课表、最近操作回执流水、待办 |
| 控制 | 设备列表（选中后看画面 + 单台操作） |
| 集控 | 通知下发、定时任务、广播、考试模式、语音对讲、屏幕广播、班级监控 |
| 设置 | 账户、连接、外观 |

### 1.3 第一次操作（推荐路径）
1. 登录 → 2. 控制页选中一台教室机 → 3. 点「锁屏」试一次（会看到回执）→ 4. 集控页发一条通知试广播。

## 2. 设备管理

### 2.1 查看状态
控制页列表显示每台设备：**uid、在线状态（绿点/灰点）、版本、最后心跳**。
选中一台 → 右侧出实时画面（JPEG 轮询；远控时转 WebRTC 实时流）。

### 2.2 筛选与搜索
- 顶部搜索：按 uid / IP 模糊匹配。
- 状态筛选：全部 / 在线 / 离线。
- 触发「刷新」拉最新列表。

### 2.3 分组（班级归班）
设备归班在**集控控制台**（站点后台）操作，管理端只读展示（班级管理页面显示
每班设备明细）。老师只能看到**授权班级**的设备（后端校验）。

## 3. 常用操作（单台 / 批量）

| 操作 | 位置 | 说明 |
|---|---|---|
| 锁屏 | 控制页选中设备 →「锁屏」 | 立刻锁屏 |
| 关机 / 重启 | 同上 →「关机」「重启」 | 破坏性，有二次确认 |
| 发消息 | 集控页「通知下发」 | 填标题/内容，选形态（弹窗/灵动岛/全屏）、严重度、是否朗读 |
| | | 勾「需确认」→ 教室机弹「确认」+ 快捷回复按钮，学生点选后回执到管理端 |
| 推文件 | 控制页选中设备 →「推文件」 | 选本地文件，推到教室机指定目录（分片+进度） |
| 查看屏幕 | 选中设备即看 | 画面右下角显示帧率 |

### 3.1 批量操作
控制页多选（Ctrl+单击加选）→ 顶部出现批量按钮（锁屏/关机/重启）。
流程：**二次确认 → 进度可见（每台 ✓/✗）→ 结果汇总**（"58 成功 2 失败"+ 查看失败设备）。
失败设备可单独重试。

## 4. 集控功能

### 4.1 通知下发（含确认 + 快捷回复）
- 标题（必填，截 24 字）、内容（截 64 字）、形态（弹窗/灵动岛/全屏）、严重度（仅全屏生效）、朗读。
- **需确认**：勾选后教室机显示「确认」按钮；可填快捷回复话术（逗号分隔，如 `收到,好的`）。
  学生点「收到」→ 管理端回执流水显示 `confirmed` + 回复内容。

### 4.2 定时任务
- 定时关机 / 定时重启：选动作 + 填时间（HH:mm）→ 下发，被控端到点执行。
- 支持列出 / 取消。

### 4.3 广播
- 广播 = 发通知给**所有在线设备**（不需选中）。内容填好后点「广播」。

### 4.4 考试模式
- 目标：一键把教室机切到"考试状态"。
- 配置：时长（分钟，0=不自动结束）+ 白名单进程（逗号分隔，如 `examclient,notepad`）。
- 效果（第一版）：全屏置顶拦截窗口（显示倒计时）+ 白名单进程轮询（非白名单且非
  系统关键进程会被终止）。
- 说明（诚实边界）：防君子不防小人——不拦 USB、不改网络、不拦 Ctrl+Alt+Del。
  严格考试需物理监考。
- 结束：管理端点「结束考试」（教室机恢复）。

### 4.5 语音对讲
- 「开始讲话」→ 麦克风采集 → 全班在线设备播放（老师→全班单向广播）。
- 学生端显示"老师正在讲话"提示。**默认静音**，点开始才采集；不录音不监听。
- 再次点「停止讲话」结束（静音）。

### 4.6 屏幕广播
- 「开始广播」→ 老师屏幕（3fps JPEG）推给全部在线设备全屏显示。
- 学生端显示"正在接收老师屏幕"。再次点「停止广播」恢复。

### 4.7 班级监控（录制回放）
- 流控页「班级监控」卡片：显示已上传的录制（按设备分组）。
- 录制在被控端 `camera_record_start` 后生成（ffmpeg 摄像头录制），结束自动上传云端。
- 点「刷新」拉最新列表；点录制可下载/播放 mp4。

## 5. 远程终端（管理员/授权老师）

- 控制页选中设备 →「打开终端」→ 教室机**本机弹确认框**（有人要开命令行，允许吗？）
  —— 只有教室机旁的人点「允许」才开。
- 会话内可敲命令看输出；超时/关闭自动结束。
- 只有能连的机器（有 terminal 能力）按钮才亮。

---

## 6. 告警与回执

- 底部/右侧「回执流水」显示每次操作结果（uid / 动作 / 成功/失败 / 错误原因）。
- 错误有具体信息（如"设备不在线，指令未下发"），不假装成功。
- 断线：顶部状态提示 + 自动重连。

## 7. 常见问题（FAQ）

| 问题 | 原因/处理 |
|---|---|
| 设备灰的/离线 | 教室机没连云端（查网络/电源）；点「刷新」重试 |
| 指令下了没反应 | 看回执流水有没有报错；设备离线会明确说"不在线" |
| 锁屏没锁上 | 可能是旧版本被控端（看版本号）；管理员可触发升级 |
| 广播没声音 | 教室机可能没音箱/音量 0；语音是单向广播（老师→学生） |
| 推文件失败 | 看回执错误；大文件需要时间（分片+进度），不要关管理端 |
| 登录不了 | 检查网站账号/角色权限；管理员确认给了授权班级 |
| 考试模式没拦住 | 第一版只拦输入+白名单进程（防君子）；禁用 USB/禁网后置 |

## 8. 权限说明（老师 vs 管理员）

| 能力 | 老师 | 管理员 |
|---|---|---|
| 看画面 | 授权班级 | 全部 |
| 锁屏/关机/消息/文件 | 教学相关 | 全部 |
| 广播/语音/屏幕广播 | 授权班级 | 全部 |
| 考试模式 | 授权班级 | 全部 |
| 远程终端 | **需管理员单独授权** | 有 |
| 班级归班/配置 | 无 | 有 |

> 校验在后端：老师 A 不能看/操作老师 B 的班级（除非被授权）。
> 学生隐私：远控时学生端显示"屏幕正在被查看"；语音不录音。
