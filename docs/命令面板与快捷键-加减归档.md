# 命令面板（Ctrl+K）与快捷键 · 加减归档

> 依据《星集控 — 全量设计文档（整理合并版）》3.5.1（命令面板）与 4.7（快捷键表）；
> 同时解决"双击 viewer-qt 起不来"这个报 `no Qt platform plugin could be initialized` 的启动失败。

## 一、先说那个错误框（用户最先撞到的）

现象：双击 `viewer-qt.exe` 弹 Qt 通用 fatal 框 ——
`This application failed to start because no Qt platform plugin could be initialized.` /
`Available platform plugins are: windows.`

**这不是缺插件。** 可用插件里明明有 `windows`，系统根本没走到"缺插件"这一步；
那只是 Qt 对**任何启动期致命错误**都会套用的同一句模板文案。

真因（命令行复现，日志 `build/viewer-run.log`）：

```
[viewer] WARN: QQmlApplicationEngine failed to load component
[viewer] WARN: file:///.../build/qml/Stelarith/Main.qml:1901:9: Cannot assign to non-existent property "theme"
[viewer] FAIL QML 没能加载（qml/Main.qml 有问题？）—— 退出
```

`Main.qml` 里给命令面板传了 `theme: root.th`，而组件的暴露属性当时叫 `th` ⇒ QML 对未知属性赋值是**编译/加载期硬错**，
引擎加载失败 → main 退出 → Qt 弹那句误导性 fatal 框。

⚠️ **qmllint 抓不到这类错**（它不做属性绑定校验）。以后必须真跑 exe 看 stderr / `viewer-run.log` 里的 `FAIL QML 没能加载`。

修复：`qml/components/CommandPalette.qml` 属性名 `th` → `theme`（与项目里 Card / Btn / AccountMenu 一致），15 处引用同步改。

## 二、新增文件

| 文件 | 行数 | 职责 | 与旧实现的行为差异 |
|---|---|---|---|
| `qml/components/CommandPalette.qml` | ~180 | 命令面板（Popup）：收命令、模糊搜索、键盘选择、执行 | 此前管理端**没有任何**全局命令入口，右栏按钮是唯一路径 |

- 三档匹配：名称前缀 > 名称含 > 别名（拼音首字母，如 `gj` → 关机教室机）⇒ 设计文档 4.8「支持拼音首字母」落地。
- 命令全部走 **`root.runAction()`**（和右栏按钮同一条路），权限门控 `permOk` / 能力门控 `capOkAll` 因此一并生效，
  不会出现"界面置灰但快捷键点得动"的后门。
- 键盘：`↑/↓` 选、`Enter` 执行、`Esc` 关闭；选中行反白（沿用黑白稿，唯一强调手段＝反白）。
- 空结果显示"没有匹配的命令"，不静默留白。

## 三、修改的既有文件

### `qml/Main.qml`（+88 / −23）

1. **命令表装配**（`Component.onCompleted`）：`pal.cmds` 共 **33 条**，分三组
   - 教室机动作 21 条：锁屏 / 重启 / 关机 / 发通知 / 终端 / 远控开·关 / 截图 / 拍一张 / 软件 / 日志 / 探活 / 摄像头 / 音量 / 文件 / 定时 / 媒体 / 开录 / 停录 / 播放 / 停播；
   - 视图 6 条：切到概览·控制·集控·设置 + 去广播；
   - 系统 6 条：刷新登录 / 网站账号登录 / 切管理员 / 切教师 / 黑白 / 浅色 / 官网下载页。
2. **快捷键 7 个**（设计文档 4.7）：`Ctrl+K` 命令面板、`Ctrl+F` 打开命令面板（原设计是"聚焦搜索框"，
   这版界面无设备搜索框，命令面板即入口）、`F5` 刷新设备列表、`Ctrl+1/2/3/4` 切四页。
3. **广播逻辑抽函数** `root.broadcastAll(text)`：原来写死在控制页那颗按钮的 `onClicked` 里，与命令面板共用一份
   （顺序不变：权限 → 内容 → 有没有设备 → 逐台下发 → 提示"已广播给 N 台设备"）；按钮 `onClicked` 缩成一行调用。
4. 广播按钮顺手修了缩进错位（原来 `Button` 比 `TextField` 深 8 格，视觉上是"按钮钻进输入框里"）。

### 没改的
- C++ 侧（`src/*`）**一行没动** —— 全是 QML 层。
- 站点 / 云端 / 被控端：零改动。

## 四、验证

| 项 | 命令 | 结果 |
|---|---|---|
| 语法 | `qmllint qml/Main.qml qml/components/CommandPalette.qml` | 无 Error（只有历史 Warning） |
| 构建 | `build-qt-viewer.bat`（Ninja + MSVC） | `[exit] 0` |
| 离屏自检 | `cd build && ./viewer-qt.exe -platform offscreen` | `viewer-qt 版本 0.6.4`、`托盘已就绪`、**无** `FAIL QML 没能加载`；云端连上后 `AUTH_FAILED`（未登录拿着票，预期） |
| 修复前对比 | 同上 | 复现 `Cannot assign to non-existent property "theme"` → 退出 |

⚠️ **离屏自检的前置**：每次构建后 `windeployqt` 会把 `platforms/qoffscreen.dll` 删掉，需重新
`cp D:/Qt/6.8.1/msvc2022_64/plugins/platforms/qoffscreen.dll build/platforms/` 才能 `-platform offscreen`。
