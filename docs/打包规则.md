# 星集控 · 管理端打包规则（纯文字规范）

> 生效：2026-10-06 ｜ 适用范围：管理端 viewer-qt 每次发布前必须执行。
> 本文件是**规则**，不是脚本；执行时按条文逐条人工/命令核验。

---

## 一、产物位置

```
Stelarith-viewer-qt/
├── src/main.cpp                  # 版本号唯一真源：kViewerVersion
├── build/                        # 开发构建目录（含编译产物，不发布）
├── dist/
│   ├── pkg-<ver>/                # 绿色包目录（发布目录，可直接运行）
│   │   ├── viewer-qt.exe
│   │   ├── platforms/qwindows.dll
│   │   ├── qml/Stelarith/Main.qml（含 schedule/ 子目录）
│   │   └── … Qt 运行时 DLL + 插件
│   └── stelarith-viewer-portable-<ver>.zip   # 对外分发压缩包
└── docs/打包规则.md              # 本规则
```

---

## 二、版本号规则

1. **唯一真源**：`src/main.cpp` 的 `kViewerVersion` 常量；改版本只改这一处。
2. 格式 `X.Y.Z`；常规发布 Z 递增，功能发布 Y 递增。
3. 版本号上方注释必须同步（曾漏改，导致注释与常量不一致）。
4. 每次发布前先改版本号，再编译、再打包。

---

## 三、打包内容

### 必须包含（运行时依赖）
- 主程序 `viewer-qt.exe`
- Qt 核心 DLL：Qt6Core / Gui / Qml / Quick / Network / WebSockets / Widgets / WebEngineCore 等
- Qt WebEngine 进程：`QtWebEngineProcess.exe`
- 平台插件：`platforms/qwindows.dll`
- 图形/辅助插件目录：generic / iconengines / imageformats / networkinformation / position / resources / styles / tls
- QML 界面：`qml/Stelarith/Main.qml` + `qml/Stelarith/schedule/`
- 图形软件栈：D3Dcompiler_47.dll / dxcompiler.dll / dxil.dll / opengl32sw.dll

### 必须排除（编译产物，非运行时）
`CMakeFiles/`、`.qt/`、`.rcc/`、`viewer-qt_autogen/`、`meta_types/`、`qmltooling/`、`qmltypes/`、`translations/`、根级 `Stelarith/`（CMake 模块缓存；真 QML 在 `qml/Stelarith/`）。

## 四、发布流程（七步，不可跳步）

1. **改版本号**：`src/main.cpp` 的 `kViewerVersion` + 上方注释。
2. **编译**：`build-qt-viewer.bat`，必须 `[exit] 0`。
3. **运行验证**：`python _probe\run_viewer_qt.py`，必须 8 秒后仍在运行、无 QML ReferenceError。
4. **打包**：新建 `dist/pkg-<ver>/`，从 `build/` 拷贝运行时内容（含上表、排除下表）。
5. **包内验证**：检查三项关键文件存在（exe / qwindows.dll / Main.qml）+ 包内 Main.qml 含本次新功能关键词。
6. **包启动验证**：从 `dist/pkg-<ver>/` 启动 exe，确认进程存活。
7. **压缩分发**：`dist/stelarith-viewer-portable-<ver>.zip`。

---

## 五、验收判据（每一条都是硬性）

- [ ] `kViewerVersion` 与 zip 文件名版本一致
- [ ] 编译 exit 0
- [ ] 运行 8 秒存活、无 ReferenceError
- [ ] 包内三项关键文件存在
- [ ] 包能启动（进程存活）
- [ ] zip 已生成且大于 100MB（Qt WebEngine 必然 >100MB）

---

## 六、常见坑（踩过，写成规则防止再犯）

1. **QML ReferenceError**：Repeater delegate 是独立作用域，不继承父级属性 → 父级必须加 `id`，delegate 内用 `父id.属性` 显式引用。2026-10-06 集控页三处（ntCol / schedCol / consolePage）都踩过。
2. **包内 exe 启动即退、无日志**：缺 Qt 运行时 DLL（最常见 Qt6Widgets / qwindows.dll）→ 规则三"必须包含"表逐项核对。
3. **禁止用 PowerShell 编辑 main.cpp**：`Get-Content`/`Set-Content` 会拆分 C++ 多行字符串字面量 → 用编辑器/edit 工具。
4. **.bat 文件保持纯 ASCII**：中文注释在 cmd 里按 GBK 解码会吞行 → 所有 .bat 不写中文。
5. **打包版本落后源码**：判据 = 包内 exe 字节数 vs 刚编出的 exe 字节数，不一致说明包是旧的。
