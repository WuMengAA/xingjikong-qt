## 1. 让云端上公网 —— ✅ 已完成（2026-10-05）

**做了什么**：给现有 cloudflared 隧道**追加**了一条
`control.245959623.xyz → http://localhost:8788`（排在通配规则 `*.<zone>` **之前**，否则会被吞），
并建好 DNS CNAME。用的命令：
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
& D:\Stelarith\Stelarith-xingjikong-qt\scripts\add-cloud-ingress.ps1 -ApiToken <CF_TOKEN>
```

**验收（已实测）**：
| 请求 | 结果 |
|---|---|
| `https://control.245959623.xyz/api/devices`（无令牌） | **401** ✅ |
| 同上（带 `CLOUD_VIEWER_TOKEN`） | **200**，`count=1 …TEST1 online` ✅ |
| `wss://control.245959623.xyz/ws/viewer` | 连接建立 ✅ |

> ⚠️ **坑（已修，记录备查）**：ingress 是**从上往下先命中先生效**，
> 隧道里本就有 `*.245959623.xyz → 8096` 的通配规则 —— 云端规则若排在它后面会**永远匹配不到**。
> 脚本已改为**插在第一条通配规则之前**。
> 另：CF 令牌若开了 **Client IP Address Filtering**，会报
> `403 code 9109 Cannot use the access token from location` —— 需在后台关掉或用无 IP 限制的 `cfut_` 令牌。

### 顺带清理（✅ 已做，2026-10-05）
隧道里原有的 `*.245959623.xyz → 8096`（**CIMS，已退役**）**已删除**。

## 2. 换掉开发令牌（**公网上线前必须做**）

现在的令牌是 `dev-cloud-token` / `viewer-3f1c…`，**一旦上公网等于把门敞开**（任何人可发指令、可看教室机实时画面）。
先在云端**换成强随机**，再往下走：

```powershell
# 生成三把强随机（32 字节 = 256 位，密码学安全随机）
function New-HexToken([int]$Bytes = 32) {
  $b = New-Object byte[] $Bytes
  [System.Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($b)
  ($b | ForEach-Object { $_.ToString('x2') }) -join ''
}
"CLOUD_WS_TOKEN=$(New-HexToken)"
"CLOUD_VIEWER_TOKEN=$(New-HexToken)"
"CLOUD_VIEWER_SECRET=$(New-HexToken)"
```

把三行写进 `D:\Stelarith\Stelarith-cloud-ws\.env`（替换旧的），重启云端：
```powershell
Stop-ScheduledTask -TaskName StelarithCloud; Start-ScheduledTask -TaskName StelarithCloud
# 或直接： taskkill /f /im node.exe  （确认那台就是云端）后由看门狗拉起
```
> ⚠️ `CLOUD_VIEWER_SECRET` 必须与**站点** `.env` 里的同名键一致（否则手机集控页登录会失败）。
> ⚠️ 换完令牌，下面装教室机/管理端时**都用新的** `CLOUD_WS_TOKEN` / `CLOUD_VIEWER_TOKEN`。

## 3. 装管理端（老师机，1 台）

1. 拷贝 `Stelarith-viewer-qt\deploy\` 整个目录到老师机。
2. 编辑同目录 `viewer.env`：
   ```ini
   set "STE_VIEWER_URL=wss://control.245959623.xyz/ws/viewer"
   set "STE_VIEWER_TOKEN=<上面生成的 CLOUD_VIEWER_TOKEN>"
   ```
3. 双击 `viewer-qt.exe`，设备列表应出现教室机。

（也可用 `Stelarith-viewer-qt\msi\stelarith-viewer-msi.msi` 安装。）

## 4. 装教室机（**一台一条命令**，不需要 AI）

把两样东西拷到 U 盘/共享盘：
- `Stelarith-control-qt\dist\stelarith-agent-setup.exe`
- `Stelarith-xingjikong-qt\scripts\install-classroom-agent.ps1`

到教室机（**管理员 PowerShell**）：
```powershell
cd <放这两个文件的目录>
powershell -NoProfile -ExecutionPolicy Bypass -File .\install-classroom-agent.ps1 `
  -Uid  class_xlzx_2028_08 `
  -CloudUrl wss://control.245959623.xyz/ws/agent `
  -Token <上面生成的 CLOUD_WS_TOKEN>
```
> 用 `-ExecutionPolicy Bypass` 是为了绕开"未签名脚本"限制（脚本默认不带签名）。
脚本会自动：停旧件 → 静默装 → 写 `agent.env` → 重启自启任务 → 自检并打印日志尾部。
**先加 `-WhatIfOnly` 干跑一遍确认参数**，再去掉它真装。

> uid 命名：`class_<校简称>_<届>_<班号>`（例 `class_xlzx_2028_08`）；**每台唯一**、全小写。

## 6. 之后每次升级（OTA）

1. 用新版 `ota.json` 声明最新版本（模板见 `docs\OTA-发布与升级说明.md`）。
2. 下发：
   ```powershell
   curl.exe -X POST https://control.245959623.xyz/api/instructions `
     -H "Authorization: Bearer $t" -H "Content-Type: application/json" `
     -d '{"uid":"class_xlzx_2028_08","action":"self_update","params":{"url":"https://control.245959623.xyz/ota/stelarith-agent-setup-0.5.x.exe","sha256":"<64位>","version":"0.5.x"}}'
   ```
3. 看该机 `version` 变化即成功。

> ⚠️ **首次升级例外**：任何跑 `0.4.0-v1` 的机器**没有 OTA 能力**，必须先**重装**到 0.5.0（本手册第 4 节）。
