# 星集控 · 配置与凭据清单

> 版本 v0.5.0。本清单是**唯一入口**：所有环境变量、凭据、生成方法与存放位置一览。
> 生产上线前，请把本表中所有「内置开发值」替换为**强随机生产值**。

---

## 1. 凭据一览与流转关系

```
                    ┌────────────────────────────────────────────┐
   CLOUD_WS_TOKEN ──┤ 云端 .env                                  │
        │           │   → 校验 agent 的 STE_QT_WS_TOKEN          │
        └───────────┼─ 被控端 agent.env 的 STE_QT_WS_TOKEN        │  ← 必须一致
                    └────────────────────────────────────────────┘

   CLOUD_VIEWER_TOKEN ─ 云端 .env
        │   → 校验 viewer 的 STE_VIEWER_TOKEN（桌面管理端长期令牌）
        └─ 也用于云端 /api/* 管理面 HTTP 鉴权（Bearer）

   CLOUD_VIEWER_SECRET ─ 云端 .env
        └─ 与站点 .env 的 CLOUD_VIEWER_SECRET **必须一致**
           （站点据此签浏览器短票据，云端据此验签）
```

一句话：**令牌成对**。改云端一处，对应客户端必须同步改，否则连不上/被 401。

## 2. 云端环境变量（`.env`）

文件位置：`Stelarith-cloud-ws\.env`（由 `node --env-file=.env` 加载；**不入版本库**）

| 键 | 默认 | 生产要求 | 说明 |
|---|---|---|---|
| `CLOUD_WS_PORT` | 8788 | 保持或按需 | 监听端口 |
| `CLOUD_WS_HOST` | `0.0.0.0` | 同机反代建议 `127.0.0.1` | 监听地址；`0.0.0.0`=公网可达 |
| `CLOUD_WS_TOKEN` | `dev-cloud-token` | **必须换** | 被控端接入令牌 |
| `CLOUD_VIEWER_TOKEN` | 回落到 `CLOUD_WS_TOKEN` | **必须单设** | 管理端长期令牌 + HTTP 管理面 Bearer |
| `CLOUD_VIEWER_SECRET` | 空（票据通道关闭） | **必须设，且与站点一致** | 浏览器短票据 HMAC 密钥 |
| `CLOUD_HEARTBEAT_TIMEOUT_MS` | 30000 | 保持 | 30s 无心跳/帧判离线 |
| `CLOUD_SWEEP_INTERVAL_MS` | 5000 | 保持 | 离线清扫周期 |
| `CLOUD_EVENTS_FILE` | `events.log` | 保持 | 事件流水文件（会增长，见运维手册日志轮转） |
| `CLOUD_QUEUE_DB_FILE` | `instruction-queue.db` | 保持 | 指令队列落盘库 |
| `CLOUD_OTA_MANIFEST_FILE` | `ota.json` | 保持 | OTA 清单路径 |
| `CLOUD_PENDING_TTL_MS` | 86400000 | 保持 | 未回执指令 24h 过期 |
| `CLOUD_PENDING_MAX_PER_DEVICE` | 50 | 保持 | 单机未回执上限 |
| `CLOUD_PROTOCOL_MODE` | `v1-compat` | 保持 | 协议兼容模式 |

> ⚠️ 云端启动会自检 `CLOUD_WS_TOKEN` / `CLOUD_VIEWER_TOKEN` / `CLOUD_VIEWER_SECRET`，
> 仍为内置值或为空时打印告警。**生产日志里出现告警即为未完成上线配置。**

## 3. 被控端环境变量（`agent.env`）

文件位置：`C:\Program Files\Stelarith\agent.env`（由安装器写入；纯 `set KEY=VALUE` 行）

| 键 | 默认 | 说明 |
|---|---|---|
| `STE_QT_WS_URL` | `ws://127.0.0.1:8788/ws/agent` | 云端地址；公网应为 `wss://` |
| `STE_QT_WS_TOKEN` | 空 | 必须与云端 `CLOUD_WS_TOKEN` 一致；空则被控端拒绝启动并**明确报错** |
| `STE_QT_UID` | 机器名 | 设备唯一代号，建议「班级-座位」 |
| `STE_QT_SHOT_DIR` | 安装目录\shots | 本地存图目录 |
| `STE_QT_HEARTBEAT_MS` | 10000 | 心跳间隔（云端会下发覆盖） |
| `STE_QT_OTA_DISABLE` | 未设（=开） | 设任意值则**硬关本机自更新**（应急） |
| `STE_QT_LOG` | `%LOCALAPPDATA%\xingjikong\agent-qt.log` | 日志路径 |

> 优先级：**已存在的环境变量 > agent.env 文件**。故 `start-agent.bat` 里把 token 留空，避免占位符覆盖真实值（历史踩坑）。

文件位置：`viewer-qt.exe` 同目录的 `viewer.env`

|---|---|---|

## 5. 强随机值生成方法

### Windows（PowerShell / CMD）
```bat
rem 32 字节 → 64 位十六进制
powershell -NoProfile -Command "[guid]::NewGuid().ToString('N') + [guid]::NewGuid().ToString('N')"
rem 或 node：
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

### Linux / macOS
```bash
openssl rand -hex 32
```

### 校验 sha256（OTA 用）
```bat
certutil -hashfile stelarith-agent-setup.exe SHA256
```
```bash
sha256sum stelarith-agent-setup.exe
```
（取输出的**小写十六进制 64 位**，填进 `ota.json` 的 `sha256`）

## 6. 生成后必须同步更新的位置（对照表）

| 改了哪里 | 必须同步改 |
|---|---|
| 云端 `CLOUD_WS_TOKEN` | 每台被控端 `agent.env` 的 `STE_QT_WS_TOKEN` |
| 云端 `CLOUD_VIEWER_TOKEN` | 每台管理端 `viewer.env` 的 `STE_VIEWER_TOKEN` |
| 云端 `CLOUD_VIEWER_SECRET` | 站点 `.env` 的 `CLOUD_VIEWER_SECRET` |
| 云端 `CLOUD_WS_HOST` | 反代 upstream / 防火墙（见部署手册第三节） |
| 发布新版本 | `ota.json`（version / url / sha256 / size） |

## 7. 凭据存放与保密纪律

- **绝不入库**：`.env`、`agent.env`、`viewer.env` 已在各工程 `.gitignore` 中。
- **分发**：`agent.env` 随安装器写入，避免人工编辑（会漏、会写错）。
- **轮换**：令牌泄露时，按上表成对替换后**重启对应进程**即可，无需重装。
- **不要**把生产令牌写进任何 `.bat` / `.ps1` / 安装器默认值（安装器默认值仅供调试）。

## 8. 尚未支持（如需请告知）

1. **多令牌/分校隔离**：当前云端只认**单把** `CLOUD_WS_TOKEN`，无法按学校/班级分权。
2. **令牌轮换不停机**：当前换令牌需重启云端（旧连接断开后按新令牌重连）。
3. **被控端 TLS 客户端证书**：当前只做令牌鉴权，未上双向 TLS。
