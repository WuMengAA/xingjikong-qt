## 一 新增 / 修改文件清单

### 1. `Stelarith-viewer-qt/src/viewerbackend.h` （E4，C++ 元对象）
- 新增两枚 Q_PROPERTY（紧接 `currentUid` 之后）：
  - `Q_PROPERTY(int themeMode READ themeMode WRITE setThemeMode NOTIFY themeModeChanged)`
  - `Q_PROPERTY(bool systemDark READ systemDark NOTIFY systemDarkChanged)`
- public 段新增内联 getter + 声明：
  - `int themeMode() const { return m_themeMode; }`
  - `void setThemeMode(int m);`
  - `bool systemDark() const { return m_systemDark; }`
- signals 段新增：`themeModeChanged(int)` / `systemDarkChanged(bool)`
- private 段新增成员：
  - `int m_themeMode = 0;`        // 0 浅色 / 1 深色 / 2 跟随系统
  - `bool m_systemDark = false;`  // 跟随系统档的 OS 深色判定

### 2. `Stelarith-viewer-qt/src/viewerbackend.cpp` （E4，C++ 实现）
- 新增 `#include <QStyleHints>`（构造函数里用 `QGuiApplication::styleHints()->colorScheme()`）。
- 构造函数 `loadPrefs()` 之后：
  - 从 `QSettings ui/themeMode` 读回 `m_themeMode`（默认 0 浅色，`qBound` 夹到 [0,2]）。
  - 取 `QGuiApplication::styleHints()->colorScheme()` 初始化 `m_systemDark`；
    连 `QStyleHints::colorSchemeChanged` → 变化时更新 `m_systemDark` 并 `emit systemDarkChanged`。
- 新增 `ViewerBackend::setThemeMode(int m)`：夹到 [0,2]，无变化早退，变化则写回
  `QSettings ui/themeMode` 并 `emit themeModeChanged`。

### 3. `Stelarith-viewer-qt/qml/Main.qml` （E4 + E5，QML）
- **E4 · 主题派生（L59-62）**：`darkMode` 由 `property bool` 改为 `readonly property bool`，
  由 `backend.themeMode` 派生：`===1` 深 / `===2` 取 `backend.systemDark` / 其它（0）浅。
  所有界面读 `darkMode` 不变；旧 4 处 `root.darkMode = true/false` 全部改为 `backend.themeMode = 1/0`。
- **E4 · 设置页外观卡（约 L1873-1918）**：原「黑白/浅色」两块 → 三档
  `Repeater`：`浅色(m:0) / 深色(m:1) / 跟随系统(m:2)`，选中块边框走 `th.inv`，
  点击 `backend.themeMode = modelData.m`（写回即持久化）。
- **E4 · 命令面板（L2848-2850）**：原两条 → 三条，`dark/light` 改设 `themeMode=1/0`，
  新增 `auto/xitong/xt` 设 `themeMode=2`。
- **E5 · 概览页顶部统计（约 L381-400）**：模型由
  `[在线:onlineCount, 已收帧:frameCount]` → `[在线:onlineCount, 待办:storage.pendingInstructions, 离线:storage.offlineDevices]`；
  更正原「待办和离线算不出来」的陈旧注释（backend.storage 现已下发）。

## 二 与旧实现的行为差异
- 启动默认外观：旧 = 永远深色（darkMode 硬编码 true）；新 = 浅色（themeMode 默认 0）。
- 主题切换：旧 = 仅「深/浅」两态、不持久化（重启回深色）；新 = 三档且落 QSettings，重启保持。
- 「跟随系统」：旧 = 无；新 = 读 OS 配色（`QStyleHints::colorScheme`），切换实时跟随。
- 概览页顶部：旧 = 只有在线/已收帧；新 = 在线/待办/离线（待办=待执行指令，离线=离线设备数）。

## 三 端点 / 接口迁移对照
- 新增 C++ 属性 `backend.themeMode(int)` / `backend.systemDark(bool)`；QML 全用这两个，未动其它后端接口。
- `backend.storage.pendingInstructions` / `backend.storage.offlineDevices` 为既有属性（存储卡已用），E5 仅复用。
