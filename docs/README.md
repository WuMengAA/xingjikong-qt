## 一、快速上手（最短路径）

1. 读《上线部署手册》第 1–2 节 → 把云端跑起来（`run-cloud.cmd`）。
2. 读《配置与凭据清单》第 5 节 → 生成三把强随机令牌，填进 `.env`。
3. 读《上线部署手册》第 3 节 → 上 TLS 反代（`wss/https`）。
4. 读《上线部署手册》第 4–5 节 → 装被控端与管理端，改 `agent.env` / `viewer.env`。
5. 读《上线部署手册》第 6 节 → 逐项验收。

## 二、上线前必须回答的问题（需环境资源）

以下资源需由你提供，给齐即可开工：

1. 服务器（系统 / 公网 IP 或隧道 / 远程方式）
2. 域名 + DNS 解析权
3. TLS 证书（或可自动签发）
4. 反代选型（Nginx / Caddy / Cloudflare Tunnel）
5. OTA 安装包托管位
6. 班级与设备命名规则 + 设备清单
7. 令牌策略（全校共用 / 分权）
8. 站点线是否协同（`CLOUD_VIEWER_SECRET`）

详见《上线部署手册》第 7 节。

## 三、本版本（v0.5.0）相较上一版的关键变化

- **云端监听地址可配**（默认 `0.0.0.0`，可收回 `127.0.0.1`）——公网部署的前提。
- **云端管理面鉴权收紧**：`/api/frame`（实时画面）、`/api/events` 等纳入令牌校验，此前裸奔。
- **指令队列落盘**：设备重连按序补发，云端重启不丢。
- **OTA 落地**：云端版本清单 + 检查接口；被控端 `self_update` 下载 / 校验 / 静默自更新。
- **三端版本号统一**为 `0.5.0`（此前 exe 报 `0.4.0-v1`、安装器写 `0.5.0`，不一致）。
- **被控端 RTC 自愈 + 按需回收 WebEngine**（无人看时省内存）。
