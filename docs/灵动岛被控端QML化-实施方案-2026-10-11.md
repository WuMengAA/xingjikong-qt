- **任务中心**：per-task 暂停/取消/详情/优先级

## 四、架构

### 4.1 目录（单端，不建共享目录）

```
Stelarith-control-qt/
├─ qml/                                    ← 新建
│   ├─ Main.qml                            孪生宿主（被 QQuickWidget 加载）
│   └─ island/
│       ├─ IslandRoot.qml                  岛根：形态/几何/主题
│       ├─ IdleBar.qml                     空闲半胶囊（HH:mm + 横杠 + 箭头）
│       ├─ ActiveBar.qml                   收起/居中/全屏三形态绘制
│       ├─ StateList.qml                   多状态列表（清单 #2）
│       ├─ MarqueeText.qml                 跑马灯（替代 m_marqueeX）
│       ├─ IslandClock.qml                 时钟（替代自绘 HH:mm）
│       ├─ WhaleMascot.qml                 鲸鱼娘（清单 #1）
│       ├─ ActionButton.qml                动作按钮
│       └─ Theme.qml                       色令牌（严重度/深浅/字号）
├─ resources/whale/                         ← cp 自 viewer（源不动）
└─ src/island.cpp                           ← 瘦身为宿主 + 桥
```

**不建 `Stelarith-shared-qml/`**：只有一端用，共享目录只增加认知成本。

### 4.2 分层（系统层 C++ 不动，视觉层 QML）

```
IslandOverlay : QWidget          ← 保留：无边框/置顶/穿透/几何动画/生命周期
  └─ QQuickWidget                ← 唯一新增
       └─ island/IslandRoot.qml
  └─ IslandBridge : QObject      ← Q_PROPERTY 桥（新增）
```

### 4.3 公开接口**一个都不改**（最高优先级风险控制点）

`island.h` 全部 12 个公开方法 + 1 个信号**保持签名逐字不变** ⇒ `main.cpp` 5 处调用点 + `notifyFromParams` **零改动**。

这是硬约束。任何需要改 `main.cpp` 的方案都视为越界，退回重设计。

### 4.4 桥（数据怎么流）

```cpp
class IslandBridge : public QObject {
    Q_OBJECT
    Q_PROPERTY(QString title    READ title    NOTIFY changed)
    Q_PROPERTY(QString desc     READ desc     NOTIFY changed)
    Q_PROPERTY(QString icon     READ icon     NOTIFY changed)
    Q_PROPERTY(QString form     READ form     NOTIFY changed)   // capsule|centered|fullscreen
    Q_PROPERTY(QString severity READ severity NOTIFY changed)   // ""|urgent|inform|remind
    Q_PROPERTY(bool    light    READ light    NOTIFY changed)
    Q_PROPERTY(bool    idle     READ idle     NOTIFY changed)
    Q_PROPERTY(bool    expanded READ expanded NOTIFY changed)
    Q_PROPERTY(QVariantList states READ states NOTIFY changed)  // 多状态聚合（清单 #2）
    Q_PROPERTY(QVariantList actions READ actions NOTIFY changed)
    Q_INVOKABLE void fireAction(const QString &label);          // QML 按钮 → C++ 回调
    Q_INVOKABLE void requestExpand(bool on);                    // 手势 → C++
};
```

QML 绑 `bridge.*`；手势回 `bridge.requestExpand()` / `fireAction()`。

## 五、风险与代价

### 5.1 已知代价

| 项 | 代价 | 缓解 |
|---|---|---|
| **exe 体积** | **+15~25MB**（Qt Quick + Controls2 + QML 插件 DLL） | 最大代价。现包约 27.5MB → 45~52MB。**实际要编出来才知道** |
| 首启耗时 | QML 引擎初始化 ~100ms | 一次性，岛是常驻件 |
| 部署 | `windeployqt` 要带 Quick 插件（`platforms`/`imageformats`/`qml/` 目录） | 已有 windeployqt 流程，加参数；**NSIS 的 DLL 通配只吃 `Qt6*`** ⇒ `qml/` 目录要显式处理 |
| **鼠标穿透** | 空闲态 `WA_TransparentForMouseEvents`（不挡课件）在 QQuickWidget 上语义不同 | **最大的技术不确定点**，见 §5.2 |
| 热更 | QML 走磁盘加载 ⇒ 改外观不用重编 | 额外收益（但被控端单实例守卫 + 构建 POST_BUILD 覆盖，需同步源码→副本，见项目笔记 §3） |

### 5.2 三个必须实测的点（不装懂）

1. **穿透语义**：空闲态要穿到下层。QQuickWidget 是子 widget，可能需要「宿主窗口 `WA_TransparentForMouseEvents` 动态开关 + QML 侧 MouseArea」的组合。**批次 3 第一个验证点。**
2. **体积实际值**：+15~25MB 是估算。
3. **窗口标志兼容**：`IslandOverlay` 构造里的 `Qt::FramelessWindowHint | WA_TranslucentBackground` 等要逐条核对，圆角+阴影在 QML 下要重做。

### 5.3 为欠账留口子（不做，但架构别堵死）

- 多状态 `states` 用 `QVariantList` ⇒ 未来任务中心/历史通知可直接扩字段
- `fireAction` 是通用回调 ⇒ 未来内联操作/预设模式不用改桥
- `MouseArea` 分层 ⇒ 六手势可逐个加，不用重构
- **不引 SQLite、不引本地 WebSocket**——那是另外的立项

### 9.3 本批次踩到并修掉的三个坑（写进代码注释，防回退）

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| 1 | 岛被拉满父宽，`implicitWidth` 96/320/400 全失效 | `Column` 会把子项拉到父宽 | Showcase 弃用 Column，改逐个 `anchors.top` 定位 + `width: implicitWidth` |
| 2 | 岛被压扁，展开态只 200px、动作按钮贴列表 | `shell` 用 `anchors.fill: parent` + `root.implicitHeight` 靠内容推导 ⇒ 循环依赖 | `IslandRoot` 改显式三段式（headH/listH/actH 相加），不用隐式推导 |
| 3 | 浅色态整个岛被染成米色 | 严重度色 `anchors.fill` + `opacity:0.35` 铺满 | 改**只做顶部 3px 细条**（`island.cpp` 是整底同色，QML 铺满会连文字一起染） |

另有两个 QML 语义坑：`states` 与 `QQuickItem` 基类属性重名（改 `items` / `stateItems`）；`Repeater` 的 `model` 传 int 时 `modelData` 不存在（改 `index` 索引取）。

### 11.1 文字方框（tofu）全链路定论

**结论：tofu 是离屏平台字体库为空导致的，QML 代码零问题。**

实验：在探针 `main()` 里、`IslandOverlay::instance()` **之前**，显式注册系统字体

```cpp
int fid = QFontDatabase::addApplicationFont(QStringLiteral("C:/Windows/Fonts/msyh.ttc"));
QStringList ffams = (fid >= 0) ? QFontDatabase::applicationFontFamilies(fid) : QStringList();
if (!ffams.isEmpty()) app.setFont(QFont(ffams.first()));
```

| 指标 | 注册前 | 注册后 |
|---|---|---|
| `addApplicationFont` 返回 | — | `0`（成功） |
| `QFontDatabase::families().size()` | **0** | **2** |
| `hasFamily("Microsoft YaHei")` | MISSING | **HAVE** |
| 截图中文 | tofu 方框 | **全部正常**（"考试模式已开始" / "本次考试 45 分钟，请勿切换窗口" / "知道了" / "需要帮助"） |

**机理**：离屏平台（`QT_QPA_PLATFORM=offscreen`）**不枚举系统字体**，`families()` 恒 0，Qt 回落到内置的 fallback 字体 ⇒ 无 CJK 字形 ⇒ tofu。显式注册后字体库有内容，QML `Text` 的默认字体即取到中文。
**生产环境（有窗口系统）一直能枚举系统字体** —— 原手绘版 `island.cpp` 的中文从来正常，这是同一套字体路径。**此前的"未验证"就此关闭，不再是风险项。**
