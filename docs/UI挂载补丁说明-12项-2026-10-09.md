## 补丁 2：接 RtcVideoSurface（集控页大画面区）

**目标**：`frameSource === "rtc"` 时用 RtcVideoSurface 显示实时画面，
否则保留现有 frame 通道（jpeg 轮询）。

**现状（grep 实测）**：
- `backend.frameSource` 已有 `"rtc" | "jpeg" | "wait"` 三态（UI 徽标/角标在用）
- 大画面显示仍走 `image://frames`（frameReady 门控）
- RtcVideoSurface.qml 已造（qmllint 通过），**未被引用**

**插入位置**：集控页大画面 Image 处（L1047 附近 `frameSource` 分支的显示层）。

**插入代码**（照抄）：
```qml
// WebRTC 实时画面：rtc 态用 RtcVideoSurface，其余走 frame 通道
RtcVideoSurface {
    id: rtcSurface
    visible: backend.frameSource === "rtc"
    anchors.fill: parent   // 与大画面同区域
    theme: root.th
    onFrameReady: { /* 接线层把 ldc_receiver.frameReady 转这里 */ }
}
```

**接线联动**（等 ldc_receiver 接入 viewerbackend 后）：
- viewerbackend 在 `ldc_receiver.frameReady(img)` 信号里调 `rtcSurface.onFrame(img)`
- 大画面 Image 的 `visible` 改为 `backend.frameSource !== "rtc"`（rtc 时藏帧通道）

**前置依赖**：`frameSource` 变 "rtc" 需被控端 WebRTC 接入（ldc_streamer 接线）
——**当前被控端未接，frameSource 实际是 "jpeg"**，故本补丁挂上后 RtcVideoSurface
处于隐藏态（不破坏现状），等 WebRTC 通了自动生效。
