# 灵动岛 G2 圆角 + 大卡片版式 · 加减归档（2026-10-17）

> 用户原话：「修一个问题：有很多通知样式，但大多数不符合审美 / 灵动岛需要G2圆角」。
> 取证后发现这不是审美分歧 —— 是**两个真 bug**：`centered`/`fullscreen` 两档在 QML 里
> 根本没有版式，落进胶囊分支；以及外壳用 `Rectangle.radius`（圆弧，曲率不连续）。

---

## 一、根因（先证，不猜）

### 1.1 「很多通知样式不符合审美」的真身：两档形态没有版式

`IslandOverlay::paintEvent()` 第一句：

```cpp
if (m_quick && m_quick->status() == QQuickWidget::Ready) return;   // QML 就绪 ⇒ C++ 什么都不画
```

⇒ **所有形态都由 QML 画**。但 `IslandRoot.qml` 此前只有 `capsule / banner / mini` 三套版式，
`_formKind === "centered"` 落进最后的 else 分支：

```qml
radius: ... : (root._expanded ? 18 : height / 2)     // ← 520×200 的卡片套到 height/2 = 100
```

后果（探针截图实证，`_probe/shots/island-form-guard.png`）：

- 520×200 的窗口被画成"两个巨圆弧 + 中间一片黑"；
- 内容按 320 宽的胶囊排（`csTitle` 的 `rightMargin: 42`、按钮 `padH + 40` 都是胶囊口径）；
- 动作按钮跑到左下角、被窗口边缘裁掉 —— 老师点了也点不到。

`fullscreen` 同理：铺满屏的窗口套 320 宽排版 ⇒ "一片黑，字挤在顶部"。

### 1.2 「G2 圆角」：`Rectangle.radius` 画的是圆弧

圆弧与直边的接缝处曲率从 `1/r` 突跳到 `0`，大圆角/浅底/大面积上能看出一道折。
G2（曲率连续 / squircle）让曲率沿边平滑过渡，角是"长出来的"。

⚠️ 被控端**不能用 `QtQuick.Shapes`**：部署树里 `qml/QtQuick/Shapes/` 只有 `DesignHelpers`、
没有 `qmlshapesplugin.dll`，exe 旁也没有 `Qt6QuickShapes.dll` —— 与 QtQuick.Controls 缺
C++ 后端同一类问题。⇒ 只能用 `Canvas`（QtQuick 基础类型）。

## 二、改法

### 2.1 新增：G2 圆角容器 `IslandSurface.qml`（135 行）

- 形状 = **直边 + 四角超椭圆**（`|x/a|^n + |y/b|^n = 1` 的四分之一段）：
  `X = r·(sin t)^p, Y = -r·(cos t)^p, p = 2/n`，`n = 5`（观感接近 iOS squircle）。
- ⚠️ **不能整体做超椭圆**：1280×72 的横幅整体超椭圆会变"橄榄形"，不是圆角矩形。
- `renderTarget: Canvas.Image`（不是默认 FBO）：教室机可能软件渲染/老显卡，Image 模式最不容易出黑块。
- 参数：`radius / fillColor / strokeColor / strokeWidth / superness / cornerSteps`；
  `default property alias content` ⇒ 子项照常写进去。
- ⚠️ 描边时路径内缩半个线宽（否则线被画布边缘裁一半，观感"缺角"）。

**踩坑（本批最贵）**：左下/左上两个角的 `sin/cos` 写反了 ⇒ 起点接不住上一条 `lineTo`
的落点 ⇒ 路径自交，非零填充规则把左侧挖空，截图表现为"左上/左下露白三角"。
判据：**曲线起点必须等于前一段 `lineTo` 的落点**，逐个角核对 t=0 与 t=π/2 的落点。

### 2.2 新增：两张面

| 文件 | 行数 | 版式 |
|---|---|---|
| `IslandCardFace.qml` | 117 | 居中卡片：图标 34（按 severity 染色）→ 标题 24 DemiBold（≤2 行）→ 描述 14（≤3 行）→ 按钮行；整块 `Column.centerIn`，内容宽 `min(width-48, 420)` |
| `IslandFullscreenFace.qml` | 109 | 全屏公告：图标 56 → 标题 36 Bold（≤3 行）→ 描述 18（≤4 行）→ 按钮 `scale 1.35`（`transformOrigin: Center`，否则放大后整体偏右下）；内容宽 `min(width*0.72, 900)`，全文垂直居中 |

两者都显式接 `th / icon / title / desc / severity / actions / bridgeRef`（隐式作用域不会跟着搬进独立文件），
按钮统一用既有 `ActionButton`（`role: primary/secondary`）+ `bridgeRef.fireAction`。

### 2.3 改：`IslandRoot.qml`（+90/−12）

1. 新增判据 `_bigForm = (centered || fullscreen)`；
2. **外壳 `Rectangle` → `IslandSurface`**，圆角六档：
   `idle → h/2 ｜ mini-orb → h/2 ｜ mini 方牌 → 28 ｜ banner → 20 ｜ centered → 24 ｜ fullscreen → 28 ｜ 胶囊 → h/2 / 18`；
3. 实例化两张面，`visible` 绑 `_formKind`；
4. **让位**（防两套版式叠字/叠按钮）：
   - 胶囊内容：`visible: !_idle && !_compactForm && !_bigForm`
   - 根级动作行：`showActions: _showActionsNow && !_bigForm`（卡片自己画按钮）
   - 鲸鱼：`visible: !_compactForm && !_bigForm`（全屏会冒一颗标题气泡重复正文；卡片里像贴纸）
5. **全屏 severity 底色**（`urgent` 红 / `inform` 琥珀 / `remind` 绿，alpha 210/205 与 C++ 手绘版逐字一致）；
   Centered **不**换底（只靠顶条 + 图标色），与手绘版同口径；
6. 严重度顶条左右内缩到 `shell.radius` 之外 + 自身 `radius: height/2` —— 原本直角细条铺满宽度，
   会在圆角段切出一条直线（"角上贴了个方片"）。

### 2.4 改：`island.cpp`（+89/−24）

1. 新增 `steG2Path(QRectF, radius, superness=5.0)` —— 与 QML 同口径的 C++ 版（`superness 5.0` / 每角 10 段，
   **双绘 parity**：不同步的话 QML 挂掉退回手绘时角会突然变形）；
2. 4 处 `addRoundedRect` → `steG2Path`：paintBigForm 主卡片（20/16）、paintCompactForm（20/28/half）、
   空闲胶囊（h/2）、活动态胶囊（24）；按钮那处（`bp.addRoundedRect(r, 10, 10)`）**不改** —— 28px 高的按钮上 G2 无视觉收益；
3. **Centered / Fullscreen 改用 `availableGeometry`**：
   - Centered 原来按整屏 `geometry()` 居中 ⇒ 任务栏在左 48px 时卡片视觉偏左（真机实测 593 → 修后 **617**）；
   - Fullscreen 原来按整屏铺（1659×912@24,24）⇒ **压住左侧任务栏 24px**（老师想点任务栏得先关通知），
     修后 **1611×912@(72,24)**；
   - 顺带删掉本函数里已无用的 `const QRect sg = screen->geometry()`。

### 2.5 改：验证设施

- `scripts/_island_qml_probe.cpp`：`--form` 增 `centered|fullscreen`（各带一条代表性文案 + severity）；
- `main.cpp`：`STE_QT_ISLAND_DEMO_FORM` 增同两档（真机验证用，日常不设零影响）；
- 门禁 `test-island-forms.mjs`：**13 → 21 断言**，新增 6 条：`_bigForm` 覆盖、内容/动作行让位、
  两张面存在且接线、外壳必须是 `IslandSurface`、G2 容器禁用 `QtQuick.Shapes`、圆角覆盖五档。

## 五、未做到 / 已知限制

1. **没重新出包**。`stable` 上的 **0.6.44 是本批之前的构建**（不含 G2 与大卡片版式）。要让它到教室机，
   必须 bump（0.6.45）→ 重编 → 打包 → 再发 stable。这是线上发布，等指令（stable 刚在 30 分钟前发过 0.6.44，
   太密的版本会让设备反复重启）。
2. **真机只验了几何与日志**，没有截取屏幕像素（取证避让：不动桌面）。G2 的"曲率连续"是**视觉属性**，
   机器只能验"用了超椭圆路径"（门禁 + 截图人工看），不能验"看着顺"。
3. **Centered 卡片在窄屏（<300px）未测**：`min(parent.width - 48, 420)` 在 240 宽时会退化成 192，
   文字可能挤 —— 目标机型是教室大屏，暂不处理。
4. **Fullscreen 按钮 `scale: 1.35` 的点击区**未真机点验（`scale` 不改 `implicitWidth`，
   MouseArea 仍按原尺寸吃事件 ⇒ 视觉放大后边缘 5px 可能点不到）。
5. 胶囊档 `radius = height/2` 时超椭圆几乎退化成椭圆（`Rectangle.radius` 与 G2 在这一档差异极小），
   所以"圆角更顺"的收益主要体现在 Banner(20) / Card(24) / Fullscreen(28) 三档。
