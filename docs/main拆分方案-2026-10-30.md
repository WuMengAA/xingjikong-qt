# main.cpp 拆分方案（2026-10-30）

对象：`Stelarith-control-qt/src/main.cpp` —— **9026 行 / 74 个全局 / 113 个 static 函数**。
动因：用户点名「你也没有真正前端后端分离」；策略层（如"3 次噪音才上报"）埋在 lambda 里，
不起整个进程 + 连 WS 就无法验证。

配套禁令已写进 `AGENTS.md`（§0 之后）：**main 只做装配；行数只许降不许升**，
由 `scripts/check-main-size.mjs` + `scripts/fixtures/main-size-baseline.json` 强制。

---

## 一、拆分原则（避免越拆越乱）

1. **纯搬迁优先**：先搬「无 main 全局依赖」的完整函数簇，不动逻辑。每刀编译通过 + 提交。
2. **不回头重构老代码**：搬到新文件里的代码保持原样（含注释），只改 `static` 与声明位置。
3. **每刀一个提交**：便于 review 与回滚；台账同步下调。
4. **依赖用注入，不用 extern 扩散**：新模块不 `extern` main 的全局变量；需要什么从构造参数传。
5. **先易后难**：按「依赖数 × 行数」排序，先切独立小簇。

## 三、第一刀（TTS）实测评估

**可行性：高。** 依赖清点（全部是既有独立模块，不需要 main 的任何全局）：

| 依赖 | 来源 | 说明 |
|---|---|---|
| `EdgeTts::instance()` | `src/edge_tts.h` | 单例，自带 finished/failed |
| `setSystemMasterVolume()` | `src/system_volume.h` | 系统主音量 |
| `AgentSettings::voiceEnabled()` / `notifyVolume()` | `src/core/AgentSettings.h` | 静态配置入口 |
| `speakTextSapi()` | main.cpp:3575 | **同簇搬迁**（仅被 speakText 调用） |
| `g_ttsSeq` / `g_ttsCurToken` / `g_ttsCurText` / `g_ttsFallbackWired` / `g_ttsFinishedWired` | main.cpp:3613–3616, 3638 | **只被 TTS 内部使用** ⇒ 可直接变成新模块的静态成员 |

**目标形态**：
```
src/tts/tts_speaker.h   →  void speakText(const QString&);
src/tts/tts_speaker.cpp →  原 3599–3699 + 3575–3598 原样搬入，static 全局改为文件内匿名 namespace
```
main.cpp 侧只剩：`#include "tts/tts_speaker.h"`（调用点一行不改，函数名保持 `speakText`）。

**收益**：main 减约 125 行；TTS 的「音量抬升—超时兜底—回退 SAPI—token 去重」这套逻辑
从此可以单独测（用假 EdgeTts），不必跑整个 agent。
