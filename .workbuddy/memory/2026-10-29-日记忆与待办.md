## 三、关键技术事实（踩过的坑，别重复踩）

### QtShadcn 集成
- 要求 **Qt 6.5+**（本机 6.12.0 ✅）；MIT；49 组件
- `add_subdirectory(third_party/qtshadcn)` + 链 `QtShadcn` + `Qt6::QuickControls2`
- **`QT_QUICK_CONTROLS_STYLE=Basic` 必做**（viewer 原为 FluentWinUI3，已改）——否则组件的 background/contentItem 覆写被宿主风格吃掉，表现为"渲染了但样式全不对"的静默故障
- `find_package(QtShadcn)` **不存在**，别写假的
- `ThemeManager` **只开放 `primary` 一个覆写口**，其余 token 只读 ⇒ **不改三方 `rebuildTokens()`**
- QtShadcn 是 **static QML 模块**（`optional plugin QtShadcnplugin`、无 .dll）⇒ 真 exe 链接后正常；**裸 qml.exe 会报 plugin not found**

### 运行时验证（重大纠错）
- **"GUI 起不来"是误判**。`qml.exe` 一直能跑 offscreen
- 假阴性根因：`qml.exe` 是 **GUI 子系统程序**，QML `console.log` 走 OutputDebugString 不进 stderr
- 让输出可见的两个环境变量（实测有效）：
  ```
  QT_QPA_PLATFORM_PLUGIN_PATH=<Qt>/plugins/platforms
  QT_ASSUME_STDERR_HAS_CONSOLE=1
  ```
- 项目自带控制台壳 `Stelarith-viewer-qt/scripts/_qml_probe_runner.cpp`，**头部注释早记了这个坑**
- 教训：**判断"环境不支持"之前，先查仓库里有没有现成工具**

### 构建/门禁
- `.pragma library` 必须在**前 128 字节内**（Qt 用 `LIMIT_INPUT 128` 判定），中文注释几行就超 ⇒ 放**首行**
- `copy_directory` 是复制语义、**不删旧件** ⇒ 移走的文件会在产物里留残留，要手工清
- **configure 期的 QML 扫描结果滞后一个构建周期**（扫的是上一次的旧副本）⇒ 见报错先比对源与副本 sha256
- 门禁判同名函数**必须按 block id**（`Connections { function onX(){} }` 同名合法）；且要剥**字符串**不只剥注释

## 五、《QtShadcn 视觉铁律与架构红线》摘要（后续所有 QML 的准则）

**视觉**
1. **去边框**：绝对禁止 `border.width` / `border.color`，靠背景色差分区
2. 圆角统一 `Theme.radius.lg`（12–16）；padding/spacing 严格 8 的倍数
3. 阴影极柔（4% 黑 / blur 20 / yOffset 4），禁浓重黑边
4. 侧栏与浮层用半透明 + `MultiEffect{blurEnabled}`（毛玻璃）

**颜色**：一律 `Theme.color.*`，**禁硬编码 Hex**
background / surface / textPrimary / textSecondary / primary / destructive / disabled

**动效（果冻）**
- hover `scale 1.02` 或变色，150ms
- pressed `scale 0.95`，`Easing.OutBack`（`cubic-bezier(.34,1.7,.64,1)`），300ms
- 展开/收起 `NumberAnimation` 控 height+opacity，`Easing.OutCubic`

**架构红线**
1. QML 纯图形：禁 `WebSocket`/`XMLHttpRequest`/`JSON.parse`/复杂业务判断，数据只走 C++ `Q_PROPERTY` 或 `QAbstractListModel`
2. **禁裸用** `Button`/`TextField`，必须用 `AppButton`/`AppInput`
3. 只用 `ColumnLayout`/`RowLayout`/`GridLayout`/`StackLayout`；**禁绝对坐标 x/y**
4. **单文件 ≤300 行**，超了用 Loader 或拆组件

**组件范式**
- `AppCard`：radius lg、surface 底、无边框、弱阴影、内部 ColumnLayout + padding 16
- `AppButton`：高 40/32、radius md、primary/secondary/destructive、按压缩放 0.95 果冻回弹
- `AppDialog`：遮罩、居中 surface 卡片、radius lg、弹出 scale 0.9→1.0 + opacity
