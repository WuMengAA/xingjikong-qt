## UDP 闪传 U1 · 云端侧落地（用户点单「新增 udp 协议快速加密传输」）
- `src/udp-relay.js`（约 300 行）：帧编解码 + ChaCha20-Poly1305（node crypto 原生）+ 会话表 + dgram 8789 中继 + HELLO/PING/PONG/CLOSE + 帧率闸门 + 空闲收口 + stats。中继只按帧头 session 路由、热路径不解密；HELLO（验令牌）/PING（打时间戳）亲自解。
- 密钥协商走 WS 新消息 `udp-session`（open/close）：权限=canAccess 同「看画面」，设备不在线直拒；opened 双端下发 {sessionId, key(base64 32B), udp:{host,port}}；viewer/agent WS 断开 ⇒ closeSessionsWhere 收口（防泄漏，远控泄漏同一病）。
- 帧格式定稿：`SU`|ver|type|session(4)|seq(8)|sendTs(8)|len(2)|tag(16)|payload；AAD=整个帧头；nonce=session||seq。
- ⚠️⚠️ 设计期抓到 3 个设计级 bug（全修 + 回归断言）：① 帧头偏移重叠（seq@12/sendTs@20 啃 len@24，应 8/16/24）；② HELLO_ACK 复用请求帧头 ⇒ len 与 payload 实长不符 ⇒ bad-length；③ **nonce 重用**（HELLO_ACK 与 HELLO 同 seq=0 同密钥 ⇒ keystream 重用，XOR 两密文还原 HELLO 里的令牌）⇒ 定稿 seq 空间划分：端→中继 <2^63，中继自发帧 =2^63+计数，越界拒收。
- ⚠️ 中继**不做** seq 单调闸门——会把 U2 选择重传的合法重传挡掉；重放防护在两端（AEAD nonce + 端侧单调）。
- fail-closed：UDP_RELAY_TOKEN 空 ⇒ 中继不启动只告警（新攻击面不许 fail-open）；生产 .env 已配 24B 随机（重启生效，暂不单独重启——等 Qt 侧就绪随 U3 一次重启）。
- 测试：`npm run test:udp` 31/31；`npm run test:udp-session` 15/15（隔离实例 18096/18097 + 临时 DB 三件套）。⚠️ 坑：8096/8097 被 Stelarith-cims-eval 的 python 占着（别动别家进程，换端口）；`curl -s -o /dev/null` 对 403 也返 0 ⇒ 就绪判断必须看 HTTP code + 进程存活；v1 信封注册回包是 `registered` 不是 `registration-ok`。

## 闪传 TCP 主轴 · 云端侧落地（用户裁决「那就tcp」）
- 背景：上一轮披露 cloudflared 隧道只转 TCP、公网 UDP 不可达 ⇒ 用户裁决「那就tcp」——闪传传输层从 UDP 改 TCP 为公网主路，放弃 UDP-over-WS 封装回退。**架构收益**：专用 TCP 连接把实时/大批数据与 WS 控制+心跳彻底分离 ⇒ 被控端 200KB/s 背压闸（main.cpp:7337，保心跳的粗暴手段却把远控全屏首帧丢光⇒viewer 全白）和文件传输停等协议（64KB 一片一回执、零重传、15s 判死）的病根一起去掉。
- 文件职责：`src/flash-core.js`（新建共享内核——帧编解码+AEAD+seq 空间纪律+中继自发帧构造+HELLO/PING 校验+会话存储，UDP/TCP 一份代码两处审计）；`src/udp-relay.js`（重构为消费内核，行为逐字不变，保留 addrIndex/帧率闸门/不做 seq 单调闸门，31+15 测试当护栏）；`src/tcp-relay.js`（新建约 330 行）；`src/index.js`（接线 tcp-session 协商+断线收口+listen 装配）；`src/config.js`（TCP 节：PORT 8790/HOST 0.0.0.0/TOKEN 空/IDLE 60s/HELLO 宽限 15s）。
- TCP 中继设计要点：流式分帧（每 socket 累积缓冲+按 len 切帧；半帧等下一 chunk、多帧合一 chunk 一次吃光）；HELLO 绑定 sock.__flash={sessionId,role}，重复角色拒（防跨连接 nonce 重用窗口）；严格单调闸门（f.seq<=lastSeq 即 drop——TCP 有序可靠，重放即拒兼守 nonce 不重用；UDP 则故意不做，保 U2 选择重传）；**背压不丢帧**（对端 write 返回 false⇒pause() 源 socket、对端 drain⇒resume()，pauses/resumes 计数器进 stats）；**一端断即收口**（socket close⇒closeSession('peer-tcp-gone')，onSessionClosed hook 销毁两端 socket，双端 WS 收 closed）；sock.setNoDelay+setKeepAlive(30s)；连接封顶 256；idle reaper setInterval（stop 时清）；hello grace timer unref。
- 测试：`tests/unit-tcp-relay.mjs`（41 断言）+ `tests/regression-tcp-session.mjs`（19 断言，隔离实例 18098+临时 DB 三件套联测 index.js 接线）。package.json 加 test:tcp/test:tcp-session。全套：TCP 41/41+19/19、UDP 重构护栏 31/31+15/15、云端既有 14/14。
