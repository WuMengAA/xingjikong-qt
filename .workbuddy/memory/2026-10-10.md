## 关键发现（产品级，待用户点单再修）
1. **Inno 安装器 vs StelarithAgentGuard 冲突**：guard 每 10 分钟且 agent 不在即 5s 后 `start` 重启。手动装或 OTA 自动升级时，Inno 关掉 agent 后 guard 秒级重启→exe 被锁→安装器 exit 1（文件其实已换，但 [Run] 重建任务那步报失败）。影响：受守护的生产机 OTA 升级可能失败。修法候选：安装器/OTA 流程装前停 guard 并在装后恢复；或 guard 检测到 ota 进行中（如 ota 目录有 pending）时避让。
2. **channel(gray) 不跨升级持久**：`install-autostart.ps1` 每次都 `New-ScheduledTaskAction -Execute exe`（纯 exe，无 STE_QT_CHANNEL），把任务 Action 重置成 stable；且 ota-relaunch.bat 直接 `start "" exe` 不带 channel。所以**任何升级（手动或 OTA）后，下次登录/重启设备回落 stable**，灰度失效。当前靠任务 Action / guard.bat 里手注的 `set STE_QT_CHANNEL=gray` 临时兜底（本机已重注）。修法：channel 落持久文件（如 `%LOCALAPPDATA%\xingjikong\channel.txt`），被控端读序=进程env→channel文件→stable；install-autostart.ps1 与 ota-relaunch.bat 都从该文件注入。
3. **build-agent-installer.bat 在本机 Git Bash `cmd //c` 下 exit 3 无输出**（疑似 bat 内 `for /f` findstr 解析或 setlocal 在双层 shell 下异常）；PowerShell 直调 ISCC 正常，rc.4/rc.5 均走此路。
