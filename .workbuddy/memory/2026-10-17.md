## 新踩坑（本批实证，最贵两条）

1. **PostThreadMessageW 投的 WM_DEVICECHANGE 到不了 QAbstractNativeEventFilter**
   （同法投 WM_APP 能到）；**SendMessage 到 Qt 顶层窗口能到**（真实 DBT 广播本就是
   SendMessage 到各顶层窗口 ⇒ Qt 转给过滤器）⇒ 合成消息探针必须走隐藏顶层窗口。
2. **moc 对 .cpp 输入生成的 TU 不含原文件**（只认头文件输入）⇒ QObject 探针类必须拆头
   （FakeAgentUi 拆进 `_agent_ui_probe_fakeui.h` 才过）。
3. 探针宏值必须带冒号（`"X:"`——onDriveArrived 收到的 drive 是 `X:` 形态；不带上 asking 六要素全假红）。
4. cl 链接步绝不带 /TP（.lib 当 C++ 源码编 ⇒ Qt6Core.lib 一串 C2018）；MSYS 会把 `/EHsc`
   当路径转换 ⇒ cl 参数走 Python subprocess（list）不过 shell。
5. 存量味道（未擅自改，待点单）：`md3/Md3Btn.qml:11 property bool enabled` 盖掉 Item.enabled
   ⇒ 祖先 enabled 传导失效（探针 note 留痕）。
