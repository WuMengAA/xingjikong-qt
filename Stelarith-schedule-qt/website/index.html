Features

能排课，更能管课

不只是画一张表。从日常调课到学期双周轮换，从科目维护到一键导出，都在一个界面里完成。

🗓️

课表网格

周视图 7 天 × 节次网格，时间轴左列固定。点击任一格即可换科目或清空，所见即所得。

📊

时间轴甘特图

垂直时间线显示每节时长，拖动块的上/下边缘调整开始与结束时间，松手自动吸附到 5 分钟刻度。

📚

科目管理

科目列表增删改名，被课表引用的科目自动锁定不可删，杜绝「删了科目课表变空白」。

🔄

多周轮换

每节课可配置轮换周期与周次（如双周轮换），按当前周自动显示对应课表，切换周次实时刷新。

🧩

课表群切换

多套课表装进「课表群」，一个下拉即切换班级或作息方案，无需重复编辑。

↩️

撤销 / 重做

基于 QUndoStack 的命令式编辑，误调课一键撤销（Ctrl+Z 级体验），改错不慌。

📤

CSES 导入导出

导出为通用课程表交换格式（subjects / timetable / schedules），可与其它排课软件互通。

💾

本地档案落盘

所有编辑一键保存为 ClassIsland 官方 Profile JSON（TimeLayouts / ClassPlans / Subjects），换机迁移零门槛。

🖥️

深色专注主题

专为教室多媒体大屏调校的高对比深色界面，白字蓝块长时间投放不刺眼。

Compatibility

数据模型，与生态对齐

不是「自成一派的孤岛工具」——底层结构能进能出，接得住已有数据，也送得出去。

ClassIsland 兼容

Profile 档案直读直写

数据结构对齐 ClassIsland 官方 JSON：TimeLayouts、ClassPlans、Subjects、ClassPlanGroups、SelectedClassPlanGroupId。每个 ClassPlan 携带 WeekDay / WeekCountDiv / WeekCountDivTotal 实现多周轮换。

CSES 标准

通用交换格式

导出符合 CSES 结构的 subjects / timetable / schedules 数据，支持与第三方排课软件互换，配合工具链可对接集控下发链路。

Tech Stack

扎实的 Qt 技术底座

模型驱动视图、坐标映射交互、命令模式撤销——每一层都用 Qt 的原生机制，不用花架子。

Qt 6.8 · 核心框架 QML · 声明式界面 C++17 · 数据与业务层 QAbstractTableModel · 课表网格 QAbstractListModel · 时间轴/科目 Q_INVOKABLE · QML 桥接 QUndoStack · 撤销重做 QJsonDocument · 档案序列化 CMake + Ninja · 构建 windeployqt · 一键部署
Get Started

三步上手

Windows 下准备好 Qt 6.8 + MSVC + CMake，然后一条命令走完「配置 → 编译 → 部署」。

# 1. 克隆
git clone …
cd Stelarith-schedule-qt

# 2. 一键构建（自动配置 CMake、编译、部署 Qt 运行时与 QML 模块）
pwsh -File build.ps1        # 增量构建
pwsh -File build.ps1 -Clean   # 全量重建

# 3. 运行
.\build\stelarith-schedule-qt.exe

首次运行自动生成示例档案（3 节时间点 + 3 科目 + 2 套课表群「默认课表 / 双周轮换」）， 命令行可指定档案路径：--profile <path>。
