# 灵动岛统一布局规范（Island Layout Spec）

> 状态：2026-10-27 立项 · Phase 0 地基
> 适用范围：被控端灵动岛所有 face / 面板 / 瞬时提示（含历史通知、课表、设置、批注、计时、监控回放、自动化规则等）
> 目标：用**一套布局语言**取代各 face 各自手搓的版式，消弭视觉漂移；新模块直接复用基元，**不要硬加**样式。

---

## 0. 为什么需要这份规范

本轮复盘截图（历史通知面板）暴露三类典型粗糙：

1. **重叠文字** —— 绝对定位元素互相压字（标题/副标题/时间轴互不避让）。
2. **黑块「知道了」** —— 瞬时提示（alert / toast）用硬编码深色矩形 + 裸文字按钮，既无 MD3 语义、也无统一语言。
3. **吉祥物压列表** —— `WhaleMascot` 在 `z:100`，历史面板 `z:40` 且未给右侧留白 ⇒ 鲸鱼盖住列表末行。

根因不是"缺令牌"（`IslandTheme` 已全量覆盖、岛内 0 处硬编码 `#`），而是**缺一致的布局基元与 z 序纪律**。本规范定义基元与纪律，后续所有 face 复用，不再各写一套。

> 关键架构约束：岛用**非单例** `IslandTheme`（需深浅并存），管理端用 `Md3` 单例。两者令牌**对齐到同一套 MD3 角色**（色/字阶/间距/圆角/动效），但实现分两套，不可互相直连。本规范只约束"取值对齐"，不强行合并。

## 1. 设计原则（向 ClassIsland 学什么）

| 原则 | 含义 | 反例（旧） |
|------|------|-----------|
| **按天分组** | 列表按"今天 / 昨天 / M月d日"分段，段头 sticky | 平铺一长串，无时间锚点 |
| **左侧时间轴** | 时间信息贴左缘、统一基线，一眼扫到时序 | 时间散在右上角，各行错位 |
| **日期 sticky 头** | 分组标签是"段"不是"行内小字"，沉在底色之上 | 段头与条目同字号同色，分不清 |
| **图标优先** | 每行前置语义图标（bell/alert/info…），不靠文字辨析类型 | 纯文字，类型靠读 |
| **克制动效** | 仅"微交互 / 过渡 / 几何形变"三档，时长走令牌；不堆滑入/弹跳 | 14 处硬编码时长、各文件取值不一 |
| **绝不重叠 z 序** | 任何新层必须落在 z 阶梯的明确档位，且显式给相邻层让位边距 | 鲸鱼 z:100 盖住 z:40 面板 |

## 2. 令牌系统（IslandTheme 为唯一真源）

> 既有令牌（`bg/fg/sub`、`severity*`、`accent`、`fs*`、`shape*`、`dur*`）保持不变。
> 本规范**新增**间距 / 圆角 / 度量三族，对齐到各 face 当前硬编码值，使基元有统一引用点。

```qml
// ── 间距（对齐 MD3 spacing 阶梯）──
property real spXS: 4
property real spS:  8
property real spM:  12
property real spL:  16
property real spXL: 20

// ── 圆角（对齐 IslandSurface 当前取值）──
property real rCard:   10   // 独立容器（历史面板等）
property real rRow:    8    // 列表行
property real rSection:6    // 分组标签
property real rPill:   999  // 胶囊/按钮/chip

// ── 列表/头部度量（取代各面硬编码 48/32/18）──
property real rowH:    48
property real headH:   32
property real sectionH: 18
```

**取值锁定纪律**：任何面改版不得重新发明 48/32/18/10/8/6，一律引用 `th.rowH` 等。机器门禁 `scripts/test-island-metrics.mjs` 已盯 shape/字阶，本规范新增的间距/圆角令牌后续纳入同款盯防。

## 3. 布局基元清单

### 3.1 既有（不可重复造）
| 基元 | 文件 | 职责 |
|------|------|------|
| `IslandSurface` | `island/IslandSurface.qml` | G2 曲率连续圆角容器（替代 `Rectangle.radius` 的折角） |
| `ActionButton` | `island/ActionButton.qml` | 主/次动作按钮（primary 实心 / secondary 描边） |
| `IslandActionRow` | `island/IslandActionRow.qml` | 根级动作行（`z:50`） |
| `SvgIcon` | `island/SvgIcon.qml` | 着色 SVG 图标（依赖 C++ `svgicon` provider） |

### 3.2 本规范新增（Phase 0 落地）
| 基元 | 文件 | 职责 | 复用既有 |
|------|------|------|---------|
| `IslandFaceHeader` | `island/IslandFaceHeader.qml` | 面头部：标题 + 未读点 + 副标题 + 尾部操作槽 | `th.headH` |
| `IslandCard` | `island/IslandCard.qml` | 一致内边距的容器（包 `IslandSurface`） | `IslandSurface` |
| `IslandListRow` | `island/IslandListRow.qml` | 统一列表行：图标/未读点/标题/描述/时间/分类 | `SvgIcon`+`IslandSurface` 风底色 |
| `IslandSectionLabel` | `island/IslandSectionLabel.qml` | ClassIsland 式分组 sticky 标签 | `th.sectionH` |
| `IslandToast` | `island/IslandToast.qml` | MD3 Snackbar 风瞬时提示（替代黑块 toast / 裸「知道了」） | `th.dur*` |

**接口约定（所有基元）**：
- `property var th: null` 必传（非单例，由 `IslandRoot` 经 `th: root.th` 显式注入）。
- 不直接读 `root.*`；数据/回调一律走显式 `property` 与 `signal`，保证可独立渲染与测试。
- 字号/圆角/间距/时长全部走 `th.*`，**禁止裸数字**（除 `1px` 描边线宽等物理常量）。

## 4. z 序阶梯（铁律）

| z | 层 | 元素 |
|---|----|------|
| 0–30 | 内容层 | 面内容、列表、卡片 |
| 40 | 历史面板 | `historyPanel`（独立容器） |
| 50 | 根级动作行 | `IslandActionRow` |
| 100 | 吉祥物 | `WhaleMascot`（右下角，全岛最高非模态层） |
| 110+ | 瞬时提示 | `IslandToast`（置顶但不挡交互） |
| 300 | 全屏面 | 全屏媒体 / 批注 |

**让位纪律**：任何 `z < 100` 的层若与吉祥物右下角（`rightMargin 6~8`、`bottomMargin 2~4`、宽 ~36~44px）几何相交，**必须 `anchors.rightMargin` 额外让出 ≥44px**（历史面板、展开区右侧栏均已照此办理）。吉祥物不得因新层而降权（它是品牌锚点）。

---

## 5. 列表 / 卡片范式

- **行高**：`th.rowH`(48)，两行文字（标题 13 + 描述 12，描述最多 2 行 `WordWrap`）。
- **未读**：左侧 5px 圆点 + 标题 `DemiBold`，已读 `Medium`；不得用额外图标表达。
- **分类标签**：仅描述行右侧小字，配色 `error→#e5484d / warning→#f5a623 / 其它→sub`；不另起一行。
- **底色**：行独立底色，hover 加深（`th.durInstant` 过渡）；行间 `spacing: 2`。
- **分组**：`ListView.section` + `IslandSectionLabel` 作段头，段头不参与行 hover。
- **容器**：面板/卡片一律 `IslandCard`（底层 `IslandSurface` G2 圆角），不得裸 `Rectangle` 画大圆角。

---

## 6. 禁忌清单（Don'ts）

- ❌ 在 face 内 `anchors` 兄弟互锚跨父级（QML 静默丢弃）。根级行只锚 `parent`。
- ❌ 用 `Rectangle.radius` 画大圆角容器（折角）——改用 `IslandSurface`。
- ❌ 硬编码时长（`90/120/200…`）或字号/圆角——走 `th.*`。
- ❌ 新 toast/alert 用深色裸矩形 + 裸文字按钮——用 `IslandToast` / `ActionButton`。
- ❌ 新列表行手搓 48px 行——用 `IslandListRow`。
- ❌ 新面板头部手搓标题——用 `IslandFaceHeader`。
- ❌ 在 `z<100` 层与吉祥物右下角相交却不让位。
