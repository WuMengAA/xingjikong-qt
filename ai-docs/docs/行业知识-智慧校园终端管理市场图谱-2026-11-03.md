# 智慧校园终端管理市场图谱：国内 vs 海外，谁在管学校的设备

> **30 秒电梯演讲**：智慧校园的"终端管理"市场，国内与海外几乎是两套平行宇宙——海外被 **Jamf/Intune/Mosyle/Google** 按 OS 生态切成几大块；国内则是 **希沃/鸿合/锐捷/华为** 等硬件厂商自带集控 + **钉钉/腾讯/阿里** 等平台型玩家 + 大量区域教育云。星集控（Stelarith）的卡位是"开源 + 自托管 + 不绑硬件 + 全校集控"——国内硬件厂商绑设备、平台厂商绑生态，海外绑 OS，它卡在三者都不愿做、纯开源又做不全的空白。**市场规模数字本轮因联网额度不可用（HTTP 402）未查证，一律标 ❓，不编造。**

## 二、海外阵营（按 OS 生态切分）

| 玩家 | 绑定生态 | 核心场景 | 部署 |
|---|---|---|---|
| **Jamf** | Apple（macOS/iPad/iOS） | 教育 1:1 设备、Apple School Manager | 云/SaaS |
| **Microsoft Intune** | Windows + M365 | 企业/教育 UEM，绑定订阅 | 云/SaaS |
| **Mosyle** | Apple（教育专精） | K-12 教育 MDM，低价 | 云/SaaS |
| **Google Admin / ChromeEDU** | ChromeOS | 美式 1:1 Chromebook 教室 | 云/SaaS |
| **Apple School Manager + ASM/MDM** | Apple 设备监管 | 批量采购 + 监管锁 | 云 |
| **ManageEngine / 其他** | 跨平台 | 中小企业 IT | 本地/云 |

> 🟡 海外教育市场高度"Apple vs Google vs Microsoft"三分天下，集控软件往往**先绑 OS 再谈功能**。

## 三、国内阵营（硬件 + 平台 + 区域云）

| 玩家 | 类型 | 集控形态 | 绑定对象 |
|---|---|---|---|
| **希沃 Seewo** | 硬件（一体机/白板） | 自带设备管理平台 | 绑希沃硬件 |
| **鸿合 HiteVision** | 硬件（智慧黑板） | 鸿合集控/运维 | 绑鸿合硬件 |
| **锐捷 Ruijie** | 网络+终端 | 锐捷云课堂/终端管理 | 绑网络+设备 |
| **华为/联想** | 硬件+云 | 教育终端/桌面云 | 绑硬件生态 |
| **钉钉/腾讯/阿里 智慧校园** | 平台型 | 教务+沟通+轻量设备管理 | 绑 IM/办公生态 |
| **区域教育云（各省）** | 政府/国企 | 区域级集控与资源 | 绑行政区 |
| **ClassIsland（开源）** | 开源课表/集控插件 | 班级信息屏集控 | 不绑硬件、自托管 |
| **星集控 Stelarith（开源）** | 开源 Qt 三端 | 全校屏幕集控 | **不绑硬件、自托管** |

> ✅ ClassIsland 与 Stelarith 是国内"开源/自托管"阵营的代表；前者聚焦"班级信息屏 + 课表"，后者是"全校终端集控 + 监看 + 远控指令"的完整平台（据仓库源码）。

## 四、国内 vs 海外：结构差异图

```
           海外                         国内
    ┌──────────────┐            ┌──────────────────┐
    │ Apple/Google/│            │ 硬件厂商自带集控  │
    │ Microsoft    │            │ (希沃/鸿合/锐捷)  │
    │ 三分天下     │            ├──────────────────┤
    ├──────────────┤            │ 平台型(钉钉/腾讯) │
    │ 集控绑 OS    │            ├──────────────────┤
    │ SaaS 订阅    │            │ 区域教育云        │
    └──────────────┘            ├──────────────────┤
                                 │ 开源(Stelarith/  │
                                 │ ClassIsland)     │
                                 └──────────────────┘
       差异：海外"绑 OS"    国内"绑硬件/绑平台/绑行政区"
             + SaaS 成熟          开源自托管是稀缺品
```

**关键差异三连**：
1. **海外**靠 OS 生态（Apple School Manager/ChromeEDU/Intune）把集控做成"订阅服务"。
2. **国内**靠硬件出货（买一体机送集控）把集控做成"设备附赠"，平台型玩家则绑 IM/办公。
3. **开源自托管**在国内外都是**稀缺品**——商业玩家嫌服务重/利润薄，纯开源又多停留在单机工具。

## 五、Stelarith 的空白交集卡位（✅ 一级信源）

```
生态绑定强度
   高 │  商业 UEM/硬件集控       ★ 星集控（开源+自托管
      │  (Jamf/希沃/鸿合)          + 全校集控+不绑硬件)
   低 │  纯开源单机工具
      └────────────────────────────────▶ 部署自由度
           低                          高
```

- ✅ 星集控是 **Qt 三端**（云端 8788 / 被控端 control-qt / 管理端 viewer-qt），可私有部署、不绑硬件、不绑 OS（Qt 跨平台）。
- ✅ 功能覆盖"设备纳管 + 课表/媒体/通知/灵动岛信息面板 + 监看(VNC) + OTA 升级 + 指令下发回执"——是开源阵营里少见的"完整平台"而非"单机工具"。
- 🟡 空白交集判断基于源码 + 行业常识推断，未做 exhaustive 竞品普查（受联网 402 限制）。
