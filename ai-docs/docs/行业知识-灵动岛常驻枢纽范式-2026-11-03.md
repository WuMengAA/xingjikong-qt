## 0. 一句话

> 别人把「通知」做成**弹窗**（打断你），把「状态」做成**状态栏**（你不看），
> 我们把「通知 + 状态 + 课表 + 倒计时 + 天气」收进一个**常驻胶囊**——
> 它像手机灵动岛一样**永远在边角、永远信息密集、永远不打断教学**。

这就是 `IslandRoot.qml` 存在的理由，也是全库 **8 个域依赖它**的唯一交叉点。

## 1. 范式解剖：三种「信息呈现」哲学的对比

```
  ╔══════════════════════════════════════════════════════════════╗
  ║  哲学 A：弹窗 (Toast / Dialog / Modal)                        ║
  ║   ── 代表：传统通知、微信弹窗、系统警告                          ║
  ║   特征：出现即打断、占据中心、需手动关、看一眼就消失             ║
  ║   缺陷：教室大屏上 = 正在上课突然黑一半 → 老师骂街             ║
  ╠══════════════════════════════════════════════════════════════╣
  ║  哲学 B：状态栏 (Status Bar / Ticker)                         ║
  ║   ── 代表：Windows 任务栏、手机通知栏、ClassIsland 顶栏        ║
  ║   特征：常驻、不打断、信息平铺、密度低                          ║
  ║   缺陷：教室场景下「概览/课表/倒计时」是**结构化**的，          ║
  ║         一条平铺栏塞不下「当前第几节+距下课+今日总览」          ║
  ╠══════════════════════════════════════════════════════════════╣
  ║  哲学 C：常驻胶囊 / 灵动岛 (Our Dynamic Island)   ★我们        ║
  ║   ── 代表：Apple iPhone 灵动岛、星集控 IslandRoot             ║
  ║   特征：常驻边角、可折叠/展开、信息按优先级流动、不抢戏         ║
  ║   优势：既「常驻不打断」(胜A)、又「结构化高密度」(胜B)          ║
  ╚══════════════════════════════════════════════════════════════╝
```

> 创意判读：**灵动岛 = 弹窗的「信息密度」+ 状态栏的「不打断」**，是两者的上确界。

```
   ┌─────────────────────────────────────────────────────────┐

   │                                                           │
   │                          [教学 PPT/白板]                  │
   │                                                     ┌───┐ │

   │   ┌───────────────────────────────────────┐              │
   │   │ 🐳 星集控岛                              │              │
   │   │ ┌────────┐ ┌────────┐ ┌────────┐      │              │
   │   │ │今日课表│ │ 倒计时 │ │ 媒体   │ ...   │  ← 面(face)   │

   │   └───────────────────────────────────────┘              │
   └─────────────────────────────────────────────────────────┘
```

**8 个面（face），仓库 `island_layout.cpp` 的 builtinRows 实读：**

| id | 面 | 默认 enabled | 数据来源 |
|---|---|---|---|
| 0 | 概览 Overview | ✅ | 汇总 |
| 1 | 今日课表 | ✅ | `ScheduleModel` |
| 2 | 媒体控制 | ✅ | `MediaProvider` |
| 3 | 笔/批注 | ✅ | `PenProvider` |
| 4 | 设置 | ✅ | `AgentSettings` |
| 5 | 自定义 | ✅ | 用户扩展 |
| 6 | 信息/天气 | ✅ | (待建) |
| **8** | **日期周次** | ❌ | `panelSource.dateInfo()` |
| **9** | **倒计时** | ❌ | `panelSource.countdownInfo()` + `CountdownTarget` |

> 创意点：面 8/9（期/倒）是**本轮中程新增**的——把「今天第几周」「离某事件还有多久」
> 也收进岛，让岛从「设备状态」升级成「时间锚点」。

## 3. 行业坐标：谁在做什么「常驻信息」

```
  信息呈现形态 ── 谁在用 ── 适配场景 ── 我们的位置
  ───────────────────────────────────────────────────
  弹窗            几乎所有系统    临时打断        我们：仅告警用
  状态栏          手机/桌面 OS    低密常驻        ClassIsland 顶栏在此
  灵动岛(胶囊)    Apple / 星集控  高密常驻+不打断  ★我们 + Apple
  电子班牌滚动条  数字标牌        纯展示          ㊙ 没交互
  Widget 小组件   iOS/Android    个人常驻         ❓ 教育场景少
```

> 关键事实：**教育集控领域，没有任何竞品用「灵动岛胶囊」作为主信息枢纽**。
> ClassIsland 用「顶栏 + 组件」，希沃用「系统级状态条」，SaaS 用「网页通知」。
> 我们是为数不多把手机端 Dynamic Island 隐喻**搬到教室大屏**的——这是原创切入点。

## 4. 为什么是「岛」而不是「栏」或「窗」（决策树）

```
  教室大屏信息该怎么呈现？
        │
   需要常驻吗？──否──▶ 弹窗就够了（告警用）
        │是
   信息结构化吗？──否──▶ 状态栏/顶栏（平铺）
        │是（课表/倒计时/媒体/笔 是结构化的）
   屏幕是教学主界面吗？──否──▶ 独立面板
        │是（老师正在用大屏上课）
   能接受中心弹窗打断吗？──否──▶ 必须边角常驻
        │
   └─▶ ★灵动岛：边角常驻 + 可折叠 + 结构化高密度 + 不打断
```

三条不可妥协的约束（来自教室真实场景）：
1. **不打断教学**（中心弹窗 = 事故）→ 必须边角；
2. **信息要结构化**（课表是「节次×科目×时间」不是一行字）→ 必须多面；
3. **老师不想看时能隐身**（胶囊折叠）→ 必须可折叠。

> 这三条同时成立的，只有「灵动岛」形态。顶栏(平铺)满足 1、2 但弱 3；弹窗满足 2 但破 1。

## 5. 技术实现要点（仓库实读，给工程师看）

- **唯一枢纽**：`IslandRoot.qml` 是单例式根，8 域经它暴露；**不设 QML 单例模块**（管理端无此模块，import 硬错整页空白）——改用 context property `islandLayout` / `panelSource`（三处注入：island.cpp / agent_ui.h / CMakeLists）。
- **面布局可配**：`IslandLayoutModel`（QAbstractListModel）roles = Id/Label/Title/Note/Enabled/Order/RequiresLive/Scale；QSettings 键 `island/layout`；顺序错会导致反向验证红（踩过）。
- **期/倒取数**：`IslandPanelSource` 用 **Q_INVOKABLE**（打开那刻算一次，配定时器越算越远——所以不用 Q_PROPERTY）；面 8/9 带 `typeof panelSource!=='undefined'` 守卫（管理端共用无注入）。
- **通知文字修复（本轮）**：`recomputeMorph()`(island.cpp:2030) 真实通知只设 `m_morphMode` 不填 `m_morphData` → 胶囊曾回退静态「收到通知」；修复 `IslandMorph.qml` 优先读 `bridgeRef.title/desc`（IslandBridge 合法 Q_PROPERTY），mdata 仅演示兜底。
- **探针陷阱**：给 QML 加 import 新 C++ 注册模块，同一轮必须给探针壳也链上该 .cpp + moc 其头，否则整页空白且 `g_qmlErrors=0`（零报错假阴性，踩过）。

## 6. 创意延伸：岛还能长成什么（中程想象，非承诺）

```
  今天(2026-11-03)              中程(设想)                  远期(设想)
  ──────────────               ─────────────              ─────────────
  概览/课表/媒体/笔/设置/         + 天气面                     + 多岛(主屏+副屏)
  自定义/信息/【期】/【倒】        + 作业提醒面                 + AI 摘要面
                                 + 设备健康面                 + 跨教室聚合看板
                                 + 考试模式专属面              + 校领导总览岛
```

> 想象边界：**岛是「教室的信息心脏」**，任何「老师/学生需要常驻知道、又不该打断教学」的信息，
> 都该长成岛的一个面。这是我们的产品哲学，不是功能清单。
