## 0. 为什么写这份文档

教室集控终端不是凭空出现的产品。它的需求强度、采购节奏、合规边界，几乎完全由两股外力塑造：**国家教育信息化政策的演进** 与 **教育行业的采购 / 渠道生态**。读懂这两条线，才能判断星集控该主攻哪类客户、用什么商业模式、在哪个政策窗口加速。

## A. 教育信息化政策演进（国内）

### A.1 政策时间轴（可视化手法 1：时间轴）

国内教育信息化的主线，是从「把网络通到校」逐步走向「用数据重塑教学」。每一阶段都对「教室终端如何被集中管理」提出了新要求。

```text
1990s末                2000s中后              2012~2018               2018~2022                2022~今
  |                       |                      |                      |                      |
  ▼                       ▼                      ▼                      ▼                      ▼
【校校通】            【三通两平台】        【教育信息化2.0】      【教育数字化战略行动】   【AI+教育 / 教育大模型】
 联网入校              宽带/资源/平台        三全两高一大           国家智慧教育平台        大模型进课堂
 单机孤岛             ↓ 班班通/人人通        ↓ 从"建"到"用"         ↓ 平台贯通             ↓ 智能化治理
  └─ 终端少、        └─ 电子白板/大屏       └─ 数据开始沉淀        └─ 一网统管雏形         └─ 终端需"可被AI调度"
     无需集控            规模化铺终端           需统一运维              需统一管控              集控=基础设施
  🟡                    🟡                     🟡                     🟡                     🟡
```

> ❓ 具体发文文号（如教技〔2012〕号系列、国务院"双减"配套、教育部 2022 年工作要点具体条目）与"三全两高一大"的逐字定义，本环境未联网查证，待补。🟡 时间线为教育信息化领域公认演进叙事，非逐条引用。

### A.2 每一阶段对「教室终端管理 / 集控」的推动（可视化手法 2：阶段→需求映射表）

| 阶段 | 终端侧典型变化 | 对"集控"的新需求 | 集控成熟度要求 |
|---|---|---|---|
| 校校通 🟡 | 机房、少量联网 PC | 基本无（单机为主） | 低 |
| 三通两平台 🟡 | 电子白板 / 交互大屏进班，班班通 | 设备清点、开机率统计、统一开关 | 中 |
| 教育信息化 2.0 🟡 | 人人通终端（学生机/平板）、录播教室 | 远程管控、统一下发应用/课表、合规审计 | 中高 |
| 教育数字化战略行动 🟡 | 国家平台贯通、区域云平台 | 跨校统一管控、数据上报、分级权限 | 高 |
| AI+教育 🟡 | 大模型进课堂、智能体助教 | 终端可被发现/调度、自动化规则、行为可控 | 极高 |

**关键判断（🟡 推断）**：政策越往后，"终端"从「资产」变成「持续在线的治理节点」。集控不再是"省事工具"，而是"政策达标项"——没有统一管控，就谈不上数据贯通与合规审计。这正是星集控这类平台的政策基本面支撑。

### A.3 政策驱动的"集控需求光谱"（可视化手法 3：光谱图）

把政策诉求按"刚性 vs 柔性"与"建设期 vs 运营期"排成光谱，可看出集控产品在不同窗口的卖点差异：

```text
建设期（一次性采购）  ───────────────────────────────────────▶  运营期（持续服务）
  "达标验收"  "设备在线率"  "数据上报"  "日常运维"  "智能治理"
  刚性↑──────┐                              ┌────刚性↑
             │ 三通两平台验收                  │ AI+教育常态化治理
  柔性───────┘                              └────柔性
  卖点：铺得上、点得清              卖点：管得住、看得明、调得动
```

## B. 集控终端的采购与渠道生态

### B.1 采购主体分层架构（可视化手法 4：分层架构 ASCII 图）

教室集控终端的采购不是单一决策，而是多层结构。理解每一层的预算来源与决策权，才能定位销售与产品的发力点。

```text
┌─────────────────────────────────────────────────────────────┐
│  层 0：国家/部委  ——  政策与标准（不直接采购终端）            │
│        定方向：数字化、国产化、平台贯通                       │
└───────────────────────────────┬─────────────────────────────┘
                                 │ 转移支付 / 专项资金 / 标准
┌───────────────────────────────▼─────────────────────────────┐
│  层 1：省 / 地市 教育局  ——  区域级集采、三个课堂专项          │
│        预算：大额、集中、带验收；倾向"软硬一体+服务"          │
└───────────────────────────────┬─────────────────────────────┘
                                 │ 分配 / 校际均衡
┌───────────────────────────────▼─────────────────────────────┐
│  层 2：区县教育局  ——  区域教育云平台、同步课堂项目业主         │
│        决策：平台选型 + 终端集控方案捆绑                       │
└───────────────────────────────┬─────────────────────────────┘
                                 │ 下达 / 配套
┌───────────────────────────────▼─────────────────────────────┐
│  层 3：学校（校方信息化主任/电教老师）  ——  自主零散采购       │
│        预算：小、灵活、重易用；倾向"免费软件+自己折腾"         │
└───────────────────────────────┬─────────────────────────────┘
                                 │ 部署在真实教室
┌───────────────────────────────▼─────────────────────────────┐
│  层 4：教室终端  ——  大屏/学生机/录播  ←  集控软件真正落点     │
│        ✅ 星集控被控端（Qt/Windows）即运行于此层               │
└─────────────────────────────────────────────────────────────┘
```

> ✅ 星集控被控端定位在层 4（教室机），管理端在老师机（层 3 侧），云端中转（8788）与站点在层 1~2 的"区域平台"抽象位。

### B.2 采购模式象限矩阵（可视化手法 5：象限矩阵）

把"决策集中度（谁掏钱）"与"服务粘性（买完要不要续费）"做成四象限，便于看清不同商业模式的落点：

```text
                高服务粘性
                   │
   Q2 区域集采       │      Q1 厂商直供+订阅
   教育局统采+运维   │     品牌厂商软硬一体+年服务费
   服务绑定强        │     强粘性、强续费
                   │
低决策集中 ────────┼─────────────── 高决策集中
（学校自定）        │              （上级统管）
                   │
   Q3 学校自主采购   │      Q4 集成商/代理商落地
   免费软件为主      │     贴牌/ODM+实施，粘性中等
   粘性弱、可替换   │     靠关系与实施吃饭
                   │
                低服务粘性
```

- **Q1（厂商直供 + 订阅）**：品牌大厂（希沃/鸿合等）主战场，软硬一体 + 年服务费，粘性最高。
- **Q2（区域集采）**：三个课堂 / 同步课堂专项，教育局统采带运维，星集控的"开源+私有化+多租户"在此有差异化空间 ✅（云端多租户已实装）。
- **Q3（学校自主）**：零散、价格敏感、爱用免费方案——星集控作为开源平台天然契合，但变现弱。
- **Q4（集成商/代理商）**：渠道靠实施与关系落地，是开源方案的重要分发层。

### B.3 渠道角色食物链（可视化手法 6：角色关系图）

```text
厂商 / ODM（造设备/出固件）
      │  供货 / 贴牌
      ▼
集成商 / 代理商（做方案、跑关系、实施部署）  ──►  教育局/学校（最终用户）
      │  需"可管控的终端软件"                       │
      ▼                                            │
   星集控这类集控平台（✅ 开源、可私有化、可嵌入） ◄──┘
      │  提供管控能力，不一定要自己卖硬件
      ▼
   最终落点：教室大屏 / 学生机（层 4）
```

**渠道洞察（🟡 推断）**：
- 集成商最缺"便宜好用、能私有化、不被厂商锁死"的管控软件——星集控的开源属性在此是卖点而非短板。
- ODM 若自带闭源管控，则星集控是"去绑定"的备选；若 ODM 无管控，则星集控是"加分项"。
- 厂商直供（Q1）对纯开源方案门槛最高，因大厂要独占服务收入。

### B.4 商业模式光谱（可视化手法 7：光谱图）

从"软件免费"到"软硬一体卖断"，是一条连续光谱，不是二分：

```text
纯免费开源 ──── 免费软件+付费服务 ──── 订阅SaaS ──── 软硬一体卖断 ──── 硬件绑定独占
 星集控✅        运维/定制/培训          年费/坐席       品牌大厂主战场     厂商锁死
 变现弱          变现中等                变现强          变现最强           用户最被动
```

> ✅ 星集控当前形态偏向"纯免费开源 + 可私有化部署"，商业变现尚未成型（符合开源项目早期态）。🟡 光谱位置为行业常识推断。

### B.5 采购决策树（可视化手法 8：决策树）

假设你是区域信息化负责人，决定"怎么把集控落下去"，典型决策路径：

```text
是否有上级统采专项资金？
├─ 否 ──► 学校自主采购？
│         ├─ 是 ──► 预算小、重易用 ──► 选开源/免费方案（星集控✅契合）
│         └─ 否 ──► 暂不采购，观望
└─ 是 ──► 是否要求数据不出本地 / 信创合规？
          ├─ 是 ──► 需私有化 + 国产化栈 ──► 星集控可私有化部署✅，但信创适配❓待补
          └─ 否 ──► 是否已有品牌大厂软硬一体？
                    ├─ 是 ──► 沿用厂商方案（粘性高、替换难）
                    └─ 否 ──► 走集成商/代理商招标 ──► 开源集控+实施服务组合（星集控机会区）
```

### B.6 信创（国产化替代）对终端管理的影响（🟡 推断 + ❓ 待查）

信创是近年绕不开的变量。它对集控的影响可归纳为三点：

1. **操作系统栈迁移**：从 Windows 向国产 Linux 桌面（统信 UOS / 麒麟等）迁移，终端管控软件必须跨栈。
   - ✅ 星集控被控端当前为 Qt/Windows；跨 Linux 桌面与安卓需额外适配（已知有 Qt-for-Android 可行性评估文档 🟡）。
2. **自主可控诉求**：闭源厂商锁死在信创场景不受欢迎，开源、可审计、可私有化是加分项 ✅。
3. **合规门槛**：政府采购目录、安可替代清单等形成准入壁垒。
   - ❓ 具体"安可替代"目录条目、入围条件未查证，待补。

> ⚠️ 信创适配是星集控的次级战场：政策刚性高但工程成本也高，应在核心 Windows 教室场景站稳后再扩展。

## C. 星集控在坐标系中的定位小结（✅）

把上面所有可视化叠起来，星集控的当前位置可概括为：

- **技术栈**：三端 Qt 架构，C++ 大脑 + QML 皮肤，云端中转（8788）+ 教室机被控端 + 老师机管理端 + 站点（SvelteKit）。✅
- **政策窗口**：落在"教育信息化 2.0 → 数字化战略 → AI+教育"的运营期，集控从"省事工具"升级为"治理基础设施"。🟡
- **采购落点**：最契合 Q2（区域集采私有化）与 Q3（学校自主开源），在 Q4（集成商分发）有渠道杠杆，最难啃 Q1（厂商直供独占）。🟡
- **商业模式**：当前偏"纯免费开源"，变现路径沿光谱向右（付费服务/订阅）逐步打开。🟡
- **差异化护城河**：✅ 不被硬件绑定 + 可私有化 + 多租户 + 教育场景深做（灵动岛组件体系）。
