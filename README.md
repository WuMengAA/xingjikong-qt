# 星集控 xingjikong-qt

教室数字运维平台（Qt 实现）：设备管控、远程协助、通知广播，一套覆盖「控制端 / 被控端」双形态。

> 项目主页与展板：<https://www.245959623.xyz/projects/xingjikong>

## 它做什么

- **设备管控** — 教室内批量设备的集中管理，控制端 / 被控端角色分离
- **远程协助** — 基于 WebRTC 的跨公网远控（国内 STUN 打洞 + 0.0.0.0 绑定 + video transceiver + 键鼠坐标回传）
- **通知广播** — 弹幕 / 全屏三档展示、快捷回复、过期消息拦截
- **静默升级** — NSIS 安装包 + 云端静默非覆盖安装，版本目录并存可回退
- **存储中心** — 本地文件 + 云端附件库

## 当前状态

以上能力均已上线（详见站点展板的待办看板）。本仓库用于承载源码与版本发布。
